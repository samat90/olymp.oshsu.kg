# Первый не меньше x

Дан массив из n чисел. Операции: «1 i x» — присвоить aᵢ = x; «2 l x» — найти наименьший индекс j ≥ l, для которого aⱼ ≥ x, или вывести −1.

**Ввод.** В первой строке n и q. Во второй — n чисел a₁…aₙ. Затем q строк с операциями. 1 ≤ n, q ≤ 50000, 1 ≤ aᵢ, x ≤ 10⁶. Операция типа 2 есть всегда.

**Вывод.** Ответ на каждую операцию типа 2 в отдельной строке.

## Примеры

**Ввод 1**
```
5 3
3 1 4 1 5
2 2 4
1 2 9
2 2 4
```
**Вывод 1**
```
3
2
```
