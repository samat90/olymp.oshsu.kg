# Набрать сумму

Из n чисел нужно выбрать несколько (возможно, ни одного) так, чтобы их сумма была равна ровно S. Возможно ли это?

**Ввод.** В первой строке n и S (1 ≤ n ≤ 100, 0 ≤ S ≤ 10^4), во второй n чисел a_i (1 ≤ a_i ≤ 10^4).

**Вывод.** YES или NO.

**Пример**

Ввод:
```
5 14
3 34 4 12 5
```
Вывод:
```
NO
```
