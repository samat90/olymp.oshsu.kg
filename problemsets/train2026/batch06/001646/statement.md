# Зубчатая подпоследовательность

Подпоследовательность чисел называется зубчатой, если разности соседних элементов строго чередуют знак (+, −, +, … или −, +, −, …). Последовательность из одного элемента зубчатая. Найдите длину самой длинной зубчатой подпоследовательности массива.

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (1 ≤ a_i ≤ 10^9).

**Вывод.** Наибольшая длина.

**Пример**

Ввод:
```
7
1 7 4 9 2 5 5
```
Вывод:
```
6
```
