# Счёт в игре

Игрок записывает очки по раундам. Запись - одно из:

- целое число - очки раунда;
- `+` - очки равны сумме двух предыдущих действительных раундов;
- `D` - очки вдвое больше предыдущего действительного раунда;
- `C` - отменить предыдущий действительный раунд (он больше не считается).

Все записи корректны. Найдите сумму очков всех действительных раундов.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` записей через пробел; числа по модулю не больше 30000.

## Выходные данные
Сумма по модулю 1000000007 (от 0 до 1000000006).

## Примеры

### Пример 1

Ввод:
```
5
5 -2 4 C D
```

Вывод:
```
1000000006
```

### Пример 2

Ввод:
```
3
3 D +
```

Вывод:
```
18
```
