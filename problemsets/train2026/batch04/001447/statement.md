Участники олимпиады набрали баллы. Выведите имена в порядке таблицы результатов: сначала больше баллов, при равенстве баллов — по алфавиту (сравнение по кодам символов).

## Формат ввода

В первой строке дано $n$. В следующих $n$ строках: имя и количество баллов.

## Формат вывода

Выведите $n$ имён по одному в строке.

## Ограничения

$1 \le n \le 5 \cdot 10^4$, $0 \le$ балл $\le 1000$. Имена состоят из букв кириллицы.

## Примеры

### Пример 1

Ввод:
```
3
Айбек 80
Бермет 95
Асан 80
```
Вывод:
```
Бермет
Айбек
Асан
```

### Пример 2

Ввод:
```
2
Улан 10
Улан 10
```
Вывод:
```
Улан
Улан
```
