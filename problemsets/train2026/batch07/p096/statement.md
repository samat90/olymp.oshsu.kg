# Недостижимые пары

В стране $n$ городов и $m$ двусторонних дорог. Сколько существует пар городов $(u, v)$, $u < v$, между которыми нельзя проехать?

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5 3
1 2
2 3
4 5
```

**Вывод**
```
6
```
