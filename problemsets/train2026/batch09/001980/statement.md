# Красные шары в выборке

В мешке $N$ шаров, из них $K$ красных. Наугад вынимают $n$ шаров. Какова вероятность, что красных среди них ровно $m$? Выведите вероятность в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Четыре числа $N$, $K$, $n$, $m$ ($1 \le N \le 10^6$, $0 \le K, n \le N$, $0 \le m \le n$).

**Вывод.** Вероятность по модулю $10^9+7$.

### Пример 1

Ввод:
```
5 2 2 1
```

Вывод:
```
200000002
```
