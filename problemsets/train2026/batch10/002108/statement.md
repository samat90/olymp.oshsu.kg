# Пути в сетке

Из левого верхнего угла сетки нужно дойти в правый нижний, двигаясь вправо или вниз. Клетки `#` — завалы, их проходить нельзя. Сколько существует путей? Ответ по модулю `10^9 + 7`.

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 1000`) и `n` строк по `m` символов `.` или `#`.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3 3
...
.#.
...
```

Вывод:
```
2
```

## Пример 2

Ввод:
```
2 2
.#
#.
```

Вывод:
```
0
```
