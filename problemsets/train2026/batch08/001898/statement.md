# Прибавить на отрезке

Дан массив из n чисел. Операции: «1 l r x» — прибавить x ко всем aₗ, …, aᵣ; «2 i» — вывести aᵢ.

**Ввод.** В первой строке n и q. Во второй — n чисел a₁…aₙ. Затем q строк с операциями. 1 ≤ n, q ≤ 100000, |aᵢ|, |x| ≤ 1000. Операция типа 2 есть всегда.

**Вывод.** Ответ на каждую операцию типа 2 в отдельной строке.

## Примеры

**Ввод 1**
```
4 3
1 2 3 4
1 2 3 10
2 3
2 4
```
**Вывод 1**
```
13
4
```
