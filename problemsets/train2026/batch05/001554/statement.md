# Без повторов, но наименьшая

Из строки нужно получить строку, в которой каждая встречающаяся буква есть ровно один раз. Для этого можно вычёркивать буквы, не меняя порядок оставшихся. Выведите лексикографически наименьший результат.

## Входные данные
Одна строка из строчных латинских букв длиной от 1 до 100000.

## Выходные данные
Искомая строка.

## Примеры

### Пример 1

Ввод:
```
bcabc
```

Вывод:
```
abc
```

### Пример 2

Ввод:
```
cbacdcbc
```

Вывод:
```
acdb
```
