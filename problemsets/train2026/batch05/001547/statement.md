# Убрать k цифр

Дано натуральное число в виде строки цифр и число `k`. Вычеркните ровно `k` цифр так, чтобы получившееся число было наименьшим. Ведущие нули в ответе отбрасываются.

## Входные данные
В первой строке число из `n` цифр (`1 ≤ n ≤ 200000`, ведущих нулей нет). Во второй строке число `k` (`0 ≤ k ≤ n`).

## Выходные данные
Наименьшее число без ведущих нулей (если цифр не осталось или остались одни нули, выведите `0`).

## Примеры

### Пример 1

Ввод:
```
1432219
3
```

Вывод:
```
1219
```

### Пример 2

Ввод:
```
10200
1
```

Вывод:
```
200
```

### Пример 3

Ввод:
```
10
2
```

Вывод:
```
0
```
