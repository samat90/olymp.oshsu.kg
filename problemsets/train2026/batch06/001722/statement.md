# Торговля с паузой

Известны цены зерна на n дней. Каждый день Каныкей может купить одну меру зерна, продать её или ничего не делать, но держать больше одной меры нельзя. После продажи на следующий день покупать нельзя (пауза один день). Какую наибольшую прибыль можно получить?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n цен p_i (1 ≤ p_i ≤ 10^4).

**Вывод.** Наибольшая прибыль.

**Пример**

Ввод:
```
5
1 2 3 0 2
```
Вывод:
```
3
```
