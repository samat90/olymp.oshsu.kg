В магазине в Бишкеке $n$ сувениров, у каждого есть цена. Азамат выбирает два разных сувенира так, чтобы их общая цена не превышала $K$. Сколько способов выбрать пару? Порядок не важен.

## Формат ввода

В первой строке даны $n$ и $K$. Во второй — $n$ цен.

## Формат вывода

Выведите количество пар.

## Ограничения

$2 \le n \le 2 \cdot 10^5$, $1 \le a_i, K \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
4 6
1 5 3 3
```
Вывод:
```
4
```

### Пример 2

Ввод:
```
3 2
5 6 7
```
Вывод:
```
0
```
