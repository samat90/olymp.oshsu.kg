# Ближайший колодец

На карте $h \times w$ клетка `1` — колодец, `0` — обычная клетка. Для каждой клетки найдите расстояние до ближайшего колодца, если ходить по сторонам клеток (расстояние между $(i,j)$ и $(a,b)$ равно $|i-a|+|b-j|$). Колодец хотя бы один.

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 2\cdot 10^5$). Далее $h$ строк по $w$ символов `0`/`1`.

**Вывод.** $h$ строк по $w$ чисел через пробел.

### Пример 1

**Ввод**
```
3 4
0001
0000
1000
```

**Вывод**
```
2 2 1 0
1 2 2 1
0 1 2 2
```
