# k-й свободный стул

В ряду n стульев: aᵢ = 0 — свободен, aᵢ = 1 — занят. Операции: «1 i» — стул i меняет состояние (свободный становится занятым и наоборот); «2 k» — вывести номер k-го слева свободного стула или −1, если свободных меньше k.

**Ввод.** В первой строке n и q. Во второй — n чисел a₁…aₙ. Затем q строк с операциями. 1 ≤ n, q ≤ 100000, 1 ≤ k ≤ n. Операция типа 2 есть всегда.

**Вывод.** Ответ на каждую операцию типа 2 в отдельной строке.

## Примеры

**Ввод 1**
```
5 4
0 1 0 0 1
2 2
1 2
2 2
2 4
```
**Вывод 1**
```
3
2
4
```
