# Лодки через реку

Через реку надо переправить n человек, вес человека i равен w_i. Лодка выдерживает суммарный вес не более C. Какое наименьшее число рейсов в одну сторону нужно, чтобы перевезти всех?

**Ввод.** В первой строке n и C (1 ≤ n ≤ 15, 1 ≤ C ≤ 1000), во второй n весов w_i (1 ≤ w_i ≤ C).

**Вывод.** Наименьшее число рейсов.

**Пример**

Ввод:
```
4 10
5 6 4 5
```
Вывод:
```
2
```
