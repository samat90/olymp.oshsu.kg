# Нечётные и чётные позиции

Сгруппируйте элементы списка: сначала все элементы на нечётных позициях (1, 3, 5, ...), затем на чётных (2, 4, ...). Порядок внутри групп сохраняется.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел.

## Выходные данные
Новый список через пробел.

## Примеры

### Пример 1

Ввод:
```
5
1 2 3 4 5
```

Вывод:
```
1 3 5 2 4
```

### Пример 2

Ввод:
```
4
8 7 6 5
```

Вывод:
```
8 6 7 5
```
