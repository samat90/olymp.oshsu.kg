# Добавить скобки

Нурлан записал строку из символов `(` и `)`. За одну операцию можно вставить скобку в любое место строки. Сколько операций нужно, чтобы строка стала правильной скобочной последовательностью?

## Входные данные
Одна строка длиной от 1 до 200000 из символов `(` и `)`.

## Выходные данные
Минимальное число вставок.

## Примеры

### Пример 1

Ввод:
```
())
```

Вывод:
```
1
```

### Пример 2

Ввод:
```
(((
```

Вывод:
```
3
```

### Пример 3

Ввод:
```
()()
```

Вывод:
```
0
```
