# Сумма глубин

Глубина вершины — число рёбер на пути от корня (вершины 1) до неё. Найдите сумму глубин всех вершин дерева.

**Ввод.** В первой строке n. В следующих n−1 строках по два числа u, v — ребро дерева. Корень — вершина 1. 1 ≤ n ≤ 100000.

**Вывод.** Одно число.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
7
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
10
```
