# Игра с краёв

Асель и Данияр по очереди берут числа с левого или правого края ряда из n чисел; первой ходит Асель. Каждый старается набрать как можно больше. Чему будет равна разность «сумма Асель минус сумма Данияра» при оптимальной игре обоих?

**Ввод.** В первой строке n (1 ≤ n ≤ 1000), во второй n чисел a_i (1 ≤ a_i ≤ 1000).

**Вывод.** Разность сумм.

**Пример**

Ввод:
```
4
4 7 2 9
```
Вывод:
```
10
```
