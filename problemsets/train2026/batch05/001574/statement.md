# Соединение верёвок

У мастера есть `n` верёвок длиной `l_i`. Соединение двух верёвок стоит столько, какова сумма их длин, и даёт одну верёвку. Какова наименьшая суммарная стоимость, чтобы получить одну верёвку?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел от 1 до 10^9.

## Выходные данные
Минимальная суммарная стоимость.

## Примеры

### Пример 1

Ввод:
```
4
4 3 2 6
```

Вывод:
```
29
```

### Пример 2

Ввод:
```
1
9
```

Вывод:
```
0
```
