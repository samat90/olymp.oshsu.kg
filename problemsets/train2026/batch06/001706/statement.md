# Слова без общих букв

Дан набор из n слов из букв a…p. Нужно выбрать несколько слов так, чтобы никакая буква не встречалась ни в двух разных выбранных словах, ни дважды внутри одного слова. Какую наибольшую суммарную длину могут иметь выбранные слова?

**Ввод.** В первой строке n (1 ≤ n ≤ 30), далее n слов длиной от 1 до 16 из букв a…p.

**Вывод.** Наибольшая суммарная длина (0, если выбрать нельзя).

**Пример**

Ввод:
```
4
un
iq
ue
abc
```
Вывод:
```
7
```
