# Знаки перед числами

Перед каждым из `n` чисел нужно поставить знак `+` или `-`. Сколькими способами сумма станет равной `T`?

**Ввод.** `n` (`1 ≤ n ≤ 60`), `T` и `n` чисел `a_i` (`0 ≤ a_i ≤ 100`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
5 3
1 1 1 1 1
```

Вывод:
```
5
```

## Пример 2

Ввод:
```
2 0
0 0
```

Вывод:
```
4
```
