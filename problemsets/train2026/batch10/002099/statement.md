# Лучшая подтаблица

Найдите прямоугольную подтаблицу (из одной или нескольких клеток) с наибольшей суммой чисел.

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 100`) и таблица (`|a| ≤ 1000`).

**Вывод.** Максимальная сумма.

## Пример 1

Ввод:
```
2 2
1 -2
-3 4
```

Вывод:
```
4
```

## Пример 2

Ввод:
```
2 2
-1 -2
-3 -4
```

Вывод:
```
-1
```
