# Грузы по дням

Грузовик из Ташкента в Ош должен перевезти `n` грузов в заданном порядке (порядок менять нельзя) за `D` дней. В день грузятся несколько подряд идущих грузов, суммарный вес которых не больше грузоподъёмности. Какова наименьшая возможная грузоподъёмность? Каждый день можно возить и ноль грузов.

**Ввод.** `n`, `D` (`1 ≤ D ≤ n ≤ 10^5`) и веса `w_i` (`1 ≤ w_i ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
6 3
3 2 2 4 1 4
```

Вывод:
```
6
```

## Пример 2

Ввод:
```
5 5
1 2 3 4 5
```

Вывод:
```
5
```
