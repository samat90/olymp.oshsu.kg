# Самое большое дерево поиска внутри

В двоичном дереве с числами в вершинах нужно найти поддерево (вершина вместе со всеми потомками), которое само является деревом поиска — слева строго меньшие значения, справа строго большие, — и содержит больше всего вершин. Выведите число вершин в нём.

**Ввод.** В первой строке n. Во второй — n чисел, значения вершин 1…n. Затем n строк: для вершины i — номера левого и правого сына (0, если нет). Корень — вершина 1. 1 ≤ n ≤ 100000, значения по модулю до 10⁹.

**Вывод.** Размер наибольшего поддерева-дерева поиска.

## Примеры

**Ввод 1**
```
5
10 5 15 1 8
2 3
4 5
0 0
0 0
0 0
```
**Вывод 1**
```
5
```
