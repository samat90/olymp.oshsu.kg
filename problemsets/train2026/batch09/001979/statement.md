# Максимум на кубиках

Бросают $n$ правильных кубиков с гранями $1, \dots, f$. Найдите математическое ожидание наибольшего выпавшего числа в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Два числа $n$ и $f$ ($1 \le n \le 10^9$, $1 \le f \le 10^5$).

**Вывод.** Ответ по модулю $10^9+7$.

### Пример 1

Ввод:
```
2 2
```

Вывод:
```
750000007
```
