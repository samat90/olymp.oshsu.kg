# Максимум и сколько раз он встречается

Дан массив из n чисел. Операции: «1 i x» — присвоить aᵢ = x; «2 l r» — вывести наибольшее значение среди aₗ, …, aᵣ и сколько раз оно там встречается.

**Ввод.** В первой строке n и q. Во второй — n чисел a₁…aₙ. Затем q строк с операциями. 1 ≤ n, q ≤ 100000, 1 ≤ aᵢ, x ≤ 10⁹. Операция типа 2 есть всегда.

**Вывод.** Для каждой операции типа 2 — два числа через пробел.

## Примеры

**Ввод 1**
```
5 3
3 7 7 2 7
2 1 5
1 2 1
2 1 3
```
**Вывод 1**
```
7 3
7 1
```
