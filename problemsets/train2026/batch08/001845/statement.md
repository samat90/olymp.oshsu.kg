# Самая далёкая вершина

Для каждой вершины дерева найдите расстояние до самой удалённой от неё вершины.

**Ввод.** В первой строке n. Затем n−1 строк с рёбрами. 1 ≤ n ≤ 100000.

**Вывод.** n чисел — ответы для вершин 1, 2, …, n.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
3 4 2 3 4
```
