# Укладка плитками 3 на n

Полосу $3 \times n$ нужно полностью покрыть плитками $1 \times 2$ (их можно поворачивать, плитки не перекрываются). Сколько способов? Ответ по модулю $10^9+7$.

**Ввод.** Одно число $n$ ($1 \le n \le 10^{18}$).

**Вывод.** Число способов по модулю $10^9+7$.

### Пример 1

Ввод:
```
2
```

Вывод:
```
3
```

### Пример 2

Ввод:
```
4
```

Вывод:
```
11
```
