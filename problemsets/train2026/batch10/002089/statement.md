# k-я скобочная последовательность

Все правильные скобочные последовательности из `n` пар скобок упорядочены лексикографически, при этом `(` меньше `)`. Выведите последовательность с номером `k` (нумерация с 1).

**Ввод.** `n` (`1 ≤ n ≤ 30`) и `k` (`1 ≤ k ≤` числа последовательностей).

**Вывод.** Строка из `2n` скобок.

## Пример 1

Ввод:
```
3 1
```

Вывод:
```
((()))
```

## Пример 2

Ввод:
```
3 5
```

Вывод:
```
()()()
```
