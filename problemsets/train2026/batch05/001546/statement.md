# Вода после дождя

После дождя в ущелье образуются лужи. Высоты соседних скал шириной 1 заданы массивом. Вода держится между скалами и не вытекает через края. Сколько единиц воды остаётся?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел - высоты от 0 до 10^9.

## Выходные данные
Суммарный объём воды.

## Примеры

### Пример 1

Ввод:
```
6
3 0 2 0 4 1
```

Вывод:
```
7
```

### Пример 2

Ввод:
```
3
1 2 3
```

Вывод:
```
0
```
