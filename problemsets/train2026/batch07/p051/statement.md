# Две команды

Среди $n$ школьников есть $m$ пар друзей. Для соревнования нужно разделить всех на две команды так, чтобы в каждой паре друзей ребята оказались в разных командах. Возможно ли это?

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$ ($a \ne b$, пары различны).

**Вывод.** `YES` или `NO`.

### Пример 1

**Ввод**
```
5 5
1 2
2 3
3 4
4 1
4 5
```

**Вывод**
```
YES
```
