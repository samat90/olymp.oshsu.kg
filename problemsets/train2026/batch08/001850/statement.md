# Сколько способов выбрать

Выбрать подмножество вершин дерева (возможно, пустое) так, чтобы никакие две выбранные не были соединены ребром. Сколько существует таких подмножеств? Выведите остаток от деления на 1000000007.

**Ввод.** В первой строке n. Затем n−1 строк с рёбрами. 1 ≤ n ≤ 100000.

**Вывод.** Количество подмножеств по модулю 1000000007.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
13
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
41
```
