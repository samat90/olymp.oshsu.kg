# Пары с заданным XOR

Сколько пар индексов $i < j$ таких, что $a_i \oplus a_j = x$ (побитовое исключающее ИЛИ)?

**Ввод.** В первой строке $n$ и $x$ ($1 \le n \le 2\cdot 10^5$, $0 \le x < 2^{30}$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{30}$).

**Вывод.** Количество пар.

### Пример 1

Ввод:
```
4 3
1 2 4 5
```

Вывод:
```
1
```
