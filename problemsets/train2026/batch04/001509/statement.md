Дан массив целых чисел. Нужно выполнить ровно $k$ операций: каждая меняет знак одного элемента на противоположный (один и тот же элемент можно менять несколько раз). Какой наибольшей может быть сумма элементов после этого?

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — массив.

## Формат вывода

Выведите максимальную сумму.

## Ограничения

$1 \le n \le 10^5$, $1 \le k \le 10^5$, $|a_i| \le 10^4$.

## Примеры

### Пример 1

Ввод:
```
4 1
3 -1 0 2
```
Вывод:
```
6
```

### Пример 2

Ввод:
```
3 3
2 -3 -1
```
Вывод:
```
4
```
