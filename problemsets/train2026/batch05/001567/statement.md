# Круг с карточками

`n` детей стоят по кругу (по часовой стрелке) и пронумерованы от 1 до `n`; у ребёнка `i` на карточке написано число `a_i ≠ 0`. Первым выбывает ребёнок 1. Если у выбывшего число `v > 0`, следующим выбывает ребёнок, до которого нужно отсчитать `v` детей по часовой стрелке, начиная с ближайшего оставшегося по часовой стрелке от выбывшего (для `v = 1` это он сам). Если `v < 0` - отсчитываем `|v|` детей против часовой стрелки, начиная с ближайшего оставшегося против часовой стрелки (для `v = -1` это он сам). В каком порядке дети покинут круг?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 2000`). Во второй строке `n` ненулевых целых чисел по модулю не больше 10^9.

## Выходные данные
Номера детей в порядке выбывания через пробел.

## Примеры

### Пример 1

Ввод:
```
4
3 -1 2 1
```

Вывод:
```
1 4 2 3
```

### Пример 2

Ввод:
```
3
1 1 1
```

Вывод:
```
1 2 3
```
