# Странный принтер

Принтер Мирлана за один ход печатает подряд одну и ту же букву на любом отрезке полоски, затирая то, что там было. Какое наименьшее число ходов нужно, чтобы напечатать заданное слово из строчных латинских букв?

**Ввод.** Слово длиной от 1 до 150.

**Вывод.** Наименьшее число ходов.

**Пример**

Ввод:
```
aaabbbaaa
```
Вывод:
```
2
```
