# Дешёвый путь по сетке

На поле n×m в каждой клетке написана цена прохода. Эрмек идёт из левой верхней клетки в правую нижнюю, шагая только вправо или вниз, и платит за каждую посещённую клетку (включая первую и последнюю). Какова наименьшая суммарная плата?

**Ввод.** В первой строке n и m (1 ≤ n, m ≤ 500), далее n строк по m чисел (0 ≤ a_ij ≤ 100).

**Вывод.** Наименьшая плата.

**Пример**

Ввод:
```
3 3
1 3 1
1 5 1
4 2 1
```
Вывод:
```
7
```
