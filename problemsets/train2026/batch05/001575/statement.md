# Заказы с дедлайнами

Мастерская в Узгене получила `n` заказов. На каждый уходит один день. У заказа `i` есть срок `d_i` (последний день, когда его можно выполнить; дни нумеруются с 1) и оплата `p_i`. В день выполняется не больше одного заказа. Какую наибольшую сумму можно заработать?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). В следующих `n` строках пары `d_i p_i` (`1 ≤ d_i ≤ 10^9`, `1 ≤ p_i ≤ 10^9`).

## Выходные данные
Максимальная суммарная оплата.

## Примеры

### Пример 1

Ввод:
```
4
2 100
1 19
2 27
1 25
```

Вывод:
```
127
```

### Пример 2

Ввод:
```
2
1 5
1 7
```

Вывод:
```
7
```
