У Тилека есть $n$ палочек. Сколько существует троек палочек (по номерам, порядок не важен), из которых можно сложить невырожденный треугольник?

## Формат ввода

В первой строке дано $n$. Во второй — длины палочек.

## Формат вывода

Выведите количество троек.

## Ограничения

$1 \le n \le 2000$, $1 \le a_i \le 10^6$.

## Примеры

### Пример 1

Ввод:
```
4
2 3 4 9
```
Вывод:
```
1
```

### Пример 2

Ввод:
```
3
1 1 3
```
Вывод:
```
0
```
