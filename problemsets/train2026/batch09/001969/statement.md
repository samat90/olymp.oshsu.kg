# Номер слова среди анаграмм

Все различные слова, получаемые перестановкой букв заданного слова, выписаны в алфавитном порядке и пронумерованы с единицы. Найдите номер заданного слова по модулю $10^9+7$.

**Ввод.** Слово из строчных латинских букв длиной от 1 до $10^5$.

**Вывод.** Номер слова по модулю $10^9+7$.

### Пример 1

Ввод:
```
bab
```

Вывод:
```
2
```
