# Почти поровну

Нурлан делит n камней весами a_i на две кучки (одна может оказаться пустой). Какова наименьшая возможная разница масс кучек?

**Ввод.** В первой строке n (1 ≤ n ≤ 100), во второй n чисел a_i (1 ≤ a_i ≤ 100).

**Вывод.** Наименьшая разность.

**Пример**

Ввод:
```
4
2 7 4 1
```
Вывод:
```
0
```
