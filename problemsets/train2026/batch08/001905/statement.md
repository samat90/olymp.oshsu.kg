# Лучший подотрезок

Дан массив из n чисел. Операции: «1 i x» — присвоить aᵢ = x; «2 l r» — среди непустых подотрезков отрезка [l, r] найти наибольшую сумму и вывести её.

**Ввод.** В первой строке n и q. Во второй — n чисел a₁…aₙ. Затем q строк с операциями. 1 ≤ n, q ≤ 60000, |aᵢ|, |x| ≤ 100. Операция типа 2 есть всегда.

**Вывод.** Ответ на каждую операцию типа 2 в отдельной строке.

## Примеры

**Ввод 1**
```
5 3
-2 3 -1 4 -5
2 1 5
1 3 -10
2 1 5
```
**Вывод 1**
```
6
4
```
