# Касса на рынке

На рынке в Оше работают `m` касс. Покупатель `i` приходит в момент `t_i` и обслуживается `d_i` минут. Покупателей обслуживают по порядку прихода; каждый идёт к кассе, которая освободится раньше всех (при равенстве - к кассе с меньшим номером), и начинает обслуживание в момент `max(t_i, освобождение кассы)`. Когда каждый закончит обслуживание?

## Входные данные
В первой строке числа `n` и `m` (`1 ≤ n ≤ 100000`, `1 ≤ m ≤ 100000`). В следующих `n` строках пары `t_i d_i` (`0 ≤ t_i ≤ 10^9`, `1 ≤ d_i ≤ 10^4`), `t_i` не убывают.

## Выходные данные
`n` чисел через пробел: моменты окончания обслуживания.

## Примеры

### Пример 1

Ввод:
```
3 2
0 5
1 2
2 2
```

Вывод:
```
5 3 5
```

### Пример 2

Ввод:
```
1 1
5 3
```

Вывод:
```
8
```
