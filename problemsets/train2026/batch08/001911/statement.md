# Присвоить на отрезке

Дан массив из n чисел. Операции: «1 l r x» — присвоить всем aₗ, …, aᵣ значение x; «2 l r» — вывести сумму aₗ + … + aᵣ.

**Ввод.** В первой строке n и q. Во второй — n чисел a₁…aₙ. Затем q строк с операциями. 1 ≤ n, q ≤ 40000, 0 ≤ aᵢ, x ≤ 1000. Операция типа 2 есть всегда.

**Вывод.** Ответ на каждую операцию типа 2 в отдельной строке.

## Примеры

**Ввод 1**
```
5 3
1 2 3 4 5
1 2 4 7
2 1 5
2 3 3
```
**Вывод 1**
```
27
7
```
