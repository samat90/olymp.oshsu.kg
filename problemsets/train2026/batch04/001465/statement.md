У Азамата есть $n$ товаров по цене $a_i$ в одном магазине и $m$ товаров по цене $b_j$ в другом. Найдите наименьшую разность цен между товаром из первого и товаром из второго магазина.

## Формат ввода

В первой строке даны $n$ и $m$. Во второй — $a_i$. В третьей — $b_j$.

## Формат вывода

Выведите минимальное значение $|a_i - b_j|$.

## Ограничения

$1 \le n, m \le 10^5$, $1 \le a_i, b_j \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
3 2
1 9 20
12 30
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
1 1
5 
5
```
Вывод:
```
0
```
