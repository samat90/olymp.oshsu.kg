# Сумма с изменениями

Дан массив из n чисел. Нужно обрабатывать операции: «1 i x» — присвоить aᵢ = x; «2 l r» — вывести сумму aₗ + … + aᵣ.

**Ввод.** В первой строке n и q. Во второй — n чисел a₁…aₙ. Затем q строк с операциями. 1 ≤ n, q ≤ 100000, 1 ≤ aᵢ, x ≤ 10⁹. Операция типа 2 есть всегда.

**Вывод.** Ответ на каждую операцию типа 2 в отдельной строке.

## Примеры

**Ввод 1**
```
5 4
1 2 3 4 5
2 1 5
1 3 10
2 2 4
2 3 3
```
**Вывод 1**
```
15
16
10
```
