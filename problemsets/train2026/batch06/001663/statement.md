# Чередование слов

Даны слова a, b и c. Можно ли получить c, перемешав буквы a и b так, что буквы каждого из слов идут в c в исходном порядке (но между ними могут вставляться буквы другого)?

**Ввод.** Три строки a, b, c из строчных латинских букв, длины от 1 до 1000.

**Вывод.** YES или NO.

**Пример**

Ввод:
```
aabcc
dbbca
aadbbcbcac
```
Вывод:
```
YES
```
