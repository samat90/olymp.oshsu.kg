Мастер Бекзат получил $n$ заказов. Каждый занимает ровно один день. У $i$-го заказа есть срок $d_i$ (его нужно сделать в один из дней $1 \ldots d_i$) и оплата $p_i$. В день можно выполнить один заказ. Какую наибольшую суммарную оплату он получит?

## Формат ввода

В первой строке дано $n$. Далее $n$ строк с парой $d_i$, $p_i$.

## Формат вывода

Выведите максимальную сумму.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le d_i \le n$, $1 \le p_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
4
2 50
1 20
2 30
3 10
```
Вывод:
```
90
```

### Пример 2

Ввод:
```
2
1 5
1 7
```
Вывод:
```
7
```
