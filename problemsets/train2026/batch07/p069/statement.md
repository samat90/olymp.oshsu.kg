# Ближайшая станция

В стране $n$ городов и $m$ двусторонних дорог с длинами. В $k$ городах есть станции скорой помощи. Для каждого города найдите расстояние до ближайшей станции.

**Ввод.** В первой строке $n, m, k$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$, $1 \le k \le n$). Во второй — номера $k$ городов со станциями. Далее $m$ строк $a\ b\ w$ ($1 \le w \le 10^6$).

**Вывод.** $n$ чисел через пробел; $-1$, если ни одной станции не достичь.

### Пример 1

**Ввод**
```
5 4 2
1 5
1 2 3
2 3 4
3 4 1
4 5 2
```

**Вывод**
```
0 3 3 2 0
```
