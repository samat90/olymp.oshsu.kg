# Начало цикла

Звенья цепочки пронумерованы от 1 до `n`. Для каждого звена задан номер следующего: `next_i`, где `0` означает конец цепочки. Начинаем с звена 1 и идём по ссылкам. Если путь уходит в цикл, выведите номер первого звена цикла (то есть первого звена, в которое мы попадём повторно), иначе `-1`.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` чисел `next_i` (`0 ≤ next_i ≤ n`).

## Выходные данные
Номер звена или `-1`.

## Примеры

### Пример 1

Ввод:
```
5
2 3 4 5 3
```

Вывод:
```
3
```

### Пример 2

Ввод:
```
3
2 3 0
```

Вывод:
```
-1
```
