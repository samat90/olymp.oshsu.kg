# Нули в конце факториала

Сколько нулей стоит в конце записи числа $n!$ в системе счисления с основанием $b$?

**Ввод.** Два числа $n$ и $b$ ($1 \le n \le 10^{18}$, $2 \le b \le 10^9$).

**Вывод.** Количество нулей.

### Пример 1

Ввод:
```
10 10
```

Вывод:
```
2
```

### Пример 2

Ввод:
```
10 8
```

Вывод:
```
2
```
