# Вода между столбами

После дождя в ущелье Сары-Челек вода скапливается между скальными столбами. Заданы высоты `n` соседних столбов шириной 1. Сколько единиц воды останется между ними? Вода не вытекает с краёв, если там нет более высокого столба.

**Ввод.** `n` (`1 ≤ n ≤ 10^5`) и `n` высот (`0 ≤ h ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
9
0 1 0 2 1 0 1 3 2
```

Вывод:
```
5
```
