# Размен монет

В кассе Асель есть m видов монет с номиналами c_1…c_m, каждого вида сколько угодно. Какое наименьшее число монет нужно, чтобы выдать ровно X сомов? Если нельзя — выведите −1.

**Ввод.** В первой строке m и X (1 ≤ m ≤ 20, 1 ≤ X ≤ 10^5), во второй m номиналов (1 ≤ c_i ≤ 10^5).

**Вывод.** Наименьшее число монет или −1.

**Пример**

Ввод:
```
3 11
1 2 5
```
Вывод:
```
3
```
