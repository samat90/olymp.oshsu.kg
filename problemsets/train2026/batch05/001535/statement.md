# Распаковка строки

Строку сжали по правилу: запись `k[S]` означает, что строка `S` повторена `k` раз. Записи могут быть вложенными. Определите длину исходной строки.

## Входные данные
Одна строка из строчных латинских букв, цифр и скобок `[` `]` длиной от 1 до 100000. Каждое число `k` от 1 до 99, запись корректна.

## Выходные данные
Длина распакованной строки по модулю 1000000007.

## Примеры

### Пример 1

Ввод:
```
3[ab]2[c]
```

Вывод:
```
8
```

### Пример 2

Ввод:
```
2[a3[bc]]d
```

Вывод:
```
15
```

### Пример 3

Ввод:
```
abc
```

Вывод:
```
3
```
