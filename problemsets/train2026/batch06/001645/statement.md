# Плитка два на n

Полоса 2×n выложена плиткой без пропусков и наложений. Есть плитки 1×2 (их можно класть любой стороной) и квадратные плитки 2×2. Сколькими способами можно выложить полосу?

**Ввод.** Число n (1 ≤ n ≤ 10^5).

**Вывод.** Число способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
3
```
Вывод:
```
5
```
