# Обходы по всем городам

В стране `n` городов и `m` двусторонних дорог. Сколько существует последовательностей городов, которые посещают каждый город ровно один раз, а соседние в последовательности города соединены дорогой? Последовательность и её запись в обратном порядке считаются разными.

**Ввод.** `n`, `m` (`1 ≤ n ≤ 14`, `0 ≤ m ≤ n(n-1)/2`) и `m` пар `u v` (без повторов).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3 2
1 2
2 3
```

Вывод:
```
2
```

## Пример 2

Ввод:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```

Вывод:
```
24
```
