# Подмножества с нулевым AND

Сколько существует непустых подмножеств индексов, для которых побитовое И выбранных чисел равно нулю? Ответ по модулю $10^9+7$.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{16}$).

**Вывод.** Количество подмножеств по модулю $10^9+7$.

### Пример 1

Ввод:
```
3
1 2 3
```

Вывод:
```
2
```
