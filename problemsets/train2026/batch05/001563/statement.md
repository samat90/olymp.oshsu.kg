# Билеты на концерт

В кассу Ошского драмтеатра стоит очередь из `n` человек. Человек `i` хочет купить `t_i` билетов. Каждый покупает по одному билету за секунду; если ему нужно ещё, он встаёт в конец очереди, иначе уходит. Через сколько секунд закончит покупку человек с номером `p`?

## Входные данные
В первой строке числа `n` и `p` (`1 ≤ p ≤ n ≤ 200000`). Во второй строке `n` чисел `t_i` (`1 ≤ t_i ≤ 10^9`).

## Выходные данные
Число секунд.

## Примеры

### Пример 1

Ввод:
```
3 2
2 3 2
```

Вывод:
```
7
```

### Пример 2

Ввод:
```
4 1
5 1 1 1
```

Вывод:
```
8
```
