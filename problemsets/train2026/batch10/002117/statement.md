# Наборы с заданной суммой

Нужно выбрать `k` различных чисел от 1 до 9 с суммой `n`. Выведите число таких наборов, а затем сами наборы: числа в каждом по возрастанию, наборы в лексикографическом порядке.

**Ввод.** `k` и `n` (`1 ≤ k ≤ 9`, `1 ≤ n ≤ 45`).

**Вывод.** Первая строка — число наборов, далее по набору в строке.

## Пример 1

Ввод:
```
3 7
```

Вывод:
```
1
1 2 4
```

## Пример 2

Ввод:
```
3 9
```

Вывод:
```
3
1 2 6
1 3 5
2 3 4
```
