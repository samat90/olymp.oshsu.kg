# Обратный обход из прямого

Дерево поиска из n различных чисел известно по прямому обходу (вершина, левое поддерево, правое поддерево). Выведите его обратный обход (левое поддерево, правое поддерево, вершина).

**Ввод.** В первой строке n, во второй — прямой обход. 1 ≤ n ≤ 100000.

**Вывод.** Обратный обход через пробел.

## Примеры

**Ввод 1**
```
5
4 2 1 3 6
```
**Вывод 1**
```
1 3 2 6 4
```

**Ввод 2**
```
3
1 2 3
```
**Вывод 2**
```
3 2 1
```
