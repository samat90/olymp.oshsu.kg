# Ближайший выход

План здания — таблица $h \times w$: `#` — стена, `.` — свободная клетка. Вы стоите в клетке $(r, c)$. Выходом считается свободная клетка на краю плана, отличная от начальной. Найдите наименьшее число ходов (по сторонам) до ближайшего выхода.

**Ввод.** В первой строке $h, w, r, c$ ($1 \le h\cdot w \le 3\cdot 10^5$), клетка $(r, c)$ свободна. Далее $h$ строк по $w$ символов.

**Вывод.** Число ходов или $-1$.

### Пример 1

**Ввод**
```
3 5 2 2
#.###
#.#.#
#...#
```

**Вывод**
```
1
```
