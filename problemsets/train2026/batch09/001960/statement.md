# Правильные скобки с началом

Сколько существует правильных скобочных последовательностей длины $2n$, которые начинаются с заданной строки $s$? Ответ по модулю $10^9+7$.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^6$), во второй — строка $s$ из скобок `(` и `)` длиной от 0 до $2n$ (пустая строка — пустая вторая строка).

**Вывод.** Количество последовательностей по модулю $10^9+7$.

### Пример 1

Ввод:
```
3
(
```

Вывод:
```
5
```

### Пример 2

Ввод:
```
2
)(
```

Вывод:
```
0
```
