# Острова в глубине

Карта $h \times w$: `#` — суша, `.` — вода. Остров — группа клеток суши, соседних по стороне. Остров называется внутренним, если ни одна его клетка не лежит на краю карты. Сколько на карте внутренних островов?

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 3\cdot 10^5$). Далее $h$ строк по $w$ символов.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5 6
######
#..#.#
#.##.#
#..#.#
######
```

**Вывод**
```
0
```
