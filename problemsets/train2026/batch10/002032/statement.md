# Площадь многоугольника

Простой многоугольник (без самопересечений) задан вершинами в порядке обхода (по или против часовой стрелки). Выведите его площадь, умноженную на 2.

**Ввод.** `n` (`3 ≤ n ≤ 10^5`) и `n` строк `x y` (`|x|, |y| ≤ 10^9`).

**Вывод.** Одно целое число.

## Пример 1

Ввод:
```
4
0 0
4 0
4 3
0 3
```

Вывод:
```
24
```

## Пример 2

Ввод:
```
3
0 0
5 1
2 7
```

Вывод:
```
33
```
