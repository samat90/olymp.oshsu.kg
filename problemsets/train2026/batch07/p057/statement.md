# Задержка сигнала

В сети $n$ узлов и $m$ направленных каналов $u \to v$ с задержкой $w$. Сигнал отправляют из узла $k$. Через какое время его получат все узлы? Если хотя бы один узел недостижим, выведите $-1$.

**Ввод.** В первой строке $n, m, k$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ строк $u\ v\ w$ ($1 \le w \le 10^6$, $u \ne v$, пары $(u,v)$ различны).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
4 4 2
2 1 1
2 3 1
3 4 1
4 1 7
```

**Вывод**
```
2
```
