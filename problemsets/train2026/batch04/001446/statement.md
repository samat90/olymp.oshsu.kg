Из $n$ учеников нужно выбрать команду из $k$ человек так, чтобы разница между самым высоким и самым низким в команде была как можно меньше. Найдите эту разницу.

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — рост учеников.

## Формат вывода

Выведите минимально возможную разницу.

## Ограничения

$1 \le k \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5 3
9 4 1 7 6
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
3 1
5 8 2
```
Вывод:
```
0
```
