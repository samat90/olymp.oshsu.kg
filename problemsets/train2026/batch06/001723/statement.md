# Торговля не более k раз

Известны цены на n дней. Нурлан может совершить не более k сделок: сделка — купить в один день и продать в более поздний. Одновременно держать больше одной меры нельзя. Какую наибольшую прибыль можно получить?

**Ввод.** В первой строке n и k (1 ≤ n ≤ 1000, 1 ≤ k ≤ 50), во второй n цен p_i (1 ≤ p_i ≤ 10^4).

**Вывод.** Наибольшая прибыль.

**Пример**

Ввод:
```
6 2
3 2 6 5 0 3
```
Вывод:
```
7
```
