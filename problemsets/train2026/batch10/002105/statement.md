# Система уравнений по модулю 2

Дана система из `n` линейных уравнений от `m` неизвестных над полем `{0, 1}` (сложение — XOR). Сколько у неё решений? Выведите ответ по модулю `10^9 + 7`.

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 300`), затем `n` строк: `m` символов-коэффициентов (`0`/`1`), пробел и свободный член `0` или `1`.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
2 2
11 0
01 1
```

Вывод:
```
1
```

## Пример 2

Ввод:
```
2 2
11 0
11 1
```

Вывод:
```
0
```
