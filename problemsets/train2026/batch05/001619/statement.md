# Сортировка через тупик

Вагоны с номерами `1, 2, ..., n` по очереди заезжают в тупик и ложатся сверху друг на друга. Из тупика в любой момент может выехать верхний вагон. Выехавшие вагоны образуют выходной порядок. Можно ли получить на выходе порядок вагонов, заданный перестановкой?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке перестановка чисел от 1 до `n` - желаемый порядок на выходе.

## Выходные данные
`YES` или `NO`.

## Примеры

### Пример 1

Ввод:
```
3
3 2 1
```

Вывод:
```
YES
```

### Пример 2

Ввод:
```
3
3 1 2
```

Вывод:
```
NO
```

### Пример 3

Ввод:
```
1
1
```

Вывод:
```
YES
```
