# Игра на маршрутах

В Таласской долине `n` перевалов, пронумерованных от 1 до `n`. Есть `m` односторонних дорог `u → v`, всегда `u < v`. Фишка стоит в перевале 1. Игроки по очереди двигают её по дороге. Первым ходит Айбек. Кто не может сделать ход, проиграл. Определите победителя.

**Ввод.** `n`, `m` (`1 ≤ n ≤ 10^5`, `0 ≤ m ≤ 2·10^5`) и `m` строк `u v`.

**Вывод.** `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
4 3
1 2
2 3
3 4
```

Вывод:
```
Айбек
```

## Пример 2

Ввод:
```
3 2
1 2
1 3
```

Вывод:
```
Айбек
```
