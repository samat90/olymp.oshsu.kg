# Следы робота

Робот-пылесос в Оше стартует в клетке `(0, 0)` и выполняет команды `U`, `D`, `L`, `R` (вверх, вниз, влево, вправо на одну клетку). Сколько различных клеток он посетил, считая стартовую?

**Ввод.** Строка из `n` команд (`1 ≤ n ≤ 10^6`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
RRULL
```

Вывод:
```
6
```

## Пример 2

Ввод:
```
UDUDUD
```

Вывод:
```
2
```
