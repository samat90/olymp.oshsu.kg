# Мосты

В стране $n$ городов и $m$ двусторонних дорог. Дорога называется мостом, если после её закрытия число групп связанных городов увеличивается. Выведите все мосты.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$ (различные, $a \ne b$).

**Вывод.** В первой строке — количество мостов $c$. Далее $c$ строк $a\ b$ ($a < b$), отсортированных по возрастанию $a$, затем $b$.

### Пример 1

**Ввод**
```
5 5
1 2
2 3
3 1
3 4
4 5
```

**Вывод**
```
2
3 4
4 5
```
