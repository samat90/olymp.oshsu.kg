# Убрать затенённые

Удалите из списка каждый элемент, правее которого есть строго больший элемент. Оставшиеся элементы сохраняют порядок.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
Оставшиеся элементы через пробел.

## Примеры

### Пример 1

Ввод:
```
5
5 2 13 3 8
```

Вывод:
```
13 8
```

### Пример 2

Ввод:
```
3
1 1 1
```

Вывод:
```
1 1 1
```
