# Непредставимая сумма

В Токмоке продают пирожки в пачках по $a$ и по $b$ штук (пачки нельзя вскрывать). Найдите наибольшее положительное количество пирожков, которое купить нельзя. Если таких количеств бесконечно много, выведите `-1`. Если нельзя купить только ноль пирожков (то есть любое положительное количество можно собрать), выведите `0`.

**Ввод.** Два числа $a$ и $b$ ($1 \le a, b \le 10^9$).

**Вывод.** Ответ.

### Пример 1

Ввод:
```
3 5
```

Вывод:
```
7
```

### Пример 2

Ввод:
```
4 6
```

Вывод:
```
-1
```

### Пример 3

Ввод:
```
1 7
```

Вывод:
```
0
```
