# Ограниченные слагаемые

Сколько существует наборов $(x_1, \dots, x_k)$ целых чисел от 0 до $m$ с суммой $n$? Наборы с разным порядком чисел считаются разными. Ответ по модулю $10^9+7$.

**Ввод.** Три числа $n$, $k$, $m$ ($1 \le n, k \le 10^6$, $0 \le m \le 10^6$).

**Вывод.** Количество наборов по модулю $10^9+7$.

### Пример 1

Ввод:
```
3 2 2
```

Вывод:
```
2
```
