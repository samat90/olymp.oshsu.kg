Есть $n$ верёвок длинами $a_i$. За одну операцию две верёвки связывают в одну, а стоимость операции равна сумме их длин. Свяжите все верёвки в одну с наименьшей общей стоимостью и выведите её.

## Формат ввода

В первой строке дано $n$. Во второй — длины.

## Формат вывода

Выведите минимальную общую стоимость (0, если верёвка одна).

## Ограничения

$1 \le n \le 10^5$, $1 \le a_i \le 10^4$.

## Примеры

### Пример 1

Ввод:
```
4
2 3 4 5
```
Вывод:
```
28
```

### Пример 2

Ввод:
```
1
9
```
Вывод:
```
0
```
