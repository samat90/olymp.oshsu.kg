# Единые термины интерфейса

Один термин на одно понятие, на сайте и в админке (русский язык).

| Понятие | Термин | Не использовать |
|---|---|---|
| Соревнование по задачам | олимпиада | соревнование, конкурс, контест |
| Человек с аккаунтом, в том числе тот, кто решает задачи в олимпиаде | пользователь | участник |
| Задача для решения | задача | проблема |
| Отправленное решение, которое проверяет судья | посылка | отправка, заявка, сдача, представление |
| Обращение в поддержку | тикет | заявка, обращение |
| Университет, школа, класс | организация | университеты и школы |

«Участие в олимпиаде» остаётся как название факта участия. «Решение» означает авторский разбор задачи, а не посылку.
Новые тексты пишутся по этой таблице; переводы лежат в `locale/*/LC_MESSAGES/django.po` и `scripts/dev/translations.json`.
