В турнире участвуют школьники из $n$ школ, из $i$-й школы пришло $a_i$ человек. В команде должно быть ровно $k$ человек из разных школ, а каждый школьник может играть не более чем в одной команде. Сколько команд можно составить?

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — $a_i$.

## Формат вывода

Выведите наибольшее число команд.

## Ограничения

$1 \le k \le n \le 10^5$, $1 \le a_i \le 10^9$ .

## Примеры

### Пример 1

Ввод:
```
4 2
3 1 2 2
```
Вывод:
```
4
```

### Пример 2

Ввод:
```
3 3
5 1 5
```
Вывод:
```
1
```
