# Дороги с поворотами

В графе $n$ вершин и $m$ двусторонних рёбер; вес каждого ребра — $0$ или $1$. Найдите наименьшую сумму весов пути из вершины $1$ в вершину $n$.

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ строк $a\ b\ w$, $w \in \{0, 1\}$.

**Вывод.** Одно число или $-1$.

### Пример 1

**Ввод**
```
4 4
1 2 1
2 4 0
1 3 0
3 4 1
```

**Вывод**
```
1
```
