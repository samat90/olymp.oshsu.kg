# Чередование цветов

В графе $n$ вершин. Даны красные и синие направленные рёбра (между парой вершин могут быть и красные, и синие рёбра, возможны петли). Для каждой вершины найдите длину кратчайшего пути из вершины $1$, в котором цвета рёбер строго чередуются (первое ребро любого цвета).

**Ввод.** В первой строке $n, r, b$ ($1 \le n \le 10^5$, $0 \le r, b \le 10^5$). Далее $r$ строк $a\ c$ — красные рёбра $a \to c$, затем $b$ строк — синие.

**Вывод.** $n$ чисел через пробел: длина пути или $-1$. Для вершины $1$ ответ $0$.

### Пример 1

**Ввод**
```
4 2 2
1 2
2 3
1 3
3 4
```

**Вывод**
```
0 1 1 -1
```
