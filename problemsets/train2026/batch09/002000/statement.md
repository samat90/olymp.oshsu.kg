# Пары (x, x XOR k) в пределах n

Сколько существует целых $x$ таких, что $0 \le x \le n$ и $0 \le x \oplus k \le n$ (здесь $\oplus$ — побитовое исключающее ИЛИ)?

**Ввод.** Два числа $n$ и $k$ ($0 \le n, k \le 10^{18}$).

**Вывод.** Количество чисел $x$.

### Пример 1

Ввод:
```
5 3
```

Вывод:
```
4
```
