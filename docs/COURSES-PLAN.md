# Раздел «Курсы» — план

Дата: 2026-11-20. Статус: реализовано одним релизом, итог в COURSES-REPORT.md.

## Идея
Платформа онлайн-курсов внутри olymp.oshsu.kg в духе Skillbox/Stepik: преподаватель собирает курс по любой дисциплине из модулей и уроков (видео YouTube, текст, задания, тесты, задачи сайта), слушатели записываются, проходят по порядку, видят прогресс; преподаватель видит успеваемость и проверяет работы. Всё на уже существующих аккаунтах, оргах, задачах и стиле сайта.

## Роли
- Пользователь: смотрит каталог, записывается, учится.
- Преподаватель: новое поле `Profile.is_teacher` (флажок, миграция 0185). Админ ставит его в карточке пользователя в админке и массовым действием «Сделать преподавателем / снять». Отдельное поле, а не `display_rank`: составитель задач может быть и преподавателем. На сайте рядом с именем маленький значок.
- Автор курса (преподаватель): создаёт, правит, удаляет только свои курсы; может добавить соавторов (этап 2).
- Админ/суперпользователь: полный CRUD всех курсов, скрыть курс (`is_hidden`).

## Модель данных (приложение judge, `judge/models/course.py`)
- `Course`: author, title, description (markdown), cover, subject (свободный текст как у Викторины), language (ru/ky/en), key (для ссылки), access (public / по ссылке / по организации), status (черновик / опубликован), is_hidden, is_deleted, created, updated, enrollments_count.
- `Module`: course, title, order.
- `Lesson`: module, order, title, type, content (markdown), youtube_id, data JSON (параметры), is_required, max_points. Типы:
  - `video` — вставка YouTube (по ссылке любого вида, хранится только id, плеер youtube-nocookie) + текст под ним;
  - `text` — статья с картинками, формулами (MathJax уже есть), кодом;
  - `test` — тест, автопроверка;
  - `assignment` — задание: ответ текстом и/или файлом, проверяет преподаватель, оценка + комментарий;
  - `problem` — существующая задача сайта (FK на Problem), зачёт по баллам посылок.
- `Enrollment`: course, profile, joined, completed_at, last_lesson.
- `LessonProgress`: enrollment, lesson, status (не начат / просмотрен / сдан / зачтён), score, completed_at.
- `TestQuestion`/`TestOption` — вопросы теста (одиночный/множественный выбор, верно/неверно, число, короткий текст). Редактор вопросов переиспользует код редактора Викторины (формы, картинки); можно импортировать вопросы из своей Викторины.
- `TestAttempt`: progress, ответы JSON, балл, время; настройки теста: число попыток, порог зачёта, перемешивание.
- `AssignmentSubmission`: progress, text, file, submitted, grade, comment, graded_by, graded_at.
- (этап 3) `Certificate`, `CourseComment` (вопросы к уроку).

Миграции только добавляют таблицы и одно поле. Данные сервера не трогаем.

## Страницы (URL /courses/…)
- `/courses/` — каталог: карточки, поиск, фильтр по дисциплине, бесконечная прокрутка (без номеров страниц, как везде).
- `/courses/<key>/` — страница курса: описание, программа (модули/уроки), автор, кнопка «Записаться».
- `/courses/<key>/learn/<lesson>/` — плеер: слева дерево модулей с галочками и полосой прогресса, в центре урок, внизу «Далее». Мобильная версия — дерево сворачивается.
- `/courses/my/` — «Я учусь» (с прогрессом, кнопка «Продолжить») и «Я преподаю».
- `/courses/<key>/edit/` — конструктор: модули/уроки, перетаскивание порядка, предпросмотр как слушатель, публикация.
- `/courses/<key>/students/` — таблица слушателей и прогресса, очередь проверки заданий, экспорт в Excel.
- Пункт «Курсы» в верхнем меню и плитка на главной.

## Админка
Раздел «Курсы» в переделанной админке: курсы, модули/уроки (inline), записи, сдачи заданий. Скрытие курса, отключатель раздела через ключ Misc config `courses_disabled` (как у Викторины). Флажок «Преподаватель» в пользователе + массовое действие.

## Технические правила
- Без WebSocket (прокси университета блокирует): всё обычный HTTP.
- Видео не хостим у себя, только YouTube-вставка; рядом всегда ссылка «Открыть на YouTube» на случай блокировки встраивания.
- Загрузки (файлы заданий, обложки) с лимитом размера и типов; хранение в media/courses/.
- Прогресс урока `video/text` — по кнопке «Изучено» (без слежки за плеером).
- Задача-урок засчитывается автоматически из таблицы посылок (порог по умолчанию 100/100; настраивается).
- Термины в `docs/GLOSSARY.md` (ru+ky): курс, модуль, урок, задание, тест, слушатель курса, преподаватель. Переводы ru/ky/en через gettext. Дизайн на modern.css, текст краткий, без пояснительных простыней.
- Тесты Django на модели, права доступа, подсчёт прогресса; CI должен оставаться зелёным.

## Этапы
**Этап 1 — основа и MVP (одним релизом):** `is_teacher` + админка; курс/модуль/урок; конструктор; уроки видео и текст; запись и прогресс; тесты с автопроверкой; урок-задача сайта; каталог, плеер, «Мои курсы»; админский CRUD; переводы.
**Этап 2 — проверка работ:** задания с файлами и ручной оценкой, очередь проверки, таблица успеваемости, экспорт Excel, соавторы, комментарии к урокам, поиск и теги.
**Этап 3 — рост:** сертификаты PDF с QR (как планировали дипломы), расписание открытия уроков и дедлайны, группы/потоки, уведомления (почта, позже Telegram), отзывы и оценка курса, шаблоны курсов/копирование, платные курсы (только если понадобится).

## Вопросы к Самату (предлагаю по умолчанию то, что в скобках)
1. Записываться могут все зарегистрированные пользователи; преподаватель может ограничить курс «по ссылке» или «только моя организация» (да).
2. Курсы бесплатные, оплаты нет (да).
3. Сертификат по завершении нужен в первом релизе или на этапе 3 (этап 3).
4. Новый курс публикуется преподавателем сам, без модерации админа; админ может скрыть (да).
