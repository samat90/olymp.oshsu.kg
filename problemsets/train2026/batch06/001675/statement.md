# Подмножества с суммой

Сколько существует подмножеств заданных n чисел (по позициям, пустое тоже считается), сумма которых равна ровно S?

**Ввод.** В первой строке n и S (1 ≤ n ≤ 200, 0 ≤ S ≤ 5000), во второй n чисел a_i (1 ≤ a_i ≤ 100).

**Вывод.** Число подмножеств по модулю 10^9 + 7.

**Пример**

Ввод:
```
4 5
1 2 3 2
```
Вывод:
```
3
```
