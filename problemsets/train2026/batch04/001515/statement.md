Ученики стоят в ряд, у каждого есть рост $a_i$. Тренер может увеличивать рост на 1 (поставив на подставку) любому ученику любое число раз. Какое наименьшее общее количество увеличений на 1 нужно, чтобы рост стал строго возрастающим слева направо?

## Формат ввода

В первой строке дано $n$. Во второй — рост.

## Формат вывода

Выведите минимальное число увеличений.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
4
1 1 2 1
```
Вывод:
```
5
```

### Пример 2

Ввод:
```
3
1 2 3
```
Вывод:
```
0
```
