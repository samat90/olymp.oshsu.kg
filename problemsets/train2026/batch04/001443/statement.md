Два слова называются анаграммами, если одно получается из другого перестановкой букв. Сколько групп попарно неанаграммных слов в списке? Иначе говоря, сколько различных слов получится, если считать анаграммы одним словом.

## Формат ввода

В первой строке дано $n$. В следующих $n$ строках — слова из букв a, b, c, d.

## Формат вывода

Выведите число различных классов анаграмм.

## Ограничения

$1 \le n \le 3 \cdot 10^4$, длина слова от 1 до 8.

## Примеры

### Пример 1

Ввод:
```
4
abc
cab
bad
da
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
2
aa
a
```
Вывод:
```
2
```
