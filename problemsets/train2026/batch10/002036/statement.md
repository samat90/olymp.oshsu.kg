# Квадраты на точках

Найдите число квадратов (с любым наклоном и ненулевой площадью), все четыре вершины которых входят в набор из `n` различных точек.

**Ввод.** `n` (`1 ≤ n ≤ 500`) и `n` строк `x y` (`|x|, |y| ≤ 1000`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
9
0 0
1 0
2 0
0 1
1 1
2 1
0 2
1 2
2 2
```

Вывод:
```
6
```
