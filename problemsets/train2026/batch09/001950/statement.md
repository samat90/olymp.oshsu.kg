# Маршруты между городами

В Кыргызстане $v$ городов, между некоторыми из них есть односторонние дороги. Сколько существует маршрутов ровно из $n$ дорог из города 1 в город $v$ (города и дороги можно посещать повторно)? Ответ по модулю $10^9+7$.

**Ввод.** В первой строке $v$ и $n$ ($1 \le v \le 6$, $1 \le n \le 10^{18}$). Далее $v$ строк по $v$ чисел: $g_{ij} = 1$, если есть дорога из $i$ в $j$, иначе 0.

**Вывод.** Количество маршрутов по модулю $10^9+7$.

### Пример 1

Ввод:
```
3 2
0 1 1
0 0 1
0 0 0
```

Вывод:
```
1
```
