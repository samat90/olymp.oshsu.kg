# Дружат ли

Есть n человек, сначала никто не дружит. Приходят q событий: «1 a b» — a и b подружились; «2 a b» — вопрос: связаны ли a и b цепочкой друзей (друг друга, друг друга и так далее)? Человек связан сам с собой.

**Ввод.** В первой строке n и q. Далее q строк с событиями. 1 ≤ n, q ≤ 100000. Вопросы есть всегда.

**Вывод.** На каждый вопрос YES или NO.

## Примеры

**Ввод 1**
```
4 4
1 1 2
2 1 3
1 2 3
2 1 3
```
**Вывод 1**
```
NO
YES
```
