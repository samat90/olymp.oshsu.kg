# Когда всё связано

Мосты между n островами строят в порядке перечисления. После какого по счёту моста впервые можно будет пройти между любыми двумя островами? Если это не случится, выведите −1. Если остров один, ответ 0.

**Ввод.** В первой строке n и m. В следующих m строках по два числа a, b — ребро между вершинами a и b (a ≠ b, кратные рёбра возможны). 1 ≤ n ≤ 100000, 0 ≤ m ≤ 250000.

**Вывод.** Номер моста, 0 или −1.

## Примеры

**Ввод 1**
```
4 4
1 2
1 2
3 4
2 3
```
**Вывод 1**
```
4
```

**Ввод 2**
```
3 1
1 2
```
**Вывод 2**
```
-1
```
