Список из $n$ различных чисел сначала отсортировали по возрастанию, а затем циклически сдвинули (первые несколько чисел переставили в конец). Найдите номер (с единицы) наименьшего числа.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ чисел.

## Формат вывода

Выведите номер наименьшего числа.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, числа различны, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5
6 7 1 3 4
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
3
1 2 3
```
Вывод:
```
1
```
