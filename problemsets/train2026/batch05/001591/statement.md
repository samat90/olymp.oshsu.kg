# С середины списка

Выведите список начиная со среднего элемента. Если элементов чётное число, средними считаются два, берётся второй из них.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел.

## Выходные данные
Элементы от среднего до последнего через пробел.

## Примеры

### Пример 1

Ввод:
```
5
1 2 3 4 5
```

Вывод:
```
3 4 5
```

### Пример 2

Ввод:
```
6
1 2 3 4 5 6
```

Вывод:
```
4 5 6
```
