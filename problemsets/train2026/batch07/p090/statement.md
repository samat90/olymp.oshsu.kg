# Самая большая независимая группа

Сеть из $n$ узлов — дерево. Выберите как можно больше узлов так, чтобы никакие два выбранных не были соединены дорогой. Сколько узлов можно выбрать?

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Далее $n-1$ строка с парами $a\ b$.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5
1 2
1 3
3 4
3 5
```

**Вывод**
```
3
```
