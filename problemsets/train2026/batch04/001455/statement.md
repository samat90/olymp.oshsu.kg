Дан отсортированный по неубыванию массив. Для каждого запроса $x$ определите, сколько раз $x$ встречается в массиве.

## Формат ввода

В первой строке даны $n$ и $q$. Во второй — массив $a$ (по неубыванию). В третьей — $q$ значений $x$.

## Формат вывода

Для каждого запроса выведите ответ через пробел.

## Ограничения

$1 \le n, q \le 2 \cdot 10^5$, $0 \le a_i, x \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
6 3
1 1 2 5 5 5
5 1 3
```
Вывод:
```
3 2 0
```

### Пример 2

Ввод:
```
2 1
4 9
0
```
Вывод:
```
0
```
