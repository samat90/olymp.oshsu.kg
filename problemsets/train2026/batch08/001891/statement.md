# Одинаковые буквы

Даны две строки A и B одинаковой длины из строчных латинских букв. Буквы A[i] и B[i] считаются равнозначными для каждого i, а равнозначность транзитивна (если a≡b и b≡c, то a≡c). Дана строка S. Замените в ней каждую букву на наименьшую по алфавиту равнозначную ей букву и выведите результат.

**Ввод.** Три строки: A, B, S. Длины A и B равны, 1 ≤ |A|, |S| ≤ 1000.

**Вывод.** Полученная строка.

## Примеры

**Ввод 1**
```
kgz
osh
zoo
```
**Вывод 1**
```
hkk
```

**Ввод 2**
```
abc
cde
edcba
```
**Вывод 2**
```
ababa
```
