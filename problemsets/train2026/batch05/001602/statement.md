# Где цепочки сходятся

Звенья пронумерованы от 1 до `n`, у каждого есть следующее звено `next_i` (`0` - конец). Две цепочки начинаются со звеньев `a` и `b`. Цепочки без циклов, но могут слиться в одну. Найдите номер первого общего звена.

## Входные данные
В первой строке число `n` (`2 ≤ n ≤ 200000`). Во второй строке `n` чисел `next_i`. В третьей строке числа `a` и `b`.

## Выходные данные
Номер первого общего звена или `-1`, если общих звеньев нет.

## Примеры

### Пример 1

Ввод:
```
5
3 3 4 5 0
1 2
```

Вывод:
```
3
```

### Пример 2

Ввод:
```
3
0 0 0
1 2
```

Вывод:
```
-1
```
