# Восстановить обратный обход

Двоичное дерево из n вершин с различными номерами от 1 до n известно по двум обходам: прямому и симметричному. Выведите его обратный обход.

**Ввод.** В первой строке n. Во второй — прямой обход, в третьей — симметричный. 1 ≤ n ≤ 100000.

**Вывод.** Обратный обход через пробел.

## Примеры

**Ввод 1**
```
5
1 2 4 3 5
4 2 1 3 5
```
**Вывод 1**
```
4 2 5 3 1
```

**Ввод 2**
```
1
1
1
```
**Вывод 2**
```
1
```
