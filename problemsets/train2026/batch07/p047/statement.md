# Безопасные площадки

В лагере $n$ площадок и $m$ односторонних троп. Площадка — тупик, если из неё не ведёт ни одна тропа. Площадка называется безопасной, если любой путь из неё (в том числе бесконечный) неизбежно заканчивается в тупике, то есть из неё нельзя дойти до цикла. Выведите количество безопасных площадок и сумму их номеров.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$.

**Вывод.** Два числа через пробел.

### Пример 1

**Ввод**
```
5 5
1 2
2 3
3 2
4 5
1 4
```

**Вывод**
```
2 9
```
