# Минимизировать наибольший XOR

Выберите целое $x \ge 0$ так, чтобы наибольшее из чисел $a_i \oplus x$ было как можно меньше. Выведите это наименьшее значение.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{30}$).

**Вывод.** Минимально возможное значение наибольшего XOR.

### Пример 1

Ввод:
```
3
1 2 3
```

Вывод:
```
2
```
