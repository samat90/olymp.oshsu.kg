Строку нужно разрезать на наибольшее возможное число частей так, чтобы каждая буква встречалась только в одной части. Выведите число частей и их длины слева направо.

## Формат ввода

Одна строка из строчных латинских букв.

## Формат вывода

В первой строке число частей, во второй — длины частей через пробел.

## Ограничения

Длина строки от 1 до $10^5$.

## Примеры

### Пример 1

Ввод:
```
abacdcefe
```
Вывод:
```
3
3 3 3
```

### Пример 2

Ввод:
```
aaaa
```
Вывод:
```
1
4
```
