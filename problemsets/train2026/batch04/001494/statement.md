В кассе есть неограниченно купюр и монет номиналом 1, 5, 10, 50, 100 и 500 сомов. Для каждой суммы найдите наименьшее число купюр и монет, которыми можно её выдать.

## Формат ввода

В первой строке дано $q$. Во второй — $q$ сумм.

## Формат вывода

Выведите ответы через пробел.

## Ограничения

$1 \le q \le 10^5$, $0 \le x \le 10^{18}$.

## Примеры

### Пример 1

Ввод:
```
3
0 7 1234
```
Вывод:
```
0 3 11
```

### Пример 2

Ввод:
```
1
499
```
Вывод:
```
14
```
