# Муравей Лэнгтона

Муравей стоит на бесконечном белом поле, лицом вверх. За шаг: если клетка белая — он поворачивает направо, красит её в чёрный и делает шаг вперёд; если чёрная — поворачивает налево, красит в белый и делает шаг вперёд. Сколько клеток будет чёрными после `k` шагов?

**Ввод.** `k` (`0 ≤ k ≤ 200000`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
0
```

Вывод:
```
0
```

## Пример 2

Ввод:
```
11
```

Вывод:
```
7
```
