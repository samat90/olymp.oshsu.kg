# Король на доске

Король стоит в левом верхнем углу доски (n+1)×(m+1) и должен попасть в правый нижний. За ход он идёт на клетку вправо, вниз или по диагонали вправо-вниз. Сколько существует маршрутов?

**Ввод.** Два числа n и m (1 ≤ n, m ≤ 1000).

**Вывод.** Число маршрутов по модулю 10^9 + 7.

**Пример**

Ввод:
```
2 2
```
Вывод:
```
13
```
