Автобус едет по $n$ перегонам длиной $a_i$ километров. Водитель может проехать подряд несколько перегонов, если их общая длина не больше $S$. Какое наибольшее число перегонов подряд он проедет?

## Формат ввода

В первой строке даны $n$ и $S$. Во второй — $a_i$.

## Формат вывода

Выведите наибольшее число подряд идущих перегонов (0, если ни один не подходит).

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^4$, $1 \le S \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5 6
2 3 1 2 4
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
2 1
5 6
```
Вывод:
```
0
```
