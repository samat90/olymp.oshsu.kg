# Перевёрнутые в скобках

Строка содержит строчные латинские буквы и правильно вложенные скобки. Начиная с самых внутренних, переверните подстроки в каждой паре скобок и уберите сами скобки. Выведите результат.

## Входные данные
Одна строка длиной от 1 до 200000.

## Выходные данные
Итоговая строка без скобок.

## Примеры

### Пример 1

Ввод:
```
(abc)
```

Вывод:
```
cba
```

### Пример 2

Ввод:
```
a(bc(de)f)g
```

Вывод:
```
afdecbg
```

### Пример 3

Ввод:
```
ab
```

Вывод:
```
ab
```
