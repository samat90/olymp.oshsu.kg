# Степень матрицы

Возведите квадратную матрицу `A` размера `n × n` в степень `k` по модулю `10^9 + 7`.

**Ввод.** `n` (`1 ≤ n ≤ 30`), `k` (`0 ≤ k ≤ 10^18`) и матрица (`0 ≤ a < 10^9+7`). `A^0` — единичная матрица.

**Вывод.** Матрица `A^k`.

## Пример 1

Ввод:
```
2 5
1 1
1 0
```

Вывод:
```
8 5
5 3
```
