# Полоса 2×n из плиток

Полоса `2 × n` замощается без пропусков и наложений плитками двух видов: доминошка `2 × 1` (в любой ориентации) и уголок из трёх клеток (в любом из четырёх поворотов). Сколькими способами? Ответ по модулю `10^9 + 7`.

**Ввод.** `n` (`1 ≤ n ≤ 10^6`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3
```

Вывод:
```
5
```

## Пример 2

Ввод:
```
4
```

Вывод:
```
11
```
