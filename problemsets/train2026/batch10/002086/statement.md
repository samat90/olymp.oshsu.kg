# Удалить цифры

Из записи числа нужно удалить ровно `k` цифр так, чтобы получилось как можно меньшее число. Ведущие нули в результате отбрасываются, если результат пуст — выведите `0`.

**Ввод.** Число `N` в виде строки (`1 ≤` длина `≤ 10^6`) и `k` (`0 ≤ k ≤` длина).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
1432219 3
```

Вывод:
```
1219
```

## Пример 2

Ввод:
```
10200 1
```

Вывод:
```
200
```
