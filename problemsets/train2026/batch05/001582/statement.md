# Корзины с яблоками

В `n` корзинах лежат яблоки. Каждую секунду Тилек берёт корзину, где яблок больше всего, и оставляет в ней только целую часть квадратного корня от прежнего числа яблок, остальные яблоки забирает. Сколько яблок останется в корзинах через `k` секунд?

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ n ≤ 200000`, `1 ≤ k ≤ 200000`). Во второй строке `n` целых чисел от 1 до 10^9.

## Выходные данные
Сумма яблок в корзинах после `k` секунд.

## Примеры

### Пример 1

Ввод:
```
4 3
25 64 9 4
```

Вывод:
```
20
```

### Пример 2

Ввод:
```
2 5
1 1
```

Вывод:
```
2
```
