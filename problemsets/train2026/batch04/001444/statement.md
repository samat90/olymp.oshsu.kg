У фирмы есть $n$ магазинов с оборотами $a_i$ и $n$ менеджеров с коэффициентами $b_j$. Каждый менеджер назначается ровно в один магазин, в каждом магазине ровно один менеджер. Прибыль равна сумме $a_i \cdot b_{p_i}$ по всем магазинам. Найдите наибольшую возможную прибыль.

## Формат ввода

В первой строке дано $n$. Во второй — $a_1 \ldots a_n$. В третьей — $b_1 \ldots b_n$.

## Формат вывода

Выведите максимальную прибыль.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i, b_i \le 10^6$.

## Примеры

### Пример 1

Ввод:
```
3
1 3 2
4 1 5
```
Вывод:
```
24
```

### Пример 2

Ввод:
```
2
10 1
1 10
```
Вывод:
```
101
```
