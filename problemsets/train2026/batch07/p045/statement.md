# Самая длинная цепочка

Задачи образуют ориентированный граф без циклов: стрелка $a \to b$ означает, что из задачи $a$ можно перейти к задаче $b$. Найдите наибольшее число стрелок в цепочке $a_1 \to a_2 \to \dots$.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$. Циклов нет.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5 5
1 2
2 3
1 3
3 4
5 4
```

**Вывод**
```
3
```
