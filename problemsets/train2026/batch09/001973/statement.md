# Браслеты

Из $n$ бусин $k$ цветов собирают браслет. Браслеты считаются одинаковыми, если один получается из другого поворотом или переворотом. Сколько различных браслетов? Ответ по модулю $10^9+7$.

**Ввод.** Два числа $n$ и $k$ ($1 \le n \le 10^6$, $1 \le k \le 10^9$).

**Вывод.** Количество браслетов по модулю $10^9+7$.

### Пример 1

Ввод:
```
4 2
```

Вывод:
```
6
```
