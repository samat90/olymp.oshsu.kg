# Игра на сумму

Числа от 1 до `m` лежат на столе. Игроки по очереди берут по одному числу (каждое можно взять один раз) и прибавляют к общей сумме. Кто первым довёл сумму до `T` или больше, выиграл. Айбек ходит первым. Известно, что сумма всех чисел не меньше `T`.

**Ввод.** Два числа `m` и `T` (`1 ≤ m ≤ 20`, `1 ≤ T ≤ m(m+1)/2`).

**Вывод.** `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
4 6
```

Вывод:
```
Айбек
```

## Пример 2

Ввод:
```
10 11
```

Вывод:
```
Бермет
```
