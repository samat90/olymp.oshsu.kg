# Рассадка без соседей

В вершинах дерева сидят ученики. Нужно выбрать как можно больше вершин так, чтобы никакие две выбранные не были соединены ребром. Сколько вершин можно выбрать?

**Ввод.** В первой строке n. Затем n−1 строк с рёбрами. 1 ≤ n ≤ 100000.

**Вывод.** Наибольшее число выбранных вершин.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
3
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
5
```
