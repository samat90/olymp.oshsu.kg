# Стрелки на улицах

Каждая клетка таблицы $h \times w$ содержит стрелку: $1$ — вправо, $2$ — влево, $3$ — вниз, $4$ — вверх. Из клетки можно перейти только в клетку, на которую указывает её стрелка (выйти за таблицу нельзя). Изменить стрелку в клетке стоит $1$ тугрик (один раз на клетку, изменять можно любые клетки). Какова наименьшая стоимость, чтобы существовал путь из левой верхней клетки в правую нижнюю?

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 10^5$). Далее $h$ строк по $w$ цифр.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
3 3
123
331
441
```

**Вывод**
```
2
```
