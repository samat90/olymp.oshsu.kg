# Поровну по группам

Нурзат хочет раздать n гирь весами a_i в k коробок так, чтобы в каждой коробке суммарный вес был одинаковым. Все гири должны быть розданы. Возможно ли это?

**Ввод.** В первой строке n и k (1 ≤ k ≤ n ≤ 14), во второй n чисел a_i (1 ≤ a_i ≤ 20).

**Вывод.** YES или NO.

**Пример**

Ввод:
```
5 2
4 3 2 3 4
```
Вывод:
```
YES
```
