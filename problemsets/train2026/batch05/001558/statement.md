# Шаблон 1-3-2

Проверьте, есть ли в массиве три элемента с позициями `i < j < k`, для которых `a[i] < a[k] < a[j]`.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
`YES`, если такая тройка есть, иначе `NO`.

## Примеры

### Пример 1

Ввод:
```
4
1 2 3 4
```

Вывод:
```
NO
```

### Пример 2

Ввод:
```
4
3 1 4 2
```

Вывод:
```
YES
```
