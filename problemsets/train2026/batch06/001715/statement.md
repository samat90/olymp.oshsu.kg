# Подземелье

Рыцарь Темир идёт по подземелью n×m из левой верхней клетки в правую нижнюю, шагая вправо или вниз. В клетке число: положительное лечит рыцаря, отрицательное наносит урон. Здоровье рыцаря должно всё время (после входа в каждую клетку, включая первую и последнюю) оставаться не меньше 1. Какое наименьшее начальное здоровье нужно?

**Ввод.** В первой строке n и m (1 ≤ n, m ≤ 500), далее n строк по m чисел (−100 ≤ a_ij ≤ 100).

**Вывод.** Наименьшее начальное здоровье.

**Пример**

Ввод:
```
2 3
-2 -3 3
-5 -10 1
```
Вывод:
```
6
```
