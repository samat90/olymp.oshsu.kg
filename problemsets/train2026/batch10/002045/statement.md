# Силуэт города

Вдоль улицы в Бишкеке стоят `n` домов-прямоугольников. Дом `i` занимает отрезок `[l, r)` по оси `x` и имеет высоту `h`. Выведите контур силуэта: вершины слева направо, в которых высота меняется. Для каждой вершины выводится `x` и новая высота. Последняя вершина имеет высоту 0. Соседние вершины с одинаковой высотой не выводятся.

**Ввод.** `n` (`1 ≤ n ≤ 10^5`) и `n` строк `l r h` (`0 ≤ l < r ≤ 10^9`, `1 ≤ h ≤ 10^9`).

**Вывод.** Число вершин `k`, затем `k` строк `x h`.

## Пример 1

Ввод:
```
3
1 5 3
2 4 5
6 8 2
```

Вывод:
```
6
1 3
2 5
4 3
5 0
6 2
8 0
```
