# Сколько префиксов

Дан список слов. Сколько различных непустых строк являются префиксом хотя бы одного из слов? Все слова состоят из строчных латинских букв.

**Ввод.** В первой строке n, затем n слов, по одному в строке. 1 ≤ n ≤ 20000, длина слова от 1 до 10.

**Вывод.** Число различных префиксов.

## Примеры

**Ввод 1**
```
3
abc
abd
b
```
**Вывод 1**
```
5
```

**Ввод 2**
```
2
aa
aa
```
**Вывод 2**
```
2
```
