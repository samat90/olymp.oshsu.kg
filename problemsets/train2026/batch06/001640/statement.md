# Последовательности монет

В кассе Нурзат m видов монет номиналов c_i, каждого вида сколько угодно. Сколькими способами можно выдать ровно X сомов, если порядок выдачи монет важен (последовательности 1+2 и 2+1 различны)?

**Ввод.** В первой строке m и X (1 ≤ m ≤ 20, 1 ≤ X ≤ 10^5), во второй m различных номиналов (1 ≤ c_i ≤ 10^5).

**Вывод.** Число способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
3 4
1 2 3
```
Вывод:
```
7
```
