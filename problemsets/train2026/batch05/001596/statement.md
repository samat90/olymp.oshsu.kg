# Сдвиг списка

Сдвиньте список вправо на `k` позиций: последние `k` элементов переходят в начало, порядок сохраняется.

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ n ≤ 200000`, `0 ≤ k ≤ 10^9`). Во второй строке `n` целых чисел.

## Выходные данные
Новый список через пробел.

## Примеры

### Пример 1

Ввод:
```
5 2
1 2 3 4 5
```

Вывод:
```
4 5 1 2 3
```

### Пример 2

Ввод:
```
3 4
7 8 9
```

Вывод:
```
9 7 8
```
