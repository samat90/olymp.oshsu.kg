# Следующее число с тем же числом единиц

Для каждого из $q$ чисел $x$ найдите наименьшее число, которое больше $x$ и имеет в двоичной записи столько же единиц.

**Ввод.** В первой строке $q$ ($1 \le q \le 1000$), далее $q$ чисел $x_i$ ($1 \le x_i \le 10^{18}$).

**Вывод.** $q$ чисел, по одному в строке.

### Пример 1

Ввод:
```
3
6
7
12
```

Вывод:
```
9
11
17
```
