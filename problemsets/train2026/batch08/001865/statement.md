# Путь до листа с суммой

В вершинах двоичного дерева записаны числа. Есть ли путь от корня до какого-нибудь листа, сумма чисел на котором равна S?

**Ввод.** В первой строке n и S. Во второй — n чисел, значения вершин 1…n (по модулю не больше 1000). Затем n строк: для вершины i — номера левого и правого сына (0, если нет). Корень — вершина 1. 1 ≤ n ≤ 100000.

**Вывод.** YES или NO.

## Примеры

**Ввод 1**
```
5 8
1 2 3 4 5
2 3
4 0
0 5
0 0
0 0
```
**Вывод 1**
```
NO
```

**Ввод 2**
```
3 100
1 2 3
2 3
0 0
0 0
```
**Вывод 2**
```
NO
```
