# Домино на плане

План пола — таблица $h \times w$: `.` — свободная клетка, `#` — занятая. Плитка домино закрывает две соседние по стороне свободные клетки. Какое наибольшее число плиток можно уложить без наложений?

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 400$). Далее $h$ строк по $w$ символов.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
3 4
..#.
....
.#..
```

**Вывод**
```
5
```
