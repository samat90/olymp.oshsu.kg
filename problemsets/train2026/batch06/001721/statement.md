# Покраска домов

Улицу из n домов красят в один из трёх цветов. Покраска дома i в цвет j стоит c_ij. Соседние дома должны быть разных цветов. Какова наименьшая суммарная стоимость?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), далее n строк по три числа c_i1, c_i2, c_i3 (1 ≤ c_ij ≤ 1000).

**Вывод.** Наименьшая стоимость.

**Пример**

Ввод:
```
3
17 2 17
16 16 5
14 3 19
```
Вывод:
```
10
```
