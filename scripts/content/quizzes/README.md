# Готовые викторины

Открытые викторины по школьным предметам (автор `samat1`). После каждой выкладки
`scripts/deploy.sh` запускает `manage.py load_quizzes`: викторины, которых ещё нет на сайте
(по ключу ссылки `/quiz/<ключ>/`), добавляются. Существующие и удалённые никогда не меняются.

Все картинки нарисованы своими силами (SVG → PNG), чужих изображений нет.

Пересобрать после правки вопросов: `python3 src/build.py <папка>` (нужен `cairosvg`).
Правка уже загруженной викторины делается в редакторе на сайте, не здесь.
