# Система счисления с основанием минус два

В системе с основанием $-2$ число записывается цифрами 0 и 1: $d_k \dots d_1 d_0$ означает $\sum d_i (-2)^i$. Запись без ведущих нулей единственна (для нуля — `0`). Запишите число $n$ в этой системе.

**Ввод.** Одно целое число $n$ ($-10^{18} \le n \le 10^{18}$).

**Вывод.** Запись числа.

### Пример 1

Ввод:
```
6
```

Вывод:
```
11010
```

### Пример 2

Ввод:
```
-3
```

Вывод:
```
1101
```
