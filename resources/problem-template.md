# Сумма двух чисел
Время: 1 с
Память: 256 МБ

Даны два целых числа `A` и `B`. Найдите их сумму.

## Входные данные

В одной строке записаны два целых числа `A` и `B` через пробел ($-10^9 \le A, B \le 10^9$).

## Выходные данные

Выведите одно число — сумму `A + B`.

## Пример 1

Ввод:
```
2 3
```

Вывод:
```
5
```

## Пример 2

Ввод:
```
-4 10
```

Вывод:
```
6
```

## Пояснение

Во втором примере $-4 + 10 = 6$.
