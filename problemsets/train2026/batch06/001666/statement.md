# Общий кусок двух слов

Найдите длину самой длинной строки, которая встречается в обоих словах как подстрока (подряд идущие буквы).

**Ввод.** Два слова по одному в строке, длиной от 1 до 2000, из строчных латинских букв.

**Вывод.** Длина.

**Пример**

Ввод:
```
abcdxyz
xyzabcd
```
Вывод:
```
4
```
