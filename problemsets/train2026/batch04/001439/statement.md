Чтобы массив стал отсортированным по неубыванию, разрешено один раз выбрать подряд идущий отрезок и отсортировать только его. Какова наименьшая возможная длина такого отрезка? Если массив уже отсортирован, ответ 0.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ целых чисел.

## Формат вывода

Выведите минимальную длину отрезка.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
6
1 2 6 4 5 7
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
3
1 2 3
```
Вывод:
```
0
```
