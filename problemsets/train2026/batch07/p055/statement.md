# Чётные и нечётные поездки

Из города $1$ выезжает автобус; он может ездить по $m$ двусторонним дорогам между $n$ городами (повторно тоже). Сколько городов, в которые можно приехать, проехав чётное число дорог (ноль тоже считается чётным числом), и сколько — проехав нечётное число дорог? Город может попасть в оба счёта.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$.

**Вывод.** Два числа через пробел: сначала для чётного, затем для нечётного числа дорог.

### Пример 1

**Ввод**
```
5 4
1 2
2 3
3 1
4 5
```

**Вывод**
```
3 3
```
