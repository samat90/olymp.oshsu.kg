# Карты в порядке возрастания

Колода из `n` различных карт лежит рубашкой вверх. Фокусник повторяет: открывает верхнюю карту и откладывает её, затем следующую верхнюю карту переносит вниз колоды (последняя оставшаяся карта просто открывается). Как нужно разложить данные карты сверху вниз, чтобы открывались они в порядке возрастания?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` различных целых чисел от 1 до 10^9.

## Выходные данные
Порядок карт в колоде сверху вниз через пробел.

## Примеры

### Пример 1

Ввод:
```
7
17 13 11 2 3 5 7
```

Вывод:
```
2 13 3 11 5 17 7
```

### Пример 2

Ввод:
```
1
4
```

Вывод:
```
4
```
