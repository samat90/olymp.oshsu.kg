# Одинаковые дни рождения

В группе $n$ человек, год состоит из $d$ дней, дни рождения независимы и равновероятны. Какова вероятность, что хотя бы у двух человек день рождения совпадает? Выведите вероятность в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Два числа $n$ и $d$ ($1 \le n \le 10^6$, $1 \le d \le 10^9$).

**Вывод.** Вероятность по модулю $10^9+7$.

### Пример 1

Ввод:
```
2 4
```

Вывод:
```
250000002
```
