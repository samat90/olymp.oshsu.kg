Мастер выписывает на табличке число из цифр от 1 до 9, цифра $d$ стоит $c_d$ сомов. Всего есть $B$ сомов. Какое наибольшее число можно выписать? Нули в числе не используются. Если нельзя написать ни одной цифры, выведите -1.

## Формат ввода

В первой строке дано $B$. Во второй — стоимости $c_1 \ldots c_9$.

## Формат вывода

Выведите наибольшее число.

## Ограничения

$0 \le B \le 2 \cdot 10^5$, $1 \le c_d \le 1000$.

## Примеры

### Пример 1

Ввод:
```
5
2 3 1 3 4 6 7 8 9
```
Вывод:
```
33333
```

### Пример 2

Ввод:
```
2
3 3 3 3 3 3 3 3 3
```
Вывод:
```
-1
```
