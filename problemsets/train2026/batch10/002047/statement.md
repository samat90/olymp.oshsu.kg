# Прямоугольник в гистограмме

Гистограмма состоит из `n` столбцов шириной 1. Найдите наибольшую площадь прямоугольника, который целиком помещается в гистограмму.

**Ввод.** `n` (`1 ≤ n ≤ 10^5`) и `n` высот (`0 ≤ h ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
6
2 1 5 6 2 3
```

Вывод:
```
10
```
