# Сумма двух квадратов

Сколькими способами число $n$ можно записать как $x^2 + y^2$ с целыми $x$ и $y$? Пары $(x, y)$ и $(y, x)$, а также знаки считаются разными (например, $1 = 1^2 + 0^2 = 0^2 + 1^2 = (-1)^2 + 0^2 = \dots$ — 4 способа).

**Ввод.** Одно число $n$ ($1 \le n \le 10^{12}$).

**Вывод.** Количество способов.

### Пример 1

Ввод:
```
5
```

Вывод:
```
8
```

### Пример 2

Ввод:
```
3
```

Вывод:
```
0
```
