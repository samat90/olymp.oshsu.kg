# Убрать все повторяющиеся

Список отсортирован по неубыванию. Удалите все числа, которые встречаются больше одного раза (вместе со всеми их копиями). Оставьте только числа, встречающиеся ровно один раз.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` чисел по неубыванию, по модулю не больше 10^9.

## Выходные данные
Оставшиеся числа через пробел или `ПУСТО`.

## Примеры

### Пример 1

Ввод:
```
6
1 2 3 3 4 4
```

Вывод:
```
1 2
```

### Пример 2

Ввод:
```
3
5 5 5
```

Вывод:
```
ПУСТО
```
