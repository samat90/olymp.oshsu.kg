# Готовые викторины

Открытые викторины по школьным предметам и по основам программирования (Python, C++, Java, C#,
JavaScript; автор `samat1`). После каждой выкладки
`scripts/deploy.sh` запускает `manage.py load_quizzes`: викторины, которых ещё нет на сайте
(по ключу ссылки `/quiz/<ключ>/`), добавляются. Существующие и удалённые никогда не меняются.

Картинки предметных викторин и викторин по программированию нарисованы своими силами (SVG → PNG).

50 тематических викторин (вопросы в `src/themed/`) используют свободные фотографии и рисунки
из Wikimedia Commons и Википедии (общественное достояние, CC0, CC BY, CC BY-SA, GFDL, FAL).
Автор и лицензия каждой картинки записаны в `<ключ>/credits.json` и выводятся в пояснении к вопросу.
Пересобрать: сначала `python3 src/themed/fetch_images.py <папка> [<папка для просмотра>] [ключ ...]`
(скачивает недостающие картинки, готовые пропускает), затем `python3 src/themed/build_themed.py <папка>`
(должно закончиться строкой «OK, 50 quizzes»). Ключ викторины — не длиннее 12 символов.

Пересобрать после правки вопросов: `python3 src/build.py <папка>` (нужен `cairosvg`).
Викторины по программированию собираются отдельно: `python3 src/build_prog.py <папка>`;
`python3 src/check_prog.py` запускает каждый пример кода (g++, javac, mcs, node) и сверяет вывод с верным ответом.
Правка уже загруженной викторины делается в редакторе на сайте, не здесь.
