# Куча из вставок

Двоичная куча с минимумом в корне хранится в массиве с номерами от 1: у элемента `i` дети `2i` и `2i+1`. При вставке число добавляется в конец, затем, пока оно меньше родителя, меняется с ним местами. Вставьте числа по очереди в пустую кучу и выведите массив кучи.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
Массив кучи через пробел.

## Примеры

### Пример 1

Ввод:
```
5
5 3 8 1 2
```

Вывод:
```
1 2 8 5 3
```

### Пример 2

Ввод:
```
3
1 2 3
```

Вывод:
```
1 2 3
```
