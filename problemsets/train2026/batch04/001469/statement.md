В списке $n$ слов. Для каждой приставки $p$ посчитайте, сколько слов начинаются с $p$ (слово равное $p$ тоже подходит).

## Формат ввода

В первой строке даны $n$ и $q$. Далее $n$ слов, затем $q$ приставок, по одному в строке.

## Формат вывода

Выведите ответы через пробел.

## Ограничения

$1 \le n, q \le 5 \cdot 10^4$, слова из букв a, b, c длиной от 1 до 8, приставки длиной от 1 до 3.

## Примеры

### Пример 1

Ввод:
```
4 2
ab
abc
b
ab
ab
c
```
Вывод:
```
3 0
```

### Пример 2

Ввод:
```
1 1
a
b
```
Вывод:
```
0
```
