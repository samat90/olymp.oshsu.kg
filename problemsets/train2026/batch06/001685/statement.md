# Лопни шарики

В ряд висит n шариков, на шарике i написано a_i. Лопая шарик i, Нурзат получает монеты: a_i, умноженное на число слева и число справа от него в текущем ряду (если соседа нет, считается 1). После лопания шарика соседи сближаются. Какое наибольшее число монет можно получить, лопнув все шарики?

**Ввод.** В первой строке n (1 ≤ n ≤ 150), во второй n чисел a_i (1 ≤ a_i ≤ 100).

**Вывод.** Наибольшее число монет.

**Пример**

Ввод:
```
4
3 1 5 8
```
Вывод:
```
167
```
