# Квадратные суммы

Из n чисел нужно составить ряд (перестановку) так, чтобы сумма каждых двух соседних была полным квадратом. Сколько существует таких перестановок? Числа с одинаковыми значениями, стоящие на разных местах, считаются разными.

**Ввод.** В первой строке n (1 ≤ n ≤ 12), во второй n чисел a_i (1 ≤ a_i ≤ 100).

**Вывод.** Количество перестановок.

**Пример**

Ввод:
```
3
1 17 8
```
Вывод:
```
2
```
