Команда должна сделать $n$ проектов подряд, по одному за раз. Проект $i$ занимает $t_i$ дней и должен быть готов к дню $d_i$ от начала работы. Опоздание проекта — число дней, на которое он готов позже срока (0, если не опоздал). Выберите порядок, при котором наибольшее опоздание минимально, и выведите его.

## Формат ввода

В первой строке дано $n$. Далее $n$ строк с парой $t_i$, $d_i$.

## Формат вывода

Выведите минимально возможное наибольшее опоздание.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le t_i \le 10^4$, $1 \le d_i \le 2 \cdot 10^9$.

## Примеры

### Пример 1

Ввод:
```
3
3 6
2 4
4 5
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
1
5 5
```
Вывод:
```
0
```
