# Вершины выпуклой оболочки

На плоскости отмечены `n` различных точек. Выведите число вершин их выпуклой оболочки. Точки, лежащие внутри оболочки или на её стороне, вершинами не считаются.

**Ввод.** `n` (`1 ≤ n ≤ 10^5`) и `n` строк `x y` (`|x|, |y| ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
5
0 0
4 0
4 4
0 4
2 2
```

Вывод:
```
4
```

## Пример 2

Ввод:
```
3
0 0
1 1
2 2
```

Вывод:
```
2
```
