# Факториал без простого множителя

Из каждого числа $1, 2, \dots, n$ вычеркнули все множители, равные простому числу $p$ (например, при $p = 3$ число 18 стало 2). Найдите произведение полученных чисел по модулю $p$.

**Ввод.** Два числа $n$ и $p$ ($1 \le n \le 10^{18}$, $2 \le p \le 10^6$, $p$ простое).

**Вывод.** Остаток от деления произведения на $p$.

### Пример 1

Ввод:
```
10 3
```

Вывод:
```
1
```
