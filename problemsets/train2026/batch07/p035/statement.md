# Самый длинный маршрут

Сеть дорог между $n$ сёлами — дерево (между любыми двумя сёлами ровно один путь без повторов). Найдите наибольшее расстояние между двумя сёлами, измеряя в дорогах.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Далее $n-1$ строка с парами $a\ b$.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
6
1 2
2 3
3 4
2 5
5 6
```

**Вывод**
```
4
```
