# Колодцы и трубы

В $n$ домах нужно обеспечить водой. В доме $i$ можно выкопать колодец за $w_i$. Кроме того, есть $m$ возможных труб между домами с ценой; дом получает воду, если в нём колодец или он соединён трубами с домом, где есть колодец. Найдите наименьшую суммарную стоимость, чтобы вода была в каждом доме.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Во второй — $n$ чисел $w_i$. Далее $m$ строк $a\ b\ c$ ($1 \le w_i, c \le 10^6$).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
3 3
1 5 4
1 2 2
2 3 3
1 3 6
```

**Вывод**
```
6
```
