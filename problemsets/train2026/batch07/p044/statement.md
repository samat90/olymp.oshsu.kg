# Семестры

Нужно пройти $n$ курсов; даны $m$ условий «курс $a$ должен быть пройден раньше курса $b$». За семестр можно пройти любое число курсов, для которых все нужные курсы пройдены в предыдущих семестрах. За какое наименьшее число семестров можно пройти всё?

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$.

**Вывод.** Число семестров или $-1$, если пройти все курсы нельзя.

### Пример 1

**Ввод**
```
5 4
1 3
2 3
3 4
3 5
```

**Вывод**
```
3
```
