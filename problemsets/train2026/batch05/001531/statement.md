# Глубина вложенности

Дана правильная скобочная последовательность из `(` и `)`. Найдите максимальную глубину вложенности скобок.

## Входные данные
Одна правильная скобочная последовательность длиной от 2 до 200000.

## Выходные данные
Одно число: максимальная глубина.

## Примеры

### Пример 1

Ввод:
```
(()(()))
```

Вывод:
```
3
```

### Пример 2

Ввод:
```
()()
```

Вывод:
```
1
```
