# Ровно по весу

Рюкзак нужно загрузить так, чтобы общий вес был равен W ровно. Есть n предметов, у предмета i вес w_i и ценность v_i, каждый можно взять не более одного раза. Какова наибольшая ценность при точном весе W? Если набрать точно W нельзя, выведите −1.

**Ввод.** В первой строке n и W (1 ≤ n ≤ 100, 1 ≤ W ≤ 10^4), далее n строк по два числа w_i и v_i (1 ≤ w_i ≤ 10^4, 1 ≤ v_i ≤ 1000).

**Вывод.** Наибольшая ценность или −1.

**Пример**

Ввод:
```
3 7
3 10
4 15
5 40
```
Вывод:
```
25
```
