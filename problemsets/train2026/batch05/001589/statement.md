# Развернуть кусок списка

Односвязный список содержит `n` чисел. Переверните участок списка с позиции `l` по позицию `r` включительно (позиции с единицы).

## Входные данные
В первой строке числа `n`, `l`, `r` (`1 ≤ l ≤ r ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
Список после изменения, числа через пробел.

## Примеры

### Пример 1

Ввод:
```
5 2 4
1 2 3 4 5
```

Вывод:
```
1 4 3 2 5
```

### Пример 2

Ввод:
```
3 1 3
7 8 9
```

Вывод:
```
9 8 7
```
