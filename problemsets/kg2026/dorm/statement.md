В новом общежитии Ошского государственного университета `n` свободных мест, и ровно `n` первокурсников ждут заселения. Студенты приехали из разных уголков страны — из Баткена, Нарына, Таласа, Каракола, — а места находятся в разных корпусах и на разных этажах.

Комендант Гульнара эже провела опрос и для каждого студента `i` и каждого места `j` оценила **неудобство** `c[i][j]`: сколько минут в день студент будет тратить на дорогу до своего факультета, с поправкой на этаж, соседей и пожелания. Некоторые сочетания недопустимы (например, места в женском блоке для юношей); они отмечены числом `-1`.

Нужно поселить всех студентов, каждого на отдельное место, так, чтобы суммарное неудобство было минимальным. Выведите это минимальное суммарное неудобство или `-1`, если поселить всех по правилам невозможно.

## Входные данные

В первой строке — целое число `n` (1 ≤ n ≤ 500).

В каждой из следующих `n` строк — по `n` целых чисел: `j`-е число `i`-й строки равно `c[i][j]` (0 ≤ c[i][j] ≤ 10⁶ или c[i][j] = −1).

## Выходные данные

Выведите одно целое число — минимальное суммарное неудобство или `-1`.
