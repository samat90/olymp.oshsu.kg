# Поиск с пропусками

Дан список слов (повторы возможны) и q шаблонов. В шаблоне точка «.» заменяет любую одну букву. Для каждого шаблона найдите, сколько слов списка ему соответствуют (длина слова должна совпадать с длиной шаблона). Все слова состоят из строчных латинских букв.

**Ввод.** В первой строке n и q. Затем n слов, затем q шаблонов, по одному в строке. 1 ≤ n ≤ 5000, 1 ≤ q ≤ 1000, длины от 1 до 8.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
4 3
osh
ish
ose
os
.sh
o..
...
```
**Вывод 1**
```
2
2
3
```
