# Сколько самых длинных подъёмов

Дан массив из n чисел. Сколько существует строго возрастающих подпоследовательностей наибольшей длины? Подпоследовательности считаются различными, если различны наборы индексов.

**Ввод.** В первой строке n (1 ≤ n ≤ 1500), во второй n чисел a_i (1 ≤ a_i ≤ 10^9).

**Вывод.** Количество по модулю 10^9 + 7.

**Пример**

Ввод:
```
6
1 3 5 4 7 2
```
Вывод:
```
2
```
