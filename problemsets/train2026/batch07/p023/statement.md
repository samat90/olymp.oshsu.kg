# Шар в лабиринте

Лабиринт — таблица $h \times w$: `.` — пусто, `#` — стена. Шар стартует в клетке $(x_1, y_1)$. За один бросок он выбирает одно из четырёх направлений и катится по пустым клеткам, пока не упрётся в стену или границу, и останавливается в последней клетке перед ней. Длина броска — число пройденных клеток. Найдите наименьшую суммарную длину бросков, после которых шар остановится в клетке $(x_2, y_2)$ (пролёт через клетку не считается остановкой).

**Ввод.** В первой строке $h, w, x_1, y_1, x_2, y_2$ ($1 \le h\cdot w \le 10^5$). Далее $h$ строк по $w$ символов. Обе клетки свободны.

**Вывод.** Число или $-1$. Если шар уже стоит в $(x_2, y_2)$, ответ $0$.

### Пример 1

**Ввод**
```
4 5 1 1 4 5
.....
.##..
..#..
.....
```

**Вывод**
```
7
```
