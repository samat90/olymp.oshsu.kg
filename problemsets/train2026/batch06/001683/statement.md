# Резка верёвки

Верёвку длиной n метров можно разрезать на целые куски. Кусок длиной i метров продаётся за p_i сомов. Какую наибольшую выручку можно получить, продав всю верёвку (можно не резать)?

**Ввод.** В первой строке n (1 ≤ n ≤ 2000), во второй n цен p_1…p_n (1 ≤ p_i ≤ 10^4).

**Вывод.** Наибольшая выручка.

**Пример**

Ввод:
```
5
2 5 7 8 10
```
Вывод:
```
12
```
