# Медиана потока

Числа поступают по одному. После каждого нового числа выведите медиану всех полученных чисел. Если чисел чётное количество, медианой считается меньшее из двух средних.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
`n` чисел через пробел.

## Примеры

### Пример 1

Ввод:
```
5
5 15 1 3 8
```

Вывод:
```
5 5 5 3 5
```

### Пример 2

Ввод:
```
2
4 4
```

Вывод:
```
4 4
```
