# Круговая улица

Дома Мирлана стоят по кругу: первый дом соседствует с последним. Как и раньше, если взять яблоки из дома, то из соседних домов брать нельзя. В доме i лежит a_i яблок. Какое наибольшее число яблок можно собрать?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (0 ≤ a_i ≤ 10^4).

**Вывод.** Наибольшая сумма.

**Пример**

Ввод:
```
4
3 2 9 4
```
Вывод:
```
12
```
