# Обмен соседей

Поменяйте местами каждые два соседних элемента: первый со вторым, третий с четвёртым и так далее. Если последний элемент без пары, он остаётся на месте.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел.

## Выходные данные
Новый список через пробел.

## Примеры

### Пример 1

Ввод:
```
4
1 2 3 4
```

Вывод:
```
2 1 4 3
```

### Пример 2

Ввод:
```
5
1 2 3 4 5
```

Вывод:
```
2 1 4 3 5
```
