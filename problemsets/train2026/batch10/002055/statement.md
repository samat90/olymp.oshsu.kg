# Числа по краям

В ряд выложены `n` карточек с числами. Эрмек и Чолпон по очереди забирают крайнюю карточку слева или справа, Эрмек первый. Каждый стремится набрать как можно больше очков. Выведите разность (сумма Эрмека минус сумма Чолпон) при оптимальной игре.

**Ввод.** `n` (`1 ≤ n ≤ 2000`) и числа `a_i` (`1 ≤ a_i ≤ 10^9`).

**Вывод.** Одно целое число.

## Пример 1

Ввод:
```
4
1 5 233 7
```

Вывод:
```
222
```

## Пример 2

Ввод:
```
3
3 9 1
```

Вывод:
```
-5
```
