# k-я перестановка

Все перестановки чисел `1…n` выписаны в лексикографическом порядке. Выведите перестановку с номером `k` (нумерация с 1).

**Ввод.** `n` (`1 ≤ n ≤ 20`) и `k` (`1 ≤ k ≤ n!`).

**Вывод.** `n` чисел через пробел.

## Пример 1

Ввод:
```
3 4
```

Вывод:
```
2 3 1
```

## Пример 2

Ввод:
```
4 24
```

Вывод:
```
4 3 2 1
```
