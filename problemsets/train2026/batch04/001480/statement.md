На джайлоо есть $n$ мест для юрт, они лежат на одной линии и заданы координатами. Нужно поставить $k$ юрт в разные места так, чтобы наименьшее расстояние между двумя юртами было как можно больше. Найдите это расстояние.

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — координаты мест.

## Формат вывода

Выведите наибольшее возможное наименьшее расстояние.

## Ограничения

$2 \le k \le n \le 10^5$, координаты различны, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5 3
1 2 8 4 9
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
2 2
5 6
```
Вывод:
```
1
```
