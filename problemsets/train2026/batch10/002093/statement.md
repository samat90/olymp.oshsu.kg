# Кратное из нулей и единиц

Найдите наименьшее положительное число, делящееся на `n`, в десятичной записи которого только цифры `0` и `1`.

**Ввод.** `n` (`1 ≤ n ≤ 10^5`).

**Вывод.** Это число (оно может быть длинным).

## Пример 1

Ввод:
```
3
```

Вывод:
```
111
```

## Пример 2

Ввод:
```
7
```

Вывод:
```
1001
```
