# Ранг пары городов

В стране $n$ городов и $m$ двусторонних дорог. Ранг пары различных городов — число дорог, выходящих хотя бы из одного из них (дорога между ними считается один раз). Найдите наибольший ранг среди всех пар городов.

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$ (различные, $a \ne b$).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5 5
1 2
2 3
2 4
3 4
4 5
```

**Вывод**
```
5
```
