# Размах всех подмассивов

Размах подмассива - это разность его максимума и минимума. Найдите сумму размахов всех непрерывных подмассивов.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел от 1 до 10^9.

## Выходные данные
Сумма по модулю 1000000007.

## Примеры

### Пример 1

Ввод:
```
3
1 3 2
```

Вывод:
```
5
```

### Пример 2

Ввод:
```
2
5 5
```

Вывод:
```
0
```
