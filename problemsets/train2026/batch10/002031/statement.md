# Точка и треугольник

Заданы невырожденный треугольник и несколько точек. Для каждой точки выведите `0`, если она вне треугольника, `1`, если строго внутри, и `2`, если лежит на границе.

**Ввод.** Первая строка: три вершины `x1 y1 x2 y2 x3 y3`. Вторая: `q` (`1 ≤ q ≤ 10^5`). Далее `q` строк с точками `x y`. Все координаты по модулю не больше `10^6`.

**Вывод.** `q` чисел, по одному в строке.

## Пример 1

Ввод:
```
0 0 10 0 0 10
4
1 1
5 5
11 0
-1 3
```

Вывод:
```
1
2
0
0
```
