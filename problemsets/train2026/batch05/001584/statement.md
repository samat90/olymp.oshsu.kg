# Ближайшие к центру

В Ош-Арене отмечены `n` точек на плоскости. Найдите `k` точек, ближайших к началу координат. Точки сравниваются по квадрату расстояния, при равенстве - по порядку во входных данных.

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ k ≤ n ≤ 200000`). Далее `n` строк `x_i y_i` (по модулю не больше 10^4).

## Выходные данные
Номера выбранных точек (с единицы) в порядке от ближней к дальней через пробел.

## Примеры

### Пример 1

Ввод:
```
4 2
1 3
-2 2
5 1
0 -1
```

Вывод:
```
4 2
```

### Пример 2

Ввод:
```
2 2
1 1
-1 -1
```

Вывод:
```
1 2
```
