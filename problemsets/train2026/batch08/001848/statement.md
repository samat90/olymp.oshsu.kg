# Пары танцоров

Рёбра дерева соединяют знакомых. Нужно составить как можно больше танцевальных пар из знакомых так, чтобы каждый участвовал не более чем в одной паре. Сколько пар можно составить?

**Ввод.** В первой строке n. Затем n−1 строк с рёбрами. 1 ≤ n ≤ 100000.

**Вывод.** Наибольшее число пар.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
2
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
2
```
