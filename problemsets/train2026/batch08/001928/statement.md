# Замена на корни

Дан набор «корней» и предложение. Каждое слово предложения, у которого есть корень в качестве начала, нужно заменить на самый короткий из таких корней. Остальные слова остаются без изменений. Все слова состоят из строчных латинских букв.

**Ввод.** В первой строке m и k. Во второй — m корней. В третьей — k слов предложения. 1 ≤ m, k ≤ 1000, длины от 1 до 8.

**Вывод.** Получившееся предложение.

## Примеры

**Ввод 1**
```
3 4
os ky kyr
oshsu kyrgyz bishkek osh
```
**Вывод 1**
```
os ky bishkek os
```
