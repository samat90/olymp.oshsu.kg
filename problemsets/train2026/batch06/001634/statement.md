# Дома Бермет

Бермет собирает яблоки в n домах вдоль улицы, в доме i лежит a_i яблок. Соседние дома соединены общей калиткой: если взять яблоки из дома, то из соседних домов брать нельзя. Какое наибольшее число яблок можно собрать?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (0 ≤ a_i ≤ 10^4).

**Вывод.** Наибольшая сумма.

**Пример**

Ввод:
```
5
2 7 9 3 1
```
Вывод:
```
12
```
