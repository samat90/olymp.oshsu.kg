# Подмножества с заданным XOR

Сколько существует подмножеств индексов (включая пустое), у которых побитовое исключающее ИЛИ выбранных чисел равно $x$? Ответ по модулю $10^9+7$.

**Ввод.** В первой строке $n$ и $x$ ($1 \le n \le 10^5$, $0 \le x < 2^{60}$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{60}$).

**Вывод.** Количество подмножеств по модулю $10^9+7$.

### Пример 1

Ввод:
```
3 3
1 2 3
```

Вывод:
```
2
```
