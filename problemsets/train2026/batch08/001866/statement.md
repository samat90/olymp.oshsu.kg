# Цепочки с суммой

В вершинах двоичного дерева записаны числа. Сколько существует нисходящих путей (от вершины к одному из её потомков, возможно, к ней самой), сумма чисел на которых равна S?

**Ввод.** В первой строке n и S. Во второй — n чисел, значения вершин 1…n (по модулю не больше 1000). Затем n строк: для вершины i — номера левого и правого сына (0, если нет). Корень — вершина 1. 1 ≤ n ≤ 100000.

**Вывод.** Количество путей.

## Примеры

**Ввод 1**
```
5 3
1 2 1 1 2
2 3
4 0
0 5
0 0
0 0
```
**Вывод 1**
```
3
```
