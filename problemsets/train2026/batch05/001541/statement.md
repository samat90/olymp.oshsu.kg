# Когда потеплеет

Бекзат записал температуру воздуха в Оше за `n` дней. Для каждого дня определите, через сколько дней будет теплее, чем в этот день.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел - температуры от -50 до 50.

## Выходные данные
`n` чисел через пробел: число дней до первого более тёплого дня или `0`, если такого дня нет.

## Примеры

### Пример 1

Ввод:
```
6
20 22 21 25 23 30
```

Вывод:
```
1 2 1 2 1 0
```

### Пример 2

Ввод:
```
3
30 20 10
```

Вывод:
```
0 0 0
```
