# Гости за круглым столом

За круглым столом $n$ мест, пронумерованных по кругу. Сколькими способами можно выбрать $k$ мест так, чтобы никакие два выбранных не были соседними? Ответ по модулю $10^9+7$.

**Ввод.** Два числа $n$ и $k$ ($3 \le n \le 10^6$, $0 \le k \le n$).

**Вывод.** Количество способов по модулю $10^9+7$.

### Пример 1

Ввод:
```
5 2
```

Вывод:
```
5
```
