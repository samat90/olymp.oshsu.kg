# Слова на приставку

Дан список слов (повторы возможны) и q запросов-приставок. Для каждой приставки найдите, сколько слов списка начинаются с неё. Все слова состоят из строчных латинских букв.

**Ввод.** В первой строке n и q. Затем n слов, затем q приставок, по одному в строке. 1 ≤ n, q ≤ 5000, длина слова и приставки от 1 до 10.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
4 3
abc
abd
b
ab
ab
a
c
```
**Вывод 1**
```
3
3
0
```
