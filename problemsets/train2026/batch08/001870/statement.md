# k-е по величине

Изначально множество чисел пусто. Выполняются q операций: «1 x» — добавить число x (его в множестве ещё нет), «2 k» — вывести k-е по возрастанию число множества (k не больше размера множества).

**Ввод.** В первой строке q, далее q строк с операциями. 1 ≤ q ≤ 100000, 1 ≤ x ≤ 10⁹. Запросов типа 2 хотя бы один.

**Вывод.** Ответ на каждый запрос типа 2 в отдельной строке.

## Примеры

**Ввод 1**
```
6
1 5
1 2
2 1
1 9
2 3
2 2
```
**Вывод 1**
```
2
9
5
```
