# Счёт скобок

Счёт правильной скобочной последовательности определяется так: `()` имеет счёт 1; запись `AB` имеет счёт, равный сумме счетов `A` и `B`; запись `(A)` имеет счёт, вдвое больший счёта `A`. Найдите счёт.

## Входные данные
Одна правильная скобочная последовательность длиной от 2 до 200000.

## Выходные данные
Счёт по модулю 1000000007.

## Примеры

### Пример 1

Ввод:
```
()
```

Вывод:
```
1
```

### Пример 2

Ввод:
```
(())
```

Вывод:
```
2
```

### Пример 3

Ввод:
```
()(())
```

Вывод:
```
3
```
