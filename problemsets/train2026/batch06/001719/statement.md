# Ходы коня

Конь стоит на клетке (r, c) доски n×n (строки и столбцы нумеруются с 1). Он делает ровно k ходов, ни разу не выходя за пределы доски. Сколько существует различных последовательностей ходов?

**Ввод.** Четыре числа n, r, c, k (1 ≤ n ≤ 30, 1 ≤ r, c ≤ n, 0 ≤ k ≤ 100).

**Вывод.** Число последовательностей по модулю 10^9 + 7.

**Пример**

Ввод:
```
3 1 1 2
```
Вывод:
```
4
```
