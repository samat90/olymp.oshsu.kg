# Числа вида 2^a 3^b 5^c

Числа, у которых в разложении на простые множители встречаются только 2, 3 и 5 (включая 1), записаны по возрастанию: 1, 2, 3, 4, 5, 6, 8, 9, 10, 12, ... Найдите $k$-е из них.

**Ввод.** Одно число $k$ ($1 \le k \le 5000$).

**Вывод.** Число.

### Пример 1

Ввод:
```
10
```

Вывод:
```
12
```
