# Период десятичной дроби

Дробь $a/b$ записана в виде десятичной дроби. Найдите длину предпериода (цифр после запятой до начала повторения) и длину периода. Если дробь конечная, длина периода равна 0.

**Ввод.** Два числа $a$ и $b$ ($1 \le a < b \le 10^9$).

**Вывод.** Два числа: длина предпериода и длина периода.

### Пример 1

Ввод:
```
1 6
```

Вывод:
```
1 1
```

### Пример 2

Ввод:
```
1 8
```

Вывод:
```
3 0
```

### Пример 3

Ввод:
```
1 7
```

Вывод:
```
0 6
```
