# Самый большой остров

Дана карта из $h$ строк и $w$ столбцов: `#` — суша, `.` — вода. Остров — группа клеток суши, соседних по стороне. Найдите площадь (число клеток) самого большого острова. Если суши нет, выведите $0$.

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 3\cdot 10^5$). Далее $h$ строк по $w$ символов.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
3 6
##.###
#..#.#
...#..
```

**Вывод**
```
6
```
