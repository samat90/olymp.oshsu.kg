# Выгодный круг

Между $n$ площадками $m$ односторонних переходов $a \to b$; проход по переходу стоит $w$ (может быть отрицательным — тогда вам платят). Существует ли замкнутый маршрут (начало и конец в одной площадке, возможно с повторами), суммарная стоимость которого отрицательна?

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 500$, $0 \le m \le 5000$). Далее $m$ строк $a\ b\ w$ ($|w| \le 10^4$).

**Вывод.** `YES` или `NO`.

### Пример 1

**Ввод**
```
4 5
1 2 3
2 3 -4
3 1 2
3 4 5
4 1 1
```

**Вывод**
```
NO
```
