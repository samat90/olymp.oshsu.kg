# k-е число в таблице

Дана квадратная таблица `n × n`, в которой числа не убывают по каждой строке и по каждому столбцу. Найдите `k`-е по величине снизу число среди всех `n²` чисел (повторы считаются отдельно).

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ n ≤ 500`, `1 ≤ k ≤ n²`). Далее `n` строк по `n` чисел от 0 до 10^9.

## Выходные данные
Искомое число.

## Примеры

### Пример 1

Ввод:
```
3 8
1 5 9
10 11 13
12 13 15
```

Вывод:
```
13
```

### Пример 2

Ввод:
```
1 1
7
```

Вывод:
```
7
```
