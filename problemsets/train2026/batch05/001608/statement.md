# Разбить на части

Разбейте список на `k` частей подряд идущих элементов так, чтобы размеры частей отличались не более чем на 1 и более ранние части были не короче поздних. Если элементов меньше, чем частей, последние части пустые.

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ n, k ≤ 100000`). Во второй строке `n` целых чисел.

## Выходные данные
`k` строк: элементы каждой части через пробел, для пустой части выведите `-`.

## Примеры

### Пример 1

Ввод:
```
7 3
1 2 3 4 5 6 7
```

Вывод:
```
1 2 3
4 5
6 7
```

### Пример 2

Ввод:
```
2 4
8 9
```

Вывод:
```
8
9
-
-
```
