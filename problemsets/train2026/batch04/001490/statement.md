На шоссе стоят $n$ остановок в целых точках. Можно построить не более $k$ новых остановок, тоже в целых точках. Какое наименьшее значение может принять наибольшее расстояние между соседними остановками?

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — координаты остановок по неубыванию.

## Формат вывода

Выведите минимальное возможное наибольшее расстояние (не меньше 1).

## Ограничения

$2 \le n \le 10^5$, $0 \le k \le 10^9$, $0 \le p_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
3 1
0 6 8
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
2 0
3 10
```
Вывод:
```
7
```
