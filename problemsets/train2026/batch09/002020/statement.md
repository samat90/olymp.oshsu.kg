# Простейшая дробь между двумя

Даны две дроби $a/b < c/d$. Найдите дробь $p/q$ с наименьшим знаменателем $q$, лежащую строго между ними. Если таких дробей с наименьшим $q$ несколько, выберите с наименьшим $p$.

**Ввод.** Четыре числа $a$, $b$, $c$, $d$ ($0 \le a$, $1 \le b, d \le 10^9$, $c \le 10^9$, $a/b < c/d$).

**Вывод.** Два числа $p$ и $q$.

### Пример 1

Ввод:
```
1 3 1 2
```

Вывод:
```
2 5
```
