Дана таблица из нулей и единиц. В каждой строке сначала идут нули, а затем единицы (любая из частей может быть пустой). Найдите строку с наибольшим числом единиц; если таких несколько, выведите самую верхнюю.

## Формат ввода

В первой строке даны $n$ и $m$. Далее $n$ строк по $m$ символов 0 или 1.

## Формат вывода

Выведите номер строки (с единицы).

## Ограничения

$1 \le n, m \le 1000$.

## Примеры

### Пример 1

Ввод:
```
3 4
0011
0111
0001
```
Вывод:
```
2
```

### Пример 2

Ввод:
```
2 2
00
00
```
Вывод:
```
1
```
