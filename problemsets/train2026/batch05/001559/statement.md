# Круг Жозефа

`n` школьников из Караколя встали по кругу и пронумерованы от 1 до `n` по часовой стрелке. Счёт начинается с первого: каждый `k`-й по счёту выбывает из круга, и счёт продолжается со следующего. Кто останется последним?

## Входные данные
Два числа `n` и `k` (`1 ≤ n ≤ 1000000`, `1 ≤ k ≤ 10^9`).

## Выходные данные
Номер оставшегося школьника.

## Примеры

### Пример 1

Ввод:
```
7 3
```

Вывод:
```
4
```

### Пример 2

Ввод:
```
1 5
```

Вывод:
```
1
```

### Пример 3

Ввод:
```
10 2
```

Вывод:
```
5
```
