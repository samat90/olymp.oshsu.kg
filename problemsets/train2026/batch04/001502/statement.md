Типография в Токмоке печатает $n$ заказов по очереди. Печать заказа $i$ занимает $t_i$ минут, а клиент платит штраф $w_i$ сомов за каждую минуту, прошедшую от начала работы до готовности его заказа. Выберите порядок печати с наименьшим общим штрафом и выведите этот штраф.

## Формат ввода

В первой строке дано $n$. Далее $n$ строк с парой $t_i$, $w_i$.

## Формат вывода

Выведите минимальный суммарный штраф.

## Ограничения

$1 \le n \le 10^5$, $1 \le t_i, w_i \le 10^4$.

## Примеры

### Пример 1

Ввод:
```
3
3 2
1 4
2 1
```
Вывод:
```
18
```

### Пример 2

Ввод:
```
1
5 5
```
Вывод:
```
25
```
