# Слияние строк

Даны строки `s` и `t`. Строится новая строка: на каждом шаге берётся первый символ одной из непустых строк и дописывается в конец результата. Выведите лексикографически наименьший результат.

**Ввод.** Две строки из строчных латинских букв, длины от 1 до 3000.

**Вывод.** Одна строка.

## Пример 1

Ввод:
```
ab
ac
```

Вывод:
```
aabc
```

## Пример 2

Ввод:
```
ba
b
```

Вывод:
```
bab
```
