# Цепочка слов

Слово x называется предшественником слова y, если y получается из x вставкой ровно одной буквы в любое место. Дан набор слов. Найдите длину самой длинной цепочки w_1, w_2, …, w_k из слов набора, где каждое слово — предшественник следующего.

**Ввод.** В первой строке n (1 ≤ n ≤ 1000), далее n различных слов из строчных латинских букв длиной от 1 до 16, по одному в строке.

**Вывод.** Наибольшая длина цепочки.

**Пример**

Ввод:
```
5
a
ba
bca
bda
bdca
```
Вывод:
```
4
```
