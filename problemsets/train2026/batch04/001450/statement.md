Посчитайте число пар индексов $i < j$, для которых $a_i > 2 \cdot a_j$.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ целых чисел.

## Формат вывода

Выведите количество таких пар.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5
9 3 4 1 2
```
Вывод:
```
6
```

### Пример 2

Ввод:
```
3
2 2 2
```
Вывод:
```
0
```
