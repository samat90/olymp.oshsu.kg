# Диагональный обход

Выведите элементы матрицы `n × m` обходом по диагоналям зигзагом: начать с левого верхнего элемента, затем двигаться вверх-вправо по диагонали до края, потом вниз-влево по следующей, и так далее.

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 500`) и матрица (`0 ≤ a ≤ 10^9`).

**Вывод.** `n·m` чисел через пробел.

## Пример 1

Ввод:
```
3 3
1 2 3
4 5 6
7 8 9
```

Вывод:
```
1 2 4 7 5 3 6 8 9
```

## Пример 2

Ввод:
```
2 3
1 2 3
4 5 6
```

Вывод:
```
1 2 4 5 3 6
```
