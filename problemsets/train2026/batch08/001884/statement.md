# Первый замкнутый мост

Мосты строят по одному. Назовём мост замыкающим, если острова, которые он соединяет, уже были связаны цепочкой построенных ранее мостов. Найдите номер первого замыкающего моста или выведите 0, если таких нет.

**Ввод.** В первой строке n и m. В следующих m строках по два числа a, b — ребро между вершинами a и b (a ≠ b, кратные рёбра возможны). 1 ≤ n ≤ 100000, 0 ≤ m ≤ 150000.

**Вывод.** Номер моста или 0.

## Примеры

**Ввод 1**
```
4 4
1 2
2 3
3 4
4 2
```
**Вывод 1**
```
4
```

**Ввод 2**
```
3 2
1 2
2 3
```
**Вывод 2**
```
0
```
