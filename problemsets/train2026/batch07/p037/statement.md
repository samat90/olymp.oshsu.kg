# Сумма расстояний

Сеть из $n$ узлов — дерево. Для каждого узла $i$ найдите сумму расстояний от него до всех остальных узлов.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Далее $n-1$ строка с парами $a\ b$.

**Вывод.** $n$ чисел через пробел.

### Пример 1

**Ввод**
```
5
1 2
1 3
3 4
3 5
```

**Вывод**
```
6 9 5 8 8
```
