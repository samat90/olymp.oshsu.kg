# Пары для танца

На танцевальном вечере $a$ юношей и $b$ девушек. Даны $m$ пар «юноша $i$ готов танцевать с девушкой $j$». Каждый танцует не более чем с одним партнёром. Какое наибольшее число танцующих пар можно составить?

**Ввод.** В первой строке $a, b, m$ ($1 \le a, b \le 300$, $0 \le m \le 5000$). Далее $m$ пар $i\ j$ (различные).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
3 3 5
1 1
1 2
2 1
3 1
3 3
```

**Вывод**
```
3
```
