# Время работы функций

Однопоточная программа вызывает функции с номерами от 0 до `n-1`. Журнал состоит из записей `id start t` (функция начала работу в начале секунды `t`) и `id end t` (функция закончила в конце секунды `t`). Функции могут вызывать друг друга, в том числе рекурсивно; пока работает вызванная функция, вызвавшая ждёт. Для каждой функции найдите, сколько секунд она работала сама, не считая времени вызванных ею функций (суммарно по всем вызовам).

## Входные данные
В первой строке числа `n` и `m` (`1 ≤ n ≤ 1000`, `2 ≤ m ≤ 200000`, `m` чётно) - число записей. Далее `m` строк журнала в порядке времени. Журнал корректен: `start` и `end` вложены правильно, секунды от 0 до 10^9.

## Выходные данные
`n` чисел через пробел.

## Примеры

### Пример 1

Ввод:
```
2 4
0 start 0
1 start 2
1 end 5
0 end 6
```

Вывод:
```
3 4
```
