# Дороги с ограничением

Между городами проложены дороги с шириной w. Для запроса «u v x» выясните, можно ли проехать из u в v, пользуясь только дорогами, ширина которых строго меньше x (грузовик может ехать только по узким дорогам). Из города в себя ехать можно всегда.

**Ввод.** В первой строке n, m, q. Затем m строк a b w, затем q строк u v x. 1 ≤ n ≤ 50000, 1 ≤ m, q ≤ 100000, 1 ≤ w ≤ 100, 1 ≤ x ≤ 101.

**Вывод.** На каждый запрос YES или NO.

## Примеры

**Ввод 1**
```
4 3 3
1 2 5
2 3 9
3 4 2
1 3 10
1 3 9
3 4 3
```
**Вывод 1**
```
YES
NO
YES
```
