# Поделить поровну

Айгерим и Бермет хотят разделить n камней весами a_i так, чтобы у каждой оказалась одинаковая суммарная масса. Все камни должны быть розданы. Возможно ли это?

**Ввод.** В первой строке n (1 ≤ n ≤ 100), во второй n чисел a_i (1 ≤ a_i ≤ 100).

**Вывод.** YES или NO.

**Пример**

Ввод:
```
4
1 5 11 5
```
Вывод:
```
YES
```
