# Стек с минимумом

Реализуйте стек целых чисел с командами:

- `push x` - положить число;
- `pop` - убрать верхнее число (ничего не выводится);
- `top` - вывести верхнее число;
- `min` - вывести наименьшее число в стеке.

Команды `pop`, `top`, `min` даются только при непустом стеке.

## Входные данные
В первой строке число команд `q` (`1 ≤ q ≤ 200000`), далее `q` строк. Числа `x` по модулю не больше 10^9.

## Выходные данные
Ответы на команды `top` и `min`, каждый в своей строке.

## Примеры

### Пример 1

Ввод:
```
6
push 5
push 2
min
pop
min
top
```

Вывод:
```
2
5
5
```
