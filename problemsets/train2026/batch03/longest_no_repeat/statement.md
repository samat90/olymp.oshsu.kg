# Без повторов

Тынчтык ищет в слове самый длинный участок подряд, в котором все буквы различны.

## Вход

Одна строка из строчных латинских букв, длина от 1 до 200000.

## Выход

Длина самого длинного участка без повторяющихся букв.

## Пример 1

**Вход**
```
abcabcbb
```

**Выход**
```
3
```

## Пример 2

**Вход**
```
bbbb
```

**Выход**
```
1
```
