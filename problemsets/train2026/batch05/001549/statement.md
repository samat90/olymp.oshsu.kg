# Кого видно в очереди

В очереди за билетами в Ала-Арче стоят `n` человек слева направо, рост у всех разный. Человек видит стоящего правее, если все люди между ними ниже обоих. Сколько людей видит каждый человек справа от себя?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` различных целых чисел - рост от 1 до 10^9.

## Выходные данные
`n` чисел через пробел - сколько людей видит каждый.

## Примеры

### Пример 1

Ввод:
```
6
10 6 8 5 11 9
```

Вывод:
```
3 1 2 1 1 0
```

### Пример 2

Ввод:
```
3
1 2 3
```

Вывод:
```
1 1 0
```
