# Рекорды цен

Известны цены на картофель на рынке за `n` дней. Для каждого дня найдите, сколько последних дней подряд (включая этот) цена не превышала цену этого дня.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел от 1 до 10^9.

## Выходные данные
`n` чисел через пробел.

## Примеры

### Пример 1

Ввод:
```
7
100 80 60 70 60 75 85
```

Вывод:
```
1 1 1 2 1 4 6
```

### Пример 2

Ввод:
```
3
5 5 5
```

Вывод:
```
1 2 3
```
