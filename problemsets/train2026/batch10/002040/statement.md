# Площадь объединения прямоугольников

Найдите площадь объединения `n` прямоугольников со сторонами, параллельными осям.

**Ввод.** `n` (`1 ≤ n ≤ 400`) и `n` строк `x1 y1 x2 y2` (`x1 < x2`, `y1 < y2`, `|·| ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
2
0 0 4 4
2 2 6 6
```

Вывод:
```
28
```
