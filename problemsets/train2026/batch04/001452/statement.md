Расставьте числа так: сначала все нечётные по возрастанию, затем все чётные по убыванию.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ целых неотрицательных чисел.

## Формат вывода

Выведите массив через пробел.

## Ограничения

$1 \le n \le 10^5$, $0 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
6
4 7 1 2 9 6
```
Вывод:
```
1 7 9 6 4 2
```

### Пример 2

Ввод:
```
2
8 8
```
Вывод:
```
8 8
```
