# Разрезать многоугольник

Выпуклый многоугольник имеет n вершин, в вершине i записано число v_i (вершины идут по кругу). Многоугольник разрезают диагоналями на треугольники (n−2 штуки). Стоимость треугольника равна произведению чисел в его трёх вершинах. Найдите наименьшую суммарную стоимость разрезания.

**Ввод.** В первой строке n (3 ≤ n ≤ 150), во второй n чисел v_i (1 ≤ v_i ≤ 100).

**Вывод.** Наименьшая суммарная стоимость.

**Пример**

Ввод:
```
4
1 3 1 4
```
Вывод:
```
7
```
