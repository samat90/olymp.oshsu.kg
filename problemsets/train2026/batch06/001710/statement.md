# Треугольник

Числа записаны треугольником из n строк (в строке i ровно i чисел). Начав с верхнего числа, нужно спуститься вниз, на каждом шаге переходя к одному из двух чисел, расположенных прямо под текущим (левому или правому). Какая наименьшая сумма встреченных чисел возможна?

**Ввод.** В первой строке n (1 ≤ n ≤ 500), далее n строк: в i-й строке i чисел (−100 ≤ a ≤ 100).

**Вывод.** Наименьшая сумма.

**Пример**

Ввод:
```
4
2
3 4
6 5 7
4 1 8 3
```
Вывод:
```
11
```
