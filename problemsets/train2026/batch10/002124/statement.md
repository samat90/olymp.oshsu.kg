# Знаки между цифрами

Дана строка из `n` цифр. Между соседними цифрами можно поставить `+`, `-`, `*` или ничего (тогда цифры склеиваются в одно число). Числа с ведущими нулями, кроме самого `0`, запрещены. Умножение выполняется раньше сложения и вычитания. Сколько способов получить значение `T`?

**Ввод.** Строка цифр (`1 ≤ n ≤ 9`) и число `T` (`|T| ≤ 10^9`) во второй строке.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
123
6
```

Вывод:
```
2
```

## Пример 2

Ввод:
```
105
5
```

Вывод:
```
2
```
