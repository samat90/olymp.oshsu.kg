# Ожидаемое число инверсий

Перестановка чисел $1, \dots, n$ выбирается случайно (все перестановки равновероятны). Инверсия — пара позиций $i < j$, на которых $a_i > a_j$. Найдите математическое ожидание числа инверсий в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Одно число $n$ ($1 \le n \le 10^{18}$).

**Вывод.** Ответ по модулю $10^9+7$.

### Пример 1

Ввод:
```
3
```

Вывод:
```
500000005
```
