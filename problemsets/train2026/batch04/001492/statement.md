Улитка ползёт на вершину высотой $h$ метров. За день она поднимается на $a$ метров, за ночь соскальзывает на $b$ метров ($b < a$). На какой по счёту день она окажется на вершине? Улитка достигла вершины, если в какой-то момент дня высота не меньше $h$.

## Формат ввода

В первой строке дано $q$ — число запросов. Далее $q$ строк по три числа $a$, $b$, $h$.

## Формат вывода

Для каждого запроса выведите номер дня, ответы через пробел.

## Ограничения

$1 \le q \le 10^5$, $1 \le b < a \le 10^9$, $1 \le h \le 3 \cdot 10^9$.

## Примеры

### Пример 1

Ввод:
```
2
5 2 12
3 1 3
```
Вывод:
```
4 1
```

### Пример 2

Ввод:
```
1
2 1 10
```
Вывод:
```
9
```
