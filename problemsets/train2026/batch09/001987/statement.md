# Наибольший XOR подмножества

Выберите любое (возможно, пустое) подмножество чисел так, чтобы их побитовое исключающее ИЛИ было максимальным. Выведите это максимальное значение.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{60}$).

**Вывод.** Максимальный XOR.

### Пример 1

Ввод:
```
3
5 6 9
```

Вывод:
```
15
```
