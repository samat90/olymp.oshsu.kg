# Разрезание на палиндромы

Строку нужно разрезать на части так, чтобы каждая часть была палиндромом. Каким наименьшим числом разрезов это можно сделать?

**Ввод.** Строка из строчных латинских букв длиной от 1 до 2000.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
aab
```

Вывод:
```
1
```

## Пример 2

Ввод:
```
abcba
```

Вывод:
```
0
```
