# Ним

Айбек и Бермет играют в ним. На столе `n` куч камней. Игроки ходят по очереди, Айбек первый. За ход нужно взять любое положительное число камней из одной кучи. Кто не может сделать ход, проиграл. Кто выигрывает при оптимальной игре?

**Ввод.** `n` (`1 ≤ n ≤ 10^5`) и размеры куч `a_i` (`0 ≤ a_i ≤ 10^9`).

**Вывод.** Имя победителя: `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
3
1 2 3
```

Вывод:
```
Бермет
```

## Пример 2

Ввод:
```
2
4 7
```

Вывод:
```
Айбек
```
