# Слова внутри слова

Дан словарь и q строк-запросов. Для каждого запроса найдите, сколько различных слов словаря являются началом (префиксом) этой строки, включая саму строку. Все слова состоят из строчных латинских букв.

**Ввод.** В первой строке n и q. Затем n слов словаря, затем q запросов, по одному в строке. 1 ≤ n, q ≤ 10000, длины от 1 до 12.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
3 3
a
ab
abc
abcd
b
ab
```
**Вывод 1**
```
3
0
2
```
