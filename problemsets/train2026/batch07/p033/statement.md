# Равенства и неравенства

Даны $n$ переменных и $q$ условий вида `a = b` или `a != b`. Можно ли присвоить переменным числа так, чтобы все условия выполнились?

**Ввод.** В первой строке $n$ и $q$ ($1 \le n \le 10^5$, $1 \le q \le 2\cdot 10^5$). Далее $q$ строк: `a = b` или `a != b` ($1 \le a, b \le n$).

**Вывод.** `YES` или `NO`.

### Пример 1

**Ввод**
```
4 4
1 = 2
2 = 3
3 != 4
1 != 3
```

**Вывод**
```
NO
```
