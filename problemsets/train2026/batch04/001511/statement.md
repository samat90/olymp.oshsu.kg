Выберите из массива три разных элемента (по номерам) так, чтобы их произведение было наибольшим.

## Формат ввода

В первой строке дано $n$. Во второй — массив.

## Формат вывода

Выведите максимальное произведение.

## Ограничения

$3 \le n \le 2 \cdot 10^5$, $|a_i| \le 10^6$.

## Примеры

### Пример 1

Ввод:
```
5
-5 -4 1 2 3
```
Вывод:
```
60
```

### Пример 2

Ввод:
```
3
-1 -2 -3
```
Вывод:
```
-6
```
