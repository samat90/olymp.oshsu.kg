# Приём в поликлинике

В поликлинике Оша пациентов принимают по срочности. Команды:

- `come name p` - пришёл пациент с именем `name` и срочностью `p`;
- `next` - вызвать пациента: выводится имя пациента с наибольшей срочностью, а при равной срочности того, кто пришёл раньше. Если никого нет, вывести `-`.

## Входные данные
В первой строке число команд `q` (`1 ≤ q ≤ 200000`), далее `q` строк. Имена - слова из латинских букв, `1 ≤ p ≤ 10^9`.

## Выходные данные
Результаты команд `next`, каждый в своей строке.

## Примеры

### Пример 1

Ввод:
```
5
come Aigul 2
come Bakyt 5
come Cholpon 5
next
next
```

Вывод:
```
Bakyt
Cholpon
```
