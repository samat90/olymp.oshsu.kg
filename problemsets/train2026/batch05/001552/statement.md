# Спокойный участок

Даны высоты точек вдоль тропы в Сары-Челеке. Участок тропы считается спокойным, если разность самой высокой и самой низкой точки на нём не больше `L`. Найдите наибольшее число подряд идущих точек, образующих спокойный участок.

## Входные данные
В первой строке числа `n` и `L` (`1 ≤ n ≤ 200000`, `0 ≤ L ≤ 10^9`). Во второй строке `n` целых чисел от 0 до 10^9.

## Выходные данные
Длина наибольшего спокойного участка.

## Примеры

### Пример 1

Ввод:
```
6 3
8 2 4 7 5 6
```

Вывод:
```
4
```

### Пример 2

Ввод:
```
3 0
1 1 2
```

Вывод:
```
2
```
