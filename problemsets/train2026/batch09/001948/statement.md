# Сумма геометрической прогрессии

Найдите $1 + a + a^2 + \dots + a^{n-1}$ по модулю $m$. Модуль $m$ может быть составным.

**Ввод.** Три числа $a$, $n$, $m$ ($1 \le a \le 10^9$, $1 \le n \le 10^{18}$, $1 \le m \le 10^9$).

**Вывод.** Остаток от деления суммы на $m$.

### Пример 1

Ввод:
```
2 5 100
```

Вывод:
```
31
```
