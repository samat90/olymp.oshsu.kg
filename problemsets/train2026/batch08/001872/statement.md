# Это дерево поиска?

Дано двоичное дерево с числами в вершинах. Является ли оно деревом поиска, то есть для каждой вершины все числа в левом поддереве строго меньше её числа, а в правом — строго больше?

**Ввод.** В первой строке n. Во второй — n чисел, значения вершин 1…n. Затем n строк: для вершины i — номера левого и правого сына (0, если нет). Корень — вершина 1. 1 ≤ n ≤ 100000, значения по модулю до 10⁹.

**Вывод.** YES или NO.

## Примеры

**Ввод 1**
```
3
2 1 3
2 3
0 0
0 0
```
**Вывод 1**
```
YES
```

**Ввод 2**
```
3
2 3 1
2 3
0 0
0 0
```
**Вывод 2**
```
NO
```
