# Путь с минимальной суммой

Из левого верхнего угла таблицы нужно дойти в правый нижний, двигаясь только вправо или вниз. Найдите наименьшую возможную сумму чисел на пути (включая обе угловые клетки).

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 1000`) и таблица (`0 ≤ a ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3 3
1 3 1
1 5 1
4 2 1
```

Вывод:
```
7
```
