# Закрытые озёра

Карта $h \times w$: `#` — суша, `.` — вода. Озеро — группа водных клеток, соседних по стороне. Озеро считается внутренним, если ни одна его клетка не лежит на краю карты. Найдите общую площадь внутренних озёр.

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 3\cdot 10^5$). Далее $h$ строк по $w$ символов.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5 6
.#####
#..#.#
#.##.#
#...##
.#####
```

**Вывод**
```
8
```
