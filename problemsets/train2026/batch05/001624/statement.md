# Максимум блоков

Массив нужно разрезать на наибольшее число подряд идущих блоков так, чтобы после сортировки каждого блока по отдельности и склейки блоков в прежнем порядке получился полностью отсортированный по неубыванию массив. На сколько блоков можно разрезать?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
Наибольшее число блоков.

## Примеры

### Пример 1

Ввод:
```
5
5 4 3 2 1
```

Вывод:
```
1
```

### Пример 2

Ввод:
```
5
2 1 3 4 4
```

Вывод:
```
4
```

### Пример 3

Ввод:
```
3
1 1 1
```

Вывод:
```
3
```
