# Сумма на кубиках

Бросают $n$ правильных кубиков, у каждого $f$ граней с числами от 1 до $f$. Какова вероятность, что сумма выпавших чисел равна $s$? Выведите вероятность в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Три числа $n$, $f$, $s$ ($1 \le n, f \le 100$, $1 \le s \le 10^4$).

**Вывод.** Вероятность по модулю $10^9+7$.

### Пример 1

Ввод:
```
2 6 7
```

Вывод:
```
166666668
```
