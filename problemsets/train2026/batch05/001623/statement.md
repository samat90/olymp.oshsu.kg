# Атомы в формуле

Химическая формула состоит из символов элементов (заглавная латинская буква и, возможно, строчная), чисел и скобок. Число после элемента или закрывающей скобки - множитель (если числа нет, множитель 1). Подсчитайте, сколько атомов каждого элемента в формуле.

## Входные данные
Одна строка длиной от 1 до 100000, формула корректна, числа от 2 до 9, итоговые количества не больше 10^9.

## Выходные данные
Элементы по алфавиту; после каждого записано количество, если оно больше 1. Всё в одной строке без пробелов.

## Примеры

### Пример 1

Ввод:
```
K4(ON(SO3)2)2
```

Вывод:
```
K4N2O14S4
```

### Пример 2

Ввод:
```
H2O
```

Вывод:
```
H2O
```

### Пример 3

Ввод:
```
Mg(OH)2
```

Вывод:
```
H2MgO2
```
