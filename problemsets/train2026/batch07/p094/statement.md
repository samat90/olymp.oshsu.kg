# Самый удалённый от суши

Карта $h \times w$: `#` — суша, `.` — вода. Для водной клетки расстояние до суши — наименьшее $|i - a| + |j - b|$ до клетки суши $(a, b)$. Найдите наибольшее такое расстояние среди водных клеток. Если на карте нет ни суши, ни воды, выведите $-1$.

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 3\cdot 10^5$). Далее $h$ строк по $w$ символов.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
3 4
#...
....
...#
```

**Вывод**
```
2
```
