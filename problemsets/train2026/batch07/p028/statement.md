# Цепочка слов

Даны $n$ различных слов длины $L$. За ход можно заменить в слове одну букву так, чтобы получилось другое слово из списка. Найдите наименьшее число ходов, которое переводит слово номер $a$ в слово номер $b$.

**Ввод.** В первой строке $n, L, a, b$ ($1 \le n \le 2\cdot 10^4$, $1 \le L \le 20$). Далее $n$ слов из строчных латинских букв.

**Вывод.** Число ходов или $-1$.

### Пример 1

**Ввод**
```
6 3 1 5
cat
cot
dog
dot
cog
cow
```

**Вывод**
```
2
```
