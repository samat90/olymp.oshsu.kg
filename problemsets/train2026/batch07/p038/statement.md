# Размеры ветвей

Сеть из $n$ узлов — дерево, корень — узел $1$. Для каждого узла найдите, сколько узлов в его ветви (сам узел и все, кто «ниже» него, если смотреть от корня).

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Далее $n-1$ строка с парами $a\ b$.

**Вывод.** $n$ чисел через пробел.

### Пример 1

**Ввод**
```
5
1 2
1 3
3 4
3 5
```

**Вывод**
```
5 1 3 1 1
```
