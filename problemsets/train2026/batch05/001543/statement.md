# Квадратный участок поля

Поле Нурбека разбито на клетки: `1` - засеянная клетка, `0` - пустая. Найдите наибольшую площадь прямоугольника, целиком состоящего из засеянных клеток.

## Входные данные
В первой строке числа `n` и `m` (`1 ≤ n, m ≤ 700`). Затем `n` строк по `m` символов `0` или `1`.

## Выходные данные
Площадь наибольшего прямоугольника из единиц (0, если единиц нет).

## Примеры

### Пример 1

Ввод:
```
3 4
1011
1111
0110
```

Вывод:
```
4
```

### Пример 2

Ввод:
```
2 2
00
00
```

Вывод:
```
0
```
