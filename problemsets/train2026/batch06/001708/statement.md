# Тропа с камнями

На поле n×m некоторые клетки заняты камнями (#), остальные свободны (.). Нурлан идёт из левой верхней клетки в правую нижнюю, каждый шаг — на соседнюю клетку вправо или вниз, по камням идти нельзя. Сколько существует путей?

**Ввод.** В первой строке n и m (1 ≤ n, m ≤ 500), далее n строк по m символов «.» или «#».

**Вывод.** Число путей по модулю 10^9 + 7 (0, если начальная или конечная клетка занята).

**Пример**

Ввод:
```
3 3
...
.#.
...
```
Вывод:
```
2
```
