# Грузоподъёмность моста

Между $n$ городами $m$ двусторонних дорог; у дороги есть предельная масса груза $c$. Грузовик едет из города $1$ в город $n$; максимальная масса груза, с которой он может проехать, равна наименьшему из пределов дорог на пути. Найдите наибольшую массу, которую можно провезти.

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ строк $a\ b\ c$ ($1 \le c \le 10^9$).

**Вывод.** Одно число или $-1$, если проехать нельзя.

### Пример 1

**Ввод**
```
4 5
1 2 10
2 4 3
1 3 5
3 4 5
2 3 20
```

**Вывод**
```
5
```
