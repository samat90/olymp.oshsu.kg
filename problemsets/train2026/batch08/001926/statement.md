# Различные подстроки

Сколько различных непустых подстрок (подряд идущих символов) у данной строки? Все слова состоят из строчных латинских букв.

**Ввод.** Одна строка длиной от 1 до 1000.

**Вывод.** Число различных подстрок.

## Примеры

**Ввод 1**
```
aab
```
**Вывод 1**
```
5
```

**Ввод 2**
```
abc
```
**Вывод 2**
```
6
```
