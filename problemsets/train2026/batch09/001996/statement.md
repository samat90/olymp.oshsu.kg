# Сумма степеней двойки со знаком

Какое наименьшее количество слагаемых вида $+2^k$ или $-2^k$ ($k \ge 0$) нужно, чтобы получить число $n$?

**Ввод.** Одно число $n$ ($1 \le n \le 10^{18}$).

**Вывод.** Наименьшее количество слагаемых.

### Пример 1

Ввод:
```
7
```

Вывод:
```
2
```

### Пример 2

Ввод:
```
23
```

Вывод:
```
3
```
