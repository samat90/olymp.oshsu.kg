# Вид треугольника

По трём точкам определите вид треугольника: `Вырожденный`, `Прямоугольный`, `Тупоугольный` или `Остроугольный`.

**Ввод.** Первая строка: `t` — число тестов (`1 ≤ t ≤ 10^5`). Далее в каждой строке по 6 целых `x1 y1 x2 y2 x3 y3` (`|x|, |y| ≤ 10^6`).

**Вывод.** Для каждого теста слово в отдельной строке.

## Пример 1

Ввод:
```
3
0 0 3 0 0 4
0 0 1 1 2 2
0 0 5 0 1 1
```

Вывод:
```
Прямоугольный
Вырожденный
Тупоугольный
```
