Эрлан хочет выписать подряд все свои числа в таком порядке, чтобы получилось как можно большее число. Найдите его.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ целых неотрицательных чисел.

## Формат вывода

Выведите наибольшее возможное число без ведущих нулей (если все числа нулевые, выведите 0).

## Ограничения

$1 \le n \le 1000$, $0 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
3
3 30 34
```
Вывод:
```
34330
```

### Пример 2

Ввод:
```
2
0 0
```
Вывод:
```
0
```
