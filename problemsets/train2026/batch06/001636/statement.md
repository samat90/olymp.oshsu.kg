# Лучший отрезок

В течение n дней Улан записывал прибыль лавки (она может быть отрицательной). Найдите непустой набор подряд идущих дней с наибольшей суммарной прибылью.

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (−1000 ≤ a_i ≤ 1000).

**Вывод.** Наибольшая сумма непустого отрезка.

**Пример**

Ввод:
```
6
-2 5 -1 4 -7 3
```
Вывод:
```
8
```
