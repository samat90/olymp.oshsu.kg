# Бильярд на столе

Шар на бильярдном столе `0 ≤ x ≤ w`, `0 ≤ y ≤ h` в целой точке `(x, y)` движется по диагонали: за секунду координата `x` меняется на `dx`, а `y` — на `dy` (`dx, dy` равны `1` или `-1`). У стенки шар отражается по правилу «угол падения равен углу отражения» (знак соответствующей скорости меняется). Где окажется шар через `t` секунд?

**Ввод.** `w h x y dx dy t` (`1 ≤ w, h ≤ 10^9`, `0 ≤ t ≤ 10^18`).

**Вывод.** Два числа `x y`.

## Пример 1

Ввод:
```
5 3 1 1 1 1 7
```

Вывод:
```
2 2
```

## Пример 2

Ввод:
```
4 4 0 0 -1 -1 1
```

Вывод:
```
1 1
```
