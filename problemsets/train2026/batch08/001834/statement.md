# Радиус дерева

Для вершины v обозначим e(v) наибольшее расстояние от v до другой вершины. Радиус дерева — наименьшее из чисел e(v). Найдите радиус.

**Ввод.** В первой строке n. В следующих n−1 строках по два числа u, v — ребро дерева. 1 ≤ n ≤ 100000.

**Вывод.** Радиус дерева.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
2
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
2
```
