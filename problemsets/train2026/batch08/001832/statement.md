# Размеры поддеревьев

Для каждой вершины дерева (корень — 1) выведите число вершин в её поддереве, включая её саму.

**Ввод.** В первой строке n. В следующих n−1 строках по два числа u, v — ребро дерева. Корень — вершина 1. 1 ≤ n ≤ 100000.

**Вывод.** n чисел — размеры поддеревьев вершин 1, 2, …, n.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
5 1 3 2 1
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
7 3 3 1 1 1 1
```
