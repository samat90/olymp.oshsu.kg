# Раздел «Курсы» — итог

Дата: 2026-11-21. Реализовано всё из плана одним релизом (этапы 1–3).

## Что есть
- **Преподаватель**: `Profile.is_teacher`, флажок в карточке пользователя и массовые действия «Сделать преподавателем / Снять статус» в админке, значок рядом с именем на сайте.
- **Курс**: модули необязательны; урок — набор блоков в любом порядке: текст (Markdown, формулы, код), видео YouTube (youtube-nocookie + ссылка «Открыть на YouTube»), картинка, файл, тест, задание с ручной оценкой, задача сайта.
- Настройки преподавателя: черновик/открытие урока, обязательность, отметка «Изучено», порог зачёта, открытие по дате и срок сдачи, последовательное открытие, доступ (все / по ссылке / организация), соавторы, отзывы, сертификат.
- **Слушатель**: запись, плеер с деревом уроков, прогресс, тесты (попытки, зачёт, разбор), задания (текст/файл, возврат на доработку), комментарии, отзыв, сертификат PDF с QR и страницей проверки `/courses/certificate/<номер>/`.
- **Преподаватель**: таблица слушателей, очередь проверки, экспорт Excel, копирование курса.
- **Админка**: блок «Курсы» (курсы с inline модулей и уроков, уроки с блоками, записи, задания, комментарии, отзывы); суперпользователь — полный CRUD. Отключатель: Misc config `courses_disabled` (текст для пользователей; закрывает запись, сдачу работ и правки).
- Меню «Курсы» (миграция 0185), плитка на главной, карточка в «О платформе», карточка в главной админки.

## Устройство
- Модели `judge/models/course.py`, правила и прогресс `judge/utils/course_logic.py`, сертификат `judge/utils/course_certificate.py` (Pillow, шрифты DejaVu в `resources/courses/fonts`), страницы `judge/views/course.py`, `course_edit.py`, шаблоны `templates/courses`, стили и скрипт `resources/courses`.
- Только HTTP, без WebSocket; списки с бесконечной прокруткой; файлы слушателей и преподавателя отдаются через проверку прав; Markdown экранируется; картинки перекодируются Pillow.
- Миграция 0185 только добавляет таблицы, поле и пункт меню. В старые миграции 0169, 0170, 0176 добавлен `defer('is_teacher')`, чтобы чистая база собиралась до применения 0185.
- Сабмит-кнопки сайта отключаются при отправке формы (common.js), поэтому `courses.js` копирует имя и значение нажатой кнопки в скрытое поле.

## Проверка
Тесты `judge.test_courses` (модели, права, прогресс, тесты, задания, файлы, сертификат, админка, редактор), flake8, прогон в браузере: админ даёт статус, преподаватель создаёт курс только из текста и курс со всеми блоками, слушатели записываются, сдают тест и задание, преподаватель оценивает, выдаётся сертификат; экраны desktop и mobile, светлая и тёмная темы.

## Выкладка
Обычная: подписанные коммиты, `git push origin improvements-2026-10:main`, автодеплой применяет миграцию 0185. Сразу после выкладки проверить `/courses/` и `deploy-status`.

## Готовые курсы
Курсы лежат в `scripts/content/courses/<папка>` и добавляются командой `manage.py load_courses` при каждом выкате: «Основы Python», «Основы Go», «Основы C++», «Основы Java», «Основы C#», «Основы JavaScript». В каждом по 13–15 модулей: урок (текст, типичные ошибки, видео, тест с автопроверкой и пояснениями) и практика (задачи из архива, задание с ручной оценкой), итоговый тест (зачёт 70%) и необязательный итоговый проект.

- Общие помощники (`Q`, `pair`, `module`) лежат в `scripts/content/courses/_dsl.py`; формат папки описан в докстринге `load_courses`.
- Команда добавляет только отсутствующие курсы. Если в `course.py` указана более новая `version`, чем записана в настройке `course_version:<ключ>`, тексты обновляются на месте: модули, уроки, блоки и вопросы сопоставляются по порядку, поэтому записи, попытки, работы и прогресс слушателей сохраняются. Настройки курса и уроки, добавленные преподавателем, не затрагиваются. Чтобы выкатить правки текстов, поднимите `version`.
- Примеры кода и ответы тестов проверяет `scripts/content/courses/check_course.py <папка>` на настоящих go, g++, javac, mcs и node (запуск в WSL); он сопоставляет вывод кода с отмеченным ответом.
- Видео: только существующие ролики, каждый проверен через YouTube oEmbed.
