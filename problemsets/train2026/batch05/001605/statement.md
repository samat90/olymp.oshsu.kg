# Удвоить число

Неотрицательное число записано списком цифр от старшей к младшей (ведущих нулей нет, кроме числа 0). Удвойте число и выведите в том же формате.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 100000`). Во второй строке `n` цифр.

## Выходные данные
Цифры результата через пробел.

## Примеры

### Пример 1

Ввод:
```
3
1 8 9
```

Вывод:
```
3 7 8
```

### Пример 2

Ввод:
```
1
0
```

Вывод:
```
0
```
