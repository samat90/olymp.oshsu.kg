# Центр сети

Сеть из $n$ узлов — дерево. Выберем один узел главным. Для него «глубина» — наибольшее расстояние до остальных узлов. Выведите все узлы, при выборе которых глубина минимальна (их один или два), по возрастанию.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Далее $n-1$ строка с парами $a\ b$.

**Вывод.** Один или два номера через пробел.

### Пример 1

**Ввод**
```
6
1 2
2 3
3 4
4 5
2 6
```

**Вывод**
```
3
```
