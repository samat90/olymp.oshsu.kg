В турнире участники набрали очки. Одинаковые очки считаются одним результатом. Найдите $k$-й по возрастанию различный результат или сообщите, что его нет.

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — $n$ очков.

## Формат вывода

Выведите $k$-й по возрастанию различный результат, а если различных результатов меньше $k$ — выведите -1.

## Ограничения

$1 \le k \le n \le 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5 2
7 3 7 1 3
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
4 3
5 5 5 5
```
Вывод:
```
-1
```
