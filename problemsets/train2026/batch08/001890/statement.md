# Две команды

n школьников хотят разделиться на две команды так, чтобы никакие двое, поссорившиеся между собой, не оказались в одной команде. Известны m пар поссорившихся. Возможно ли такое деление?

**Ввод.** В первой строке n и m. В следующих m строках по два числа a, b — ребро между вершинами a и b (a ≠ b, кратные рёбра возможны). 1 ≤ n ≤ 100000, 0 ≤ m ≤ 150000.

**Вывод.** YES или NO.

## Примеры

**Ввод 1**
```
4 4
1 2
2 3
3 4
4 1
```
**Вывод 1**
```
YES
```

**Ввод 2**
```
3 3
1 2
2 3
3 1
```
**Вывод 2**
```
NO
```
