# Сумма XOR по путям дерева

В Нарынской области $n$ сёл соединены $n-1$ дорогами так, что от любого села можно доехать до любого другого. У каждой дороги есть число $w$. «Значение пути» между двумя сёлами — побитовое исключающее ИЛИ чисел на дорогах пути. Найдите сумму значений путей по всем неупорядоченным парам разных сёл.

**Ввод.** В первой строке $n$ ($2 \le n \le 10^5$). Далее $n-1$ строк: $u, v, w$ ($1 \le u, v \le n$, $0 \le w < 2^{30}$) — дорога между сёлами $u$ и $v$.

**Вывод.** Сумма.

### Пример 1

Ввод:
```
3
1 2 1
2 3 2
```

Вывод:
```
6
```
