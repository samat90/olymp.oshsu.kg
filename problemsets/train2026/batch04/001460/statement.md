Высоты на горной тропе строго возрастают до вершины, а потом строго убывают (подъём или спуск могут быть пустыми). Найдите номер вершины, то есть наибольшего элемента.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ различных высот.

## Формат вывода

Выведите номер (с единицы) вершины.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
6
1 4 9 8 5 2
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
3
7 5 1
```
Вывод:
```
1
```
