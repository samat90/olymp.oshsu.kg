# Скобки в выражении

Дано логическое выражение из значений T (истина) и F (ложь), соединённых знаками & (и), | (или), ^ (исключающее или). Сколькими способами можно расставить скобки так, чтобы значение выражения было истинным? Способы различаются порядком вычислений.

**Ввод.** Строка вида T^F|T&F без пробелов, содержащая от 1 до 99 значений.

**Вывод.** Число способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
T|F&T
```
Вывод:
```
2
```
