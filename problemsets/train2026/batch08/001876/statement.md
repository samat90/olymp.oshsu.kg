# Ближайшее значение

В дереве поиска хранится n различных чисел. Для каждого из q запросов x найдите хранящееся число, ближайшее к x по модулю разности. Если таких два, выведите меньшее.

**Ввод.** В первой строке n и q. Во второй — n чисел. В третьей — q запросов. 1 ≤ n, q ≤ 100000, числа от 0 до 10⁹.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
4 3
1 5 9 12
6 7 0
```
**Вывод 1**
```
5
5
1
```
