# Пятнашки 2 на 3

Доска $2 \times 3$ содержит фишки $1$–$5$ и пустую клетку $0$. За ход можно передвинуть фишку, соседнюю по стороне с пустой клеткой, на её место. Нужно получить расположение
```
1 2 3
4 5 0
```
Какое наименьшее число ходов потребуется?

**Ввод.** Две строки по три числа — исходное расположение.

**Вывод.** Число ходов или $-1$, если получить нужное расположение нельзя.

### Пример 1

**Ввод**
```
1 2 3
4 0 5
```

**Вывод**
```
1
```
