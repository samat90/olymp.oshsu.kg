Плитка шоколада состоит из $n$ долек подряд, у $i$-й сладость $a_i$. Айжан хочет разломать её на $k+1$ кусков из подряд идущих долек и раздать $k$ друзьям, а один кусок оставить себе. Она берёт самый несладкий кусок. Какой наибольшей может быть его сладость?

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — $a_i$.

## Формат вывода

Выведите наибольшую возможную сладость куска Айжан.

## Ограничения

$1 \le k < n \le 10^5$, $1 \le a_i \le 10^4$.

## Примеры

### Пример 1

Ввод:
```
5 2
3 1 4 1 5
```
Вывод:
```
4
```

### Пример 2

Ввод:
```
3 2
2 2 2
```
Вывод:
```
2
```
