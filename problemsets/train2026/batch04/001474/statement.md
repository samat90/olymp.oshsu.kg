Даны $n$ отрезков на числовой прямой (концы включаются). Для каждой точки $x$ определите, скольким отрезкам она принадлежит.

## Формат ввода

В первой строке даны $n$ и $q$. Далее $n$ строк с парой $l_i$, $r_i$. В последней строке $q$ точек.

## Формат вывода

Выведите ответы через пробел.

## Ограничения

$1 \le n, q \le 2 \cdot 10^5$, $1 \le l_i \le r_i \le 10^9$, $1 \le x \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
3 3
1 5
3 8
6 7
4 6 9
```
Вывод:
```
2 2 0
```

### Пример 2

Ввод:
```
1 1
2 2
2
```
Вывод:
```
1
```
