# Ограничитель запросов

Сервис принимает не более `m` запросов за любые `w` секунд подряд. Запрос в момент `t` принимается, если среди уже принятых запросов в моменты `t - w + 1 ... t` их меньше `m`; иначе он отклоняется (отклонённые не считаются). Для каждого запроса определите, принят ли он.

## Входные данные
В первой строке числа `n`, `w`, `m` (`1 ≤ n ≤ 200000`, `1 ≤ w ≤ 10^9`, `1 ≤ m ≤ 100000`). Во второй строке `n` неубывающих целых чисел - моменты запросов от 0 до 10^9.

## Выходные данные
`n` слов `YES` или `NO` через пробел.

## Примеры

### Пример 1

Ввод:
```
6 2 3
1 2 3 4 5 6
```

Вывод:
```
YES YES YES YES YES YES
```

### Пример 2

Ввод:
```
3 10 1
1 2 12
```

Вывод:
```
YES NO YES
```
