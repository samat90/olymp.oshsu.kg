# Дерево из отсортированных чисел

Из n отсортированных по возрастанию различных чисел строят дерево поиска: корнем становится средний элемент (при чётном числе элементов — левый из двух средних), левое поддерево строится так же из элементов левее, правое — из элементов правее. Выведите значения в порядке прямого обхода.

**Ввод.** В первой строке n, во второй — n чисел по возрастанию. 1 ≤ n ≤ 100000.

**Вывод.** Прямой обход через пробел.

## Примеры

**Ввод 1**
```
5
1 2 3 4 5
```
**Вывод 1**
```
3 1 2 4 5
```

**Ввод 2**
```
4
1 2 3 4
```
**Вывод 2**
```
2 1 3 4
```
