# Жизнь на торе

Игра «Жизнь» на поле `n × m`, замкнутом в тор (за правым краем — левый, за нижним — верхний). Клетка `#` жива, `.` мертва. За один шаг: живая клетка с 2 или 3 живыми соседями (из восьми) остаётся живой, мёртвая ровно с 3 живыми соседями оживает, остальные мертвы. Выведите поле после `k` шагов.

**Ввод.** `n`, `m`, `k` (`3 ≤ n, m ≤ 40`, `0 ≤ k ≤ 100`), затем `n` строк по `m` символов.

**Вывод.** `n` строк.

## Пример 1

Ввод:
```
4 4 1
....
.##.
.##.
....
```

Вывод:
```
....
.##.
.##.
....
```
