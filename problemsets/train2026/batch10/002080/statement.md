# Стирание повторов

Дана строка. Пока в ней есть `k` одинаковых символов подряд, их удаляют (оставшиеся части склеиваются). Выведите, что останется. Результат не зависит от порядка удаления.

**Ввод.** Строка из строчных латинских букв длиной `n` (`1 ≤ n ≤ 10^6`) и число `k` (`2 ≤ k ≤ 10^6`) во второй строке.

**Вывод.** Итоговая строка (может быть пустой).

## Пример 1

Ввод:
```
deeedbbcccbdaa
3
```

Вывод:
```
aa
```

## Пример 2

Ввод:
```
abcd
2
```

Вывод:
```
abcd
```
