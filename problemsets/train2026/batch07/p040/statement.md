# Оповещение сотрудников

В компании $n$ сотрудников, у каждого, кроме директора (номер $h$), есть ровно один непосредственный начальник. Директор узнаёт новость в момент $0$ и передаёт её своим подчинённым; каждый сотрудник $i$ тратит $t_i$ минут, после чего все его непосредственные подчинённые узнают новость одновременно. Через сколько минут новость узнают все?

**Ввод.** В первой строке $n$ и $h$ ($1 \le n \le 10^5$). Во второй — $n$ чисел: номер начальника сотрудника $i$ (для директора $-1$). В третьей — $n$ чисел $t_i$ ($0 \le t_i \le 1000$).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
6 3
3 1 -1 3 3 1
2 5 4 0 0 0
```

**Вывод**
```
6
```
