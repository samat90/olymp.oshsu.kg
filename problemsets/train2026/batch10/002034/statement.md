# Площадь выпуклой оболочки

Найдите площадь выпуклой оболочки `n` различных точек, умноженную на 2. Если оболочка вырождена в точку или отрезок, площадь равна 0.

**Ввод.** `n` (`1 ≤ n ≤ 10^5`) и `n` строк `x y` (`|x|, |y| ≤ 10^9`).

**Вывод.** Одно целое число.

## Пример 1

Ввод:
```
5
0 0
4 0
4 4
0 4
2 2
```

Вывод:
```
32
```

## Пример 2

Ввод:
```
2
1 1
5 7
```

Вывод:
```
0
```
