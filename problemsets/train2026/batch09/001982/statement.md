# Вершины-пики случайной перестановки

Позиция $i$ в перестановке называется пиком, если число на ней больше всех своих соседей (у крайних позиций один сосед). Перестановка чисел $1, \dots, n$ выбирается случайно. Найдите математическое ожидание числа пиков в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Одно число $n$ ($1 \le n \le 10^{18}$).

**Вывод.** Ответ по модулю $10^9+7$.

### Пример 1

Ввод:
```
3
```

Вывод:
```
333333337
```
