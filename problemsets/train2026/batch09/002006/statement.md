# Минимальная сумма двух XOR

Даны числа $a$, $b$ и $n$. Выберите целое $x$ от 0 до $n$ так, чтобы значение $(x \oplus a) + (x \oplus b)$ было наименьшим. Если таких $x$ несколько, выберите наименьшее.

**Ввод.** Три числа $a$, $b$, $n$ ($0 \le a, b, n \le 10^{18}$).

**Вывод.** Наименьшее значение и соответствующее $x$.

### Пример 1

Ввод:
```
6 12 5
```

Вывод:
```
10 4
```
