# Удвоенная площадь треугольника

Дан треугольник с целыми координатами вершин. Выведите его площадь, умноженную на 2 (это целое число).

**Ввод.** Три строки, в каждой пара целых `x y` (`|x|, |y| ≤ 10^9`). Треугольник может быть вырожденным.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
0 0
4 0
0 3
```

Вывод:
```
12
```

## Пример 2

Ввод:
```
1 1
2 2
3 3
```

Вывод:
```
0
```
