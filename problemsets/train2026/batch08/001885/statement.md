# Сеть дорог

Между n посёлками можно проложить дороги определённой стоимости. Нужно выбрать дороги так, чтобы из любого посёлка можно было добраться в любой другой, а общая стоимость была наименьшей. Найдите эту стоимость. Гарантируется, что это возможно.

**Ввод.** В первой строке n и m. В следующих m строках a, b, w — дорога между a и b стоимостью w (1 ≤ w ≤ 1000). 1 ≤ n ≤ 50000, m ≤ 125000.

**Вывод.** Наименьшая общая стоимость.

## Примеры

**Ввод 1**
```
4 5
1 2 1
2 3 4
1 3 2
3 4 5
2 4 3
```
**Вывод 1**
```
6
```
