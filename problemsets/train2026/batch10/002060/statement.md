# Вычитание квадратов

В куче `n` камней. За ход можно взять любое ненулевое число камней, являющееся квадратом (1, 4, 9, …). Кто не может сделать ход, проиграл. Айбек ходит первым. Определите победителя для нескольких `n`.

**Ввод.** `t` (`1 ≤ t ≤ 10^5`) и `t` значений `n` (`0 ≤ n ≤ 20000`).

**Вывод.** Для каждого `n` слово `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
5
1
2
4
7
17
```

Вывод:
```
Айбек
Бермет
Айбек
Бермет
Бермет
```
