# Слияние куч

В ряд лежат n куч камней, в куче i — a_i камней. За ход можно слить две соседние кучи в одну, заплатив столько, сколько в них камней вместе. Какова наименьшая суммарная плата, чтобы слить всё в одну кучу?

**Ввод.** В первой строке n (1 ≤ n ≤ 150), во второй n чисел a_i (1 ≤ a_i ≤ 100).

**Вывод.** Наименьшая суммарная плата.

**Пример**

Ввод:
```
4
4 1 1 4
```
Вывод:
```
18
```
