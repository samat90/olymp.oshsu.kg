К кассе в Караколе пришли $n$ человек, обслуживание $i$-го занимает $a_i$ минут. Время ожидания человека — это время, пока обслуживают всех, кто стоит перед ним. В каком порядке их пустить, чтобы сумма времён ожидания была наименьшей? Выведите эту сумму.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ времён обслуживания.

## Формат вывода

Выведите минимальную суммарную длительность ожидания.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^6$.

## Примеры

### Пример 1

Ввод:
```
3
3 1 2
```
Вывод:
```
4
```

### Пример 2

Ввод:
```
1
7
```
Вывод:
```
0
```
