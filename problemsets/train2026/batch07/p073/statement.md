# Обязательные и возможные линии

Дан связный граф из $n$ вершин и $m$ рёбер с весами. Остов — набор из $n-1$ рёбер, связывающий все вершины. Рассмотрим все остовы наименьшего возможного веса. Ребро называется *обязательным*, если оно входит в каждый такой остов, и *возможным*, если входит в некоторые, но не во все. Найдите количество обязательных и количество возможных рёбер.

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 100$, $n-1 \le m \le 200$). Далее $m$ строк $a\ b\ w$ ($1 \le w \le 1000$). Граф связный, без кратных рёбер.

**Вывод.** Два числа через пробел.

### Пример 1

**Ввод**
```
4 5
1 2 1
2 3 1
3 4 1
1 4 1
1 3 5
```

**Вывод**
```
0 4
```
