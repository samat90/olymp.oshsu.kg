В ряду растут $n$ цветков, $i$-й распустится в день $b_i$. Для букета нужно взять $k$ подряд растущих распустившихся цветков, один цветок можно использовать только в одном букете. Через какое наименьшее число дней можно собрать $m$ букетов? Если это невозможно, выведите -1.

## Формат ввода

В первой строке даны $n$, $m$, $k$. Во второй — $b_i$.

## Формат вывода

Выведите минимальный день или -1.

## Ограничения

$1 \le n \le 10^5$, $1 \le m, k$, $1 \le b_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5 2 2
1 2 5 3 4
```
Вывод:
```
4
```

### Пример 2

Ввод:
```
3 2 2
4 4 4
```
Вывод:
```
-1
```
