# k-й по величине в потоке

Числа поступают по одному. После каждого нового числа определите, какое число стоит `k`-м по величине среди всех полученных (при равных значениях каждое считается отдельно).

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ k ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
`n` чисел через пробел: после каждого числа его `k`-е по величине, а пока чисел меньше `k` - `-1`.

## Примеры

### Пример 1

Ввод:
```
6 3
4 5 8 2 9 1
```

Вывод:
```
-1 -1 4 4 5 5
```

### Пример 2

Ввод:
```
3 1
5 2 7
```

Вывод:
```
5 5 7
```
