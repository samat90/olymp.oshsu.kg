# Прямоугольник наименьшей площади

Из заданных `n` различных точек выберите четыре, образующие прямоугольник со сторонами, параллельными осям. Выведите наименьшую возможную площадь или `0`, если таких прямоугольников нет.

**Ввод.** `n` (`1 ≤ n ≤ 500`) и `n` строк `x y` (`0 ≤ x, y ≤ 40000`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
5
1 1
1 3
3 1
3 3
2 2
```

Вывод:
```
4
```
