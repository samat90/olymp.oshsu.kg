# Редактура архива

## Уборка повторов, 2 октября 2026

Проверены все 1035 задач: в общем списке оставлена 81 самостоятельная задача,
954 шаблонных повтора скрыты полем `is_listed`. Их URL, посылки, тесты и связи
с соревнованиями сохраняются. Условия сокращены до постановки, форматов
ввода/вывода и одного примера. Убраны автоматические пояснения и подсказки.

Поле `difficulty` хранит отдельную оценку 1–100%, независимо от баллов.
Для существующих собственных задач оценки редакционные, не значения ACMP.
Список сортируется по сложности в обе стороны и фильтруется по диапазону;
неоценённые задачи идут последними. Информация о сервере-судье убрана.
Таблица показывает темы, решаемость и число решивших. Для существующих
пустых названий тем используется их ID, шесть задач соревнований отнесены
к математике, сортировке, графам и динамическому программированию.

```bash
python manage.py migrate
python scripts/content/curate_archive.py /path/to/current-export.json --output /path/to/curated.json
python scripts/content/apply_archive.py /path/to/curated.json --mode check
python scripts/content/apply_archive.py /path/to/curated.json --mode apply
python scripts/content/assign_topics.py /path/to/topics-before.json --apply
# Откат данных именно этого выпуска:
python scripts/content/apply_archive.py /path/to/curated.json --mode rollback
```

Перед применением необходима резервная копия БД. Импорт проверяет состав
архива, идентичность объектов, исходное содержимое и защищённые настройки.
Устаревший генератор повторов выключен по умолчанию.
Скрипт классификации сохраняет исходные названия тем и связи в отдельный JSON.

Для замены архива на 1000+ задач именно ACMP нужен предоставленный для переноса
экспорт условий и полный комплект тестов/чекеров. Открытая таблица ACMP
не содержит такой комплект. Существующие локальные задачи не переименованы
в задачи ACMP; непроверяемые копии не публикуются.

## Предыдущая редактура, 28 сентября 2026

Выпуск охватывает 1035 задач и оба контеста. Каталог содержит полноценные
условия, ограничения, формат ввода/вывода и примеры.
Общие учебные варианты используют одну проверенную формулировку с параметрами
конкретной задачи. Номера задач и история решений сохраняются.

Исправлены неоднозначные правила выбора при равенстве, нижняя медиана,
непустой подмассив, отсутствие чётных элементов, нумерация и формат ответов.
Исправлены пояснения о партах и противоречие в ограничении энергии.
Уточнены 61 вводящее в заблуждение название. В контестах указаны фактические
даты, список задач, максимальные баллы и правила используемого формата.

## Воспроизводимая проверка

Приватные выгрузки находятся в `artifacts/content-audit/` и исключены из Git:

- `original.json`: исходные задачи, переводы, контесты и связи;
- `judge-data/problems/`: копия всех серверных тестов;
- `release.json`: новые условия и прежние значения для отката;
- `review.csv`: результат проверки каждой из 1035 задач;
- `report.json`: сводка, количества и SHA-256 выпуска.

```powershell
.venv/Scripts/python.exe -X utf8 scripts/content/build.py
.venv/Scripts/python.exe -X utf8 scripts/content/preview.py
```

`build.py` проверяет ограничения и ответы всех 8130 существующих тестов
независимыми эталонными вычислениями, затем проверяет 2072 новых примера.
`preview.py` использует только локальную SQLite-базу `ui-preview.sqlite3`;
проверяет преобразование всех условий в HTML и сохранность каждого примера.
Рабочая PostgreSQL-база не используется для локального предпросмотра.

## Установка и откат

Перед установкой требуется свежая резервная копия БД. На сервере команда
выполняется из корня проекта его виртуальным окружением:

```bash
venv/bin/python scripts/content/apply_release.py /path/to/release.json --mode check
venv/bin/python scripts/content/apply_release.py /path/to/release.json --mode apply
venv/bin/python scripts/content/verify_release.py /path/to/export-directory
```

Импорт сверяет полный состав архива и старые значения, затем в одной
транзакции обновляет только названия/условия задач и описания/аннотации
контестов. После транзакции сбрасываются штатные кеши HTML, метаданных и PDF.
Лимиты, тесты, начисление баллов, расписание, рейтинг, посылки и участники
не изменяются. Проверка после публикации сравнивает защищённые настройки
и открывает все 1035 страниц задач и четыре страницы контестов/результатов.

Для отката именно этого выпуска без восстановления пользовательских данных:

```bash
venv/bin/python scripts/content/apply_release.py /path/to/release.json --mode rollback
```

Откат откажется перезаписать условия, которые были отредактированы после выпуска.
Тесты на judge-сервере остаются прежними: независимая проверка не выявила
ошибок в эталонных ответах. Формат вещественного вывода описан в соответствии
с действующей точной текстовой проверкой: шесть знаков, у площади треугольника — один.
