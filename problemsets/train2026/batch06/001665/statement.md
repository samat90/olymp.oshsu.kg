# Шаблон с повторением

Шаблон состоит из строчных букв и символов «.», где «.» заменяет одну любую букву. После любой буквы или точки может стоять «*», что означает: предыдущий символ повторяется любое число раз, в том числе ноль. Подходит ли строка шаблону целиком?

**Ввод.** В первой строке шаблон (1 ≤ длина ≤ 1000, «*» не стоит первым и не идёт два раза подряд), во второй строка из строчных букв (1 ≤ длина ≤ 1000).

**Вывод.** YES или NO.

**Пример**

Ввод:
```
a*b.c*
aaabxd
```
Вывод:
```
NO
```
