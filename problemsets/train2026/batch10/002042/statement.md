# Целые точки внутри многоугольника

Простой многоугольник задан целыми вершинами. Сколько целых точек лежит строго внутри него?

**Ввод.** `n` (`3 ≤ n ≤ 10^5`) и `n` строк `x y` — вершины в порядке обхода (`|·| ≤ 10^6`). Соседние вершины различны.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
4
0 0
4 0
4 3
0 3
```

Вывод:
```
6
```

## Пример 2

Ввод:
```
3
0 0
5 0
0 5
```

Вывод:
```
6
```
