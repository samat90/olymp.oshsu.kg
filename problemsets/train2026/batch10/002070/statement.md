# Камнепад

Поле `n × m`: `*` — камень, `X` — неподвижная скала, `.` — пустота. Камни падают вниз, пока не упрутся в дно, скалу или другой камень. Выведите поле после падения.

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 500`), затем `n` строк по `m` символов.

**Вывод.** `n` строк.

## Пример 1

Ввод:
```
3 3
*.*
.X.
*..
```

Вывод:
```
...
*X.
*.*
```

## Пример 2

Ввод:
```
2 2
**
..
```

Вывод:
```
..
**
```
