# Крестики-нолики

Доска 3×3, символы `X`, `O` и `.` (пусто). Выигрывает тот, кто первым выстроит три своих знака в ряд, столбец или диагональ. Дана незаконченная позиция (никто ещё не выиграл, есть пустые клетки) и чей ход. Оба играют оптимально. Выведите итог: `X` (выиграет X), `O` (выиграет O) или `Ничья`.

**Ввод.** `t` (`1 ≤ t ≤ 2000`), затем `t` блоков: три строки доски и строка с символом `X` или `O` — чей ход.

**Вывод.** Для каждого блока одно слово.

## Пример 1

Ввод:
```
2
XX.
OO.
...
X
XOX
OXO
O..
X
```

Вывод:
```
X
X
```
