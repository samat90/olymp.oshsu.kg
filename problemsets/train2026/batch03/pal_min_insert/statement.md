# Достроить палиндром

Эрлан может вставлять в слово буквы в любые места. Какое наименьшее число вставок превратит слово в палиндром?

## Вход

Одна строка из строчных латинских букв, длина от 1 до 1000.

## Выход

Наименьшее число вставок.

## Пример 1

**Вход**
```
ab
```

**Выход**
```
1
```

## Пример 2

**Вход**
```
mom
```

**Выход**
```
0
```
