# Сколько квадратов из единиц

Дано поле n×m из нулей и единиц. Сколько в нём квадратов (любого размера, с любым положением), состоящих только из единиц?

**Ввод.** В первой строке n и m (1 ≤ n, m ≤ 500), далее n строк по m символов 0 или 1.

**Вывод.** Количество квадратов.

**Пример**

Ввод:
```
2 3
111
111
```
Вывод:
```
8
```
