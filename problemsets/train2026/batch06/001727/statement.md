# Выгодные подарки в дереве

Школы района образуют дерево из n вершин (корень — вершина 1). Школа i получает подарок стоимостью w_i. Если школа получила подарок, её соседи получить не могут. Какая наибольшая суммарная стоимость подарков возможна?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел w_i (1 ≤ w_i ≤ 1000), далее n−1 строк с рёбрами a, b.

**Вывод.** Наибольшая суммарная стоимость.

**Пример**

Ввод:
```
5
3 2 5 1 4
1 2
1 3
2 4
2 5
```
Вывод:
```
10
```
