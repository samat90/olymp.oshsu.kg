# Разные сдвиги

Сколько различных слов получается из данного слова всеми циклическими сдвигами (включая нулевой)?

## Вход

Одна строка из строчных латинских букв, длина от 1 до 200000.

## Выход

Количество различных слов.

## Пример 1

**Вход**
```
abab
```

**Выход**
```
2
```

## Пример 2

**Вход**
```
abc
```

**Выход**
```
3
```

## Пример 3

**Вход**
```
aaaa
```

**Выход**
```
1
```
