# Ожерелья из бусин

Из $n$ бусин, каждая одного из $k$ цветов, собирают ожерелье в виде кольца. Ожерелья, которые совпадают после поворота, считаются одинаковыми (переворачивать нельзя). Сколько различных ожерелий? Ответ по модулю $10^9+7$.

**Ввод.** Два числа $n$ и $k$ ($1 \le n \le 10^6$, $1 \le k \le 10^9$).

**Вывод.** Количество ожерелий по модулю $10^9+7$.

### Пример 1

Ввод:
```
4 2
```

Вывод:
```
6
```
