# Следующее простое

Для каждого из $q$ чисел найдите наименьшее простое число, не меньшее его.

**Ввод.** В первой строке $q$ ($1 \le q \le 1000$), далее $q$ чисел $x_i$ ($1 \le x_i \le 10^{12}$).

**Вывод.** $q$ чисел, по одному в строке.

### Пример 1

Ввод:
```
3
1
14
100
```

Вывод:
```
2
17
101
```
