# Сколько обходов

Между n посёлками проложены двусторонние дороги. Сколько существует порядков обхода, при которых каждый посёлок посещён ровно один раз и каждые два соседних в порядке посёлка соединены дорогой? Порядок v_1, …, v_n и обратный ему считаются разными.

**Ввод.** В первой строке n и m (1 ≤ n ≤ 13, 0 ≤ m ≤ n(n−1)/2), далее m строк с парами a, b — посёлки, соединённые дорогой (1 ≤ a < b ≤ n, пары различны).

**Вывод.** Количество порядков.

**Пример**

Ввод:
```
4 4
1 2
2 3
3 4
1 4
```
Вывод:
```
8
```
