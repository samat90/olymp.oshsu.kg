# Ближайший меньший слева

Для каждого элемента массива найдите номер ближайшего слева элемента, который строго меньше него.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел от 1 до 10^9.

## Выходные данные
`n` чисел через пробел: для каждой позиции номер (с единицы) ближайшего меньшего слева элемента или `0`, если такого нет.

## Примеры

### Пример 1

Ввод:
```
5
4 5 2 10 8
```

Вывод:
```
0 1 0 3 3
```

### Пример 2

Ввод:
```
3
1 2 3
```

Вывод:
```
0 1 2
```
