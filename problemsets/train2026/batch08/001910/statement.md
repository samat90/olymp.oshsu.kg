# Сумма в прямоугольнике

Дана таблица n × m, сначала заполненная нулями. Операции: «1 x y v» — прибавить v к клетке (x, y); «2 x₁ y₁ x₂ y₂» — вывести сумму чисел в прямоугольнике с углами (x₁, y₁) и (x₂, y₂).

**Ввод.** В первой строке n, m, q. Затем q операций. 1 ≤ n, m ≤ 400, 1 ≤ q ≤ 50000, |v| ≤ 100, x₁ ≤ x₂, y₁ ≤ y₂. Операция типа 2 есть всегда.

**Вывод.** Ответ на каждую операцию типа 2 в отдельной строке.

## Примеры

**Ввод 1**
```
3 3 4
1 1 1 5
1 2 2 7
2 1 1 2 2
2 2 2 3 3
```
**Вывод 1**
```
12
7
```
