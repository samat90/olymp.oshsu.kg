# Карточки Мирлана

У Мирлана n карточек с числами a_i. За один ход он выбирает значение v, забирает все карточки с этим значением и получает v очков за каждую. После этого все карточки со значениями v−1 и v+1 сгорают. Какое наибольшее число очков можно набрать?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (1 ≤ a_i ≤ 10^4).

**Вывод.** Наибольшее число очков.

**Пример**

Ввод:
```
6
3 4 2 3 3 4
```
Вывод:
```
10
```
