# К-е число с m единицами

Все натуральные числа с ровно $m$ единицами в двоичной записи выписаны по возрастанию. Найдите число на позиции $k$ (с единицы).

**Ввод.** Два числа $m$ и $k$ ($1 \le m \le 60$, $1 \le k \le 10^{18}$). Гарантируется, что ответ меньше $2^{60}$.

**Вывод.** Искомое число.

### Пример 1

Ввод:
```
2 4
```

Вывод:
```
9
```
