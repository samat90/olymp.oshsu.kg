# Партия 3: строки (001329–001428)

100 задач на строки. В папке задачи: statement.md, gen.py (`python3 gen.py K`, K=1..10, детерминированный), sol.py (эталон, stdin→stdout), brute.py (перебор), meta.json (код, название, TL, 100 баллов, 10 тестов).
Эталон сверен с перебором на 300 случайных мелких тестах каждой задачи. `_src/` — исходники, из которых папки собраны (`python3 build.py all`).
