# Диаметр с длинами дорог

Сеть из $n$ узлов — дерево, у каждой дороги есть длина. Найдите наибольшее расстояние (по длине дорог) между двумя узлами.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Далее $n-1$ строка $a\ b\ w$ ($1 \le w \le 10^6$).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5
1 2 3
2 3 4
2 4 1
4 5 6
```

**Вывод**
```
11
```
