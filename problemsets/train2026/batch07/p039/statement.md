# Расстояние в дереве

Сеть из $n$ узлов — дерево. Ответьте на $q$ запросов: сколько дорог на пути между узлами $a$ и $b$.

**Ввод.** В первой строке $n$ и $q$ ($1 \le n, q \le 5\cdot 10^4$). Далее $n-1$ строка с парами $a\ b$, затем $q$ строк с парами $a\ b$.

**Вывод.** $q$ чисел, по одному в строке.

### Пример 1

**Ввод**
```
5 3
1 2
1 3
3 4
3 5
2 4
4 5
1 1
```

**Вывод**
```
3
2
0
```
