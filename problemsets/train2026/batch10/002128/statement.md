# Слова в таблице

В таблице `n × m` записаны буквы. Слово можно составить, если его буквы идут по соседним (по стороне) клеткам и ни одна клетка не используется дважды. Для каждого из `q` слов определите, можно ли его составить.

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 4`), `n` строк по `m` букв, число `q` (`1 ≤ q ≤ 50`) и `q` слов (длина от 1 до 10; буквы строчные латинские).

**Вывод.** Для каждого слова `YES` или `NO`.

## Пример 1

Ввод:
```
2 3
abc
def
3
abe
adeb
abcf
```

Вывод:
```
YES
YES
YES
```
