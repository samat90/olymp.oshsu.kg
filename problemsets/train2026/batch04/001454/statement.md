Дан отсортированный по неубыванию массив. Для каждого запроса $x$ найдите номер (с единицы) первого элемента, равного $x$.

## Формат ввода

В первой строке даны $n$ и $q$. Во второй — массив $a$ (по неубыванию). В третьей — $q$ значений $x$.

## Формат вывода

Для каждого запроса выведите номер первого вхождения или -1, если такого элемента нет. Ответы через пробел.

## Ограничения

$1 \le n, q \le 2 \cdot 10^5$, $1 \le a_i, x \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5 3
1 2 2 4 7
2 3 7
```
Вывод:
```
2 -1 5
```

### Пример 2

Ввод:
```
1 1
5
5
```
Вывод:
```
1
```
