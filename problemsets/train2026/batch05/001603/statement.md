# Максимальная сумма пар

В списке чётное число элементов `n`. Элемент на позиции `i` (с нуля) считается парным к элементу на позиции `n - 1 - i`. Найдите наибольшую сумму парных элементов.

## Входные данные
В первой строке чётное число `n` (`2 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
Максимальная сумма пары.

## Примеры

### Пример 1

Ввод:
```
4
5 4 2 1
```

Вывод:
```
6
```

### Пример 2

Ввод:
```
2
4 2
```

Вывод:
```
6
```
