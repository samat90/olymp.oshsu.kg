# Дерево поиска

Есть n ключей в порядке возрастания, к ключу i обращаются f_i раз. Из них строят двоичное дерево поиска. Стоимость дерева равна сумме f_i·d_i, где d_i — глубина ключа (корень имеет глубину 1). Найдите наименьшую возможную стоимость.

**Ввод.** В первой строке n (1 ≤ n ≤ 150), во второй n чисел f_i (1 ≤ f_i ≤ 1000).

**Вывод.** Наименьшая стоимость.

**Пример**

Ввод:
```
3
34 8 50
```
Вывод:
```
142
```
