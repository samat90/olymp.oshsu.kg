Среди $n$ участников олимпиады найдите двух, чей рост отличается меньше всего, и выведите эту разность.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ целых чисел (рост).

## Формат вывода

Выведите минимальную разность между двумя разными участниками (индексами).

## Ограничения

$2 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
4
170 150 181 172
```
Вывод:
```
2
```

### Пример 2

Ввод:
```
3
5 5 9
```
Вывод:
```
0
```
