# Клумбы без соседей

Садовник Адилет засаживает цветами клетки прямоугольной клумбы n×m: в каждой клетке либо цветок, либо пусто. Цветы нельзя сажать в клетках, имеющих общую сторону. Сколько существует способов засадить клумбу (пустая клумба тоже способ)?

**Ввод.** Два числа n и m (1 ≤ n ≤ 200, 1 ≤ m ≤ 10).

**Вывод.** Число способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
2 3
```
Вывод:
```
17
```
