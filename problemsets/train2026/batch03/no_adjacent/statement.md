# Без соседей

Дана строка. Можно ли переставить её буквы так, чтобы никакие две одинаковые буквы не стояли рядом?

## Вход

Одна строка из строчных латинских букв, длина от 1 до 200000.

## Выход

`YES` или `NO`.

## Пример 1

**Вход**
```
aab
```

**Выход**
```
YES
```

## Пример 2

**Вход**
```
aaab
```

**Выход**
```
NO
```
