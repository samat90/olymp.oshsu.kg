# Прыжки по камням

Темир стоит на первом из n камней. С камня i он может прыгнуть вперёд на любое число камней от 1 до a_i. Какое наименьшее число прыжков нужно, чтобы добраться до последнего камня? Если это невозможно, выведите −1.

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (0 ≤ a_i ≤ 1000).

**Вывод.** Наименьшее число прыжков или −1.

**Пример**

Ввод:
```
5
2 3 1 1 4
```
Вывод:
```
2
```
