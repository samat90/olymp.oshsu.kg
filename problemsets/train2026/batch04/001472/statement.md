Посчитайте число пар индексов $i < j$, для которых $a_i + a_j = K$.

## Формат ввода

В первой строке даны $n$ и $K$. Во второй — массив.

## Формат вывода

Выведите количество пар.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i, K \le 2 \cdot 10^9$.

## Примеры

### Пример 1

Ввод:
```
5 6
1 5 3 3 3
```
Вывод:
```
4
```

### Пример 2

Ввод:
```
2 4
1 2
```
Вывод:
```
0
```
