# Следующий больший

Для каждого элемента массива найдите ближайший справа элемент, который строго больше него.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
`n` чисел через пробел: для каждой позиции значение ближайшего большего справа элемента или `-1`, если такого нет.

## Примеры

### Пример 1

Ввод:
```
5
2 1 5 3 4
```

Вывод:
```
5 5 -1 4 -1
```

### Пример 2

Ввод:
```
3
3 3 3
```

Вывод:
```
-1 -1 -1
```
