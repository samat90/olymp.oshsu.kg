# Ферзь в углу

Ферзь стоит на клетке `(x, y)` бесконечной доски. За ход его можно сдвинуть влево на любое число клеток, вниз на любое число клеток или по диагонали влево-вниз на любое число клеток (оба сдвига равны). Нельзя выйти за границу `x ≥ 0`, `y ≥ 0`. Кто поставит ферзя в `(0, 0)`, выиграл. Первым ходит Айбек. Определите победителя для нескольких позиций.

**Ввод.** `t` (`1 ≤ t ≤ 10^5`) и `t` строк `x y` (`0 ≤ x, y ≤ 10^6`, позиция не `(0, 0)`).

**Вывод.** Для каждой позиции `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
3
1 2
3 5
4 7
```

Вывод:
```
Бермет
Бермет
Бермет
```
