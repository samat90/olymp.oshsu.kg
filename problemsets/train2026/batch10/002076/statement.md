# Сломанная клавиатура

На сломанной клавиатуре клавиши `[` и `]` не печатают символ, а нажимают Home и End: `[` переносит курсор в начало текста, `]` — в конец. Остальные символы вставляются в позицию курсора, и курсор сдвигается за вставленный символ. Выведите итоговый текст.

**Ввод.** Строка длиной `n` (`1 ≤ n ≤ 10^6`) без пробелов: строчные буквы, `[` и `]`.

**Вывод.** Итоговый текст.

## Пример 1

Ввод:
```
ab[cd]ef
```

Вывод:
```
cdabef
```

## Пример 2

Ввод:
```
[[x]y[z
```

Вывод:
```
zxy
```
