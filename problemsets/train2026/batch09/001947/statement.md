# Китайская теорема об остатках

Найдите наименьшее целое $x \ge 0$, для которого одновременно выполняется $x \equiv r_i \pmod{m_i}$ для всех $i$. Модули не обязательно взаимно просты.

**Ввод.** В первой строке $n$ ($1 \le n \le 20$). В следующих $n$ строках пары $r_i, m_i$ ($0 \le r_i < m_i \le 10^9$). Гарантируется, что НОК всех модулей не превосходит $10^{18}$.

**Вывод.** Число $x$ или `-1`, если решения нет.

### Пример 1

Ввод:
```
2
1 4
3 6
```

Вывод:
```
9
```

### Пример 2

Ввод:
```
2
1 4
2 6
```

Вывод:
```
-1
```
