# Кружки для всех

В школе n учеников (номера 1…n) и m кружков. В кружок j ходят некоторые ученики. Какое наименьшее число кружков нужно выбрать, чтобы каждый ученик ходил хотя бы в один из них? Если это невозможно, выведите −1.

**Ввод.** В первой строке n и m (1 ≤ n ≤ 16, 1 ≤ m ≤ 20). Далее m строк: число учеников в кружке, затем их номера.

**Вывод.** Наименьшее число кружков или −1.

**Пример**

Ввод:
```
4 3
2 1 2
2 2 3
2 3 4
```
Вывод:
```
2
```
