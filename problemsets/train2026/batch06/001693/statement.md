# Распил бревна

Бревно длиной L нужно распилить в m заданных точках p_1…p_m (расстояния от левого конца). Один распил стоит столько, какова длина пилимого в этот момент куска. Порядок распилов выбирает Темир. Какова наименьшая суммарная стоимость?

**Ввод.** В первой строке L и m (2 ≤ L ≤ 10^6, 1 ≤ m ≤ 100). Во второй m различных чисел p_i (1 ≤ p_i < L).

**Вывод.** Наименьшая суммарная стоимость.

**Пример**

Ввод:
```
10 3
2 4 7
```
Вывод:
```
20
```
