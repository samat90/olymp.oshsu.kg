# Соединить все пункты

На плоскости $n$ пунктов с целыми координатами. Соединить два пункта прямым кабелем стоит $|x_1-x_2|+|y_1-y_2|$. Найдите наименьшую стоимость, при которой все пункты связаны друг с другом (напрямую или через другие).

**Ввод.** В первой строке $n$ ($1 \le n \le 1500$). Далее $n$ строк $x\ y$ ($|x|,|y| \le 10^6$).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5
0 0
2 2
3 10
5 2
7 0
```

**Вывод**
```
20
```
