# Расстановка ферзей: первая

Расстановку `n` ферзей на доске `n × n`, где никто никого не бьёт, можно записать как перестановку `p_1…p_n`: `p_i` — столбец ферзя в строке `i`. Выведите лексикографически наименьшую такую расстановку или `-1`, если её нет.

**Ввод.** `n` (`1 ≤ n ≤ 28`).

**Вывод.** `n` чисел через пробел или `-1`.

## Пример 1

Ввод:
```
4
```

Вывод:
```
2 4 1 3
```

## Пример 2

Ввод:
```
3
```

Вывод:
```
-1
```
