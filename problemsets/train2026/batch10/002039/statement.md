# Пересечение двух прямоугольников

Два прямоугольника со сторонами, параллельными осям, заданы левым нижним и правым верхним углами. Найдите площадь их общей части.

**Ввод.** Две строки `x1 y1 x2 y2` (`x1 < x2`, `y1 < y2`, `|·| ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
0 0 4 4
2 1 6 3
```

Вывод:
```
4
```

## Пример 2

Ввод:
```
0 0 1 1
5 5 6 6
```

Вывод:
```
0
```
