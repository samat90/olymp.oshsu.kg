Дана перестановка чисел от 0 до $n-1$. Её режут на несколько подряд идущих кусков, каждый кусок сортируют отдельно, а потом склеивают в исходном порядке кусков. На сколько кусков наибольшее число можно разрезать, чтобы в результате получился отсортированный массив?

## Формат ввода

В первой строке дано $n$. Во второй — перестановка чисел от 0 до $n-1$.

## Формат вывода

Выведите наибольшее число кусков.

## Ограничения

$1 \le n \le 2 \cdot 10^5$.

## Примеры

### Пример 1

Ввод:
```
5
1 0 2 4 3
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
3
2 1 0
```
Вывод:
```
1
```
