# Наибольший прямоугольник из единиц

В таблице из нулей и единиц найдите прямоугольник наибольшей площади, целиком состоящий из единиц. Выведите его площадь (0, если единиц нет).

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 700`) и `n` строк по `m` символов `0`/`1`.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3 4
1011
1111
0110
```

Вывод:
```
4
```
