# Не больше половины

Есть несколько куч камней. За ход игрок выбирает кучу из `s ≥ 2` камней и забирает из неё от 1 до `⌊s/2⌋` камней. Куча из одного камня неприкосновенна. Кто не может сделать ход, проиграл. Айбек ходит первым. Кто выиграет?

**Ввод.** `k` (`1 ≤ k ≤ 10^5`) и размеры куч `s_i` (`1 ≤ s_i ≤ 1500`).

**Вывод.** `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
1
2
```

Вывод:
```
Айбек
```

## Пример 2

Ввод:
```
2
3 3
```

Вывод:
```
Бермет
```
