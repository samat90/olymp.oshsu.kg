# Пропускная способность сети

Сеть из $n$ узлов и $m$ направленных каналов: канал $a \to b$ пропускает не более $c$ единиц данных в секунду. Какое наибольшее количество данных в секунду можно передавать из узла $1$ в узел $n$ (по любым путям одновременно)?

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 100$, $0 \le m \le 600$). Далее $m$ строк $a\ b\ c$ ($1 \le c \le 10^6$, $a \ne b$).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
4 5
1 2 3
1 3 2
2 3 1
2 4 2
3 4 3
```

**Вывод**
```
5
```
