# Вычесть цифру

Игроки по очереди вычитают из числа одну из его ненулевых цифр. Первым ходит Айбек. Кто не может сделать ход (число стало 0), проиграл. Для нескольких стартовых чисел определите победителя.

**Ввод.** `t` (`1 ≤ t ≤ 10^5`) и `t` чисел `n` (`0 ≤ n ≤ 300000`).

**Вывод.** Для каждого числа `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
4
1
10
21
100
```

Вывод:
```
Айбек
Бермет
Айбек
Бермет
```
