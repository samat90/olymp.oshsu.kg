# Сколько раз встречается как подпоследовательность

Сколькими способами из слова s можно вычеркнуть буквы так, чтобы осталось слово t? Способы различаются набором оставшихся позиций.

**Ввод.** Две строки s и t из строчных латинских букв, |s| ≤ 2000, |t| ≤ 1000, длины не меньше 1.

**Вывод.** Число способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
rabbbit
rabbit
```
Вывод:
```
3
```
