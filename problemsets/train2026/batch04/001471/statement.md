Дан массив из нулей и единиц. Для каждого запроса $k$ найдите номер (с единицы) позиции, на которой стоит $k$-я по счёту единица, либо -1, если единиц меньше $k$.

## Формат ввода

В первой строке даны $n$ и $q$. Во второй — массив. В третьей — $q$ значений $k$.

## Формат вывода

Выведите ответы через пробел.

## Ограничения

$1 \le n, q \le 2 \cdot 10^5$, $1 \le k \le n$.

## Примеры

### Пример 1

Ввод:
```
6 3
0 1 1 0 1 0
1 3 4
```
Вывод:
```
2 5 -1
```

### Пример 2

Ввод:
```
1 1
0
1
```
Вывод:
```
-1
```
