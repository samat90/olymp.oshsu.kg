# Ход в 2048

Поле `n × n` игры, подобной 2048, заполнено числами (0 — пусто). Ход: все числа сдвигаются до упора в выбранную сторону (`L`, `R`, `U`, `D`), при этом две соседние (после сдвига) одинаковые плитки, ближайшие к стороне сдвига, сливаются в одну с удвоенным значением; каждая плитка сливается не более раза за ход, пары образуются начиная со стороны сдвига. Выведите поле после хода.

**Ввод.** `n` (`1 ≤ n ≤ 300`), затем `n` строк по `n` чисел (`0 ≤ a ≤ 10^9`) и последней строкой — буква хода.

**Вывод.** Поле после хода.

## Пример 1

Ввод:
```
4
2 2 2 0
4 4 0 8
0 0 0 0
2 0 2 2
L
```

Вывод:
```
4 2 0 0
8 8 0 0
0 0 0 0
4 2 0 0
```
