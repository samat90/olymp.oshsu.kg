# Перестановка по знакам

Задана строка из `n-1` символов `I` и `D`. Символ `I` на позиции `i` означает, что `p_i < p_{i+1}`, а `D` — что `p_i > p_{i+1}`. Выведите лексикографически наименьшую перестановку чисел `1…n`, удовлетворяющую строке.

**Ввод.** `n` (`2 ≤ n ≤ 10^6`) и строка длины `n-1`.

**Вывод.** `n` чисел через пробел.

## Пример 1

Ввод:
```
4
IDI
```

Вывод:
```
1 3 2 4
```

## Пример 2

Ввод:
```
3
DD
```

Вывод:
```
3 2 1
```
