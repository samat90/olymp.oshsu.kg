# Покраска забора

Забор из n досок сначала не покрашен (цвет 0). Маляр выполняет q покрасок: «l r c» — доски с l по r перекрашиваются в цвет c. Выведите итоговые цвета всех досок.

**Ввод.** В первой строке n и q. Затем q строк l r c. 1 ≤ n, q ≤ 100000, 1 ≤ l ≤ r ≤ n, 1 ≤ c ≤ 10⁶.

**Вывод.** n чисел через пробел.

## Примеры

**Ввод 1**
```
5 3
1 3 1
2 5 2
4 4 3
```
**Вывод 1**
```
1 2 2 3 2
```
