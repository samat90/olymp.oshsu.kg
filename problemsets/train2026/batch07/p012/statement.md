# Король на карте

Карта — таблица $h \times w$: `.` — свободная клетка, `#` — преграда. Король ходит как в шахматах: в любую из восьми соседних клеток (включая диагонали), если она свободна. Найдите наименьшее число ходов из левой верхней клетки в правую нижнюю.

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 3\cdot 10^5$). Далее $h$ строк по $w$ символов. Левая верхняя и правая нижняя клетки свободны.

**Вывод.** Число ходов или $-1$.

### Пример 1

**Ввод**
```
3 3
.#.
#.#
...
```

**Вывод**
```
2
```
