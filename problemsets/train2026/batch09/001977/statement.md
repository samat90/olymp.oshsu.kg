# Кто первым выбросит орла

Азамат и Айгуль по очереди подбрасывают монету, Азамат первый. Вероятность орла равна $a/b$. Выигрывает тот, у кого первым выпадет орёл. Найдите вероятность победы Азамата. Выведите её в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Два числа $a$ и $b$ ($1 \le a \le b \le 10^9$, $b$ не делится на $10^9+7$).

**Вывод.** Вероятность по модулю $10^9+7$.

### Пример 1

Ввод:
```
1 2
```

Вывод:
```
666666672
```
