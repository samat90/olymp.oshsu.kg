# Ним наоборот

Правила нима, но проигрывает тот, кто берёт последний камень. Айбек ходит первым. Кто выигрывает при оптимальной игре?

**Ввод.** `n` (`1 ≤ n ≤ 10^5`) и размеры куч `a_i` (`0 ≤ a_i ≤ 10^9`). Хотя бы одна куча непуста.

**Вывод.** `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
3
1 1 1
```

Вывод:
```
Бермет
```

## Пример 2

Ввод:
```
2
1 2
```

Вывод:
```
Айбек
```
