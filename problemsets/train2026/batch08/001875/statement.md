# Сколько деревьев поиска

Сколько существует различных по форме деревьев поиска, содержащих n различных ключей? Выведите остаток от деления на 1000000007.

**Ввод.** Одно число n, 1 ≤ n ≤ 100000.

**Вывод.** Ответ по модулю 1000000007.

## Примеры

**Ввод 1**
```
3
```
**Вывод 1**
```
5
```

**Ввод 2**
```
1
```
**Вывод 2**
```
1
```
