# Обеды в столовой

В столовой лежит стопка бутербродов (сверху вниз): `0` - с сыром, `1` - с колбасой. В очереди стоят `n` студентов, каждый хочет только свой тип. Если первый в очереди хочет верхний бутерброд, он берёт его и уходит, иначе уходит в конец очереди. Так продолжается, пока кто-то может взять. Сколько студентов останутся голодными?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` значений - что хотят студенты в порядке очереди. В третьей строке `n` значений - бутерброды сверху вниз.

## Выходные данные
Число студентов, оставшихся без обеда.

## Примеры

### Пример 1

Ввод:
```
4
1 1 0 0
0 1 0 1
```

Вывод:
```
0
```

### Пример 2

Ввод:
```
3
1 1 1
0 0 1
```

Вывод:
```
3
```
