# Заправки на трассе

Машина едет по трассе Бишкек - Ош в одном направлении. До цели `T` километров, в начале в баке хватает топлива на `F` километров. Вдоль пути есть `n` заправок: на заправке `i` на расстоянии `x_i` от старта можно взять `f_i` километров хода (всё сразу). Бак не ограничен. Какое наименьшее число остановок на заправках нужно, чтобы доехать? Если доехать нельзя, выведите `-1`.

## Входные данные
В первой строке числа `T`, `F`, `n` (`1 ≤ T ≤ 10^9`, `0 ≤ F ≤ 10^9`, `0 ≤ n ≤ 200000`). Далее `n` строк `x_i f_i` в порядке возрастания `x_i` (`0 < x_i < T`, `1 ≤ f_i ≤ 10^9`).

## Выходные данные
Минимальное число остановок или `-1`.

## Примеры

### Пример 1

Ввод:
```
100 10 4
10 60
20 30
30 30
60 40
```

Вывод:
```
2
```

### Пример 2

Ввод:
```
100 50 0
```

Вывод:
```
-1
```

### Пример 3

Ввод:
```
100 1 1
10 100
```

Вывод:
```
-1
```
