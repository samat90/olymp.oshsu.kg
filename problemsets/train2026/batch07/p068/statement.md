# Обход всех сёл

Связный граф из $n$ вершин. Найдите длину наименьшего маршрута (в рёбрах), который побывает в каждой вершине хотя бы раз. Начать и закончить можно в любых вершинах; вершины и рёбра можно использовать повторно.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 12$, $0 \le m \le 66$). Далее $m$ пар $a\ b$. Граф связный.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
4 3
1 2
1 3
1 4
```

**Вывод**
```
4
```
