# Номер перестановки

Все перестановки чисел $1, \dots, n$ выписаны в лексикографическом порядке. Сколько перестановок идут раньше заданной перестановки? Ответ по модулю $10^9+7$.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$), во второй — перестановка.

**Вывод.** Количество предшествующих перестановок по модулю $10^9+7$.

### Пример 1

Ввод:
```
3
2 3 1
```

Вывод:
```
3
```
