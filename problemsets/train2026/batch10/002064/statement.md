# Круг Эрмека

`n` детей стоят по кругу и пронумерованы от 1 до `n`. Считают с первого ребёнка: каждый `k`-й по счёту выбывает, счёт продолжается со следующего. Выведите номер последнего оставшегося.

**Ввод.** `n` и `k` (`1 ≤ n ≤ 10^6`, `1 ≤ k ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
5 2
```

Вывод:
```
3
```

## Пример 2

Ввод:
```
7 3
```

Вывод:
```
4
```
