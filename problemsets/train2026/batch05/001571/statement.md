# Слияние списков

Есть `m` списков чисел, каждый уже отсортирован по неубыванию. Объедините их в один отсортированный список.

## Входные данные
В первой строке число `m` (`1 ≤ m ≤ 10000`). Далее `m` строк: в каждой сначала длина списка `l_i` (`0 ≤ l_i`), затем `l_i` чисел по неубыванию. Общее число элементов не больше 200000, элементы по модулю не больше 10^9.

## Выходные данные
Все числа в порядке неубывания через пробел (если чисел нет - пустая строка).

## Примеры

### Пример 1

Ввод:
```
3
3 1 4 7
2 2 6
1 5
```

Вывод:
```
1 2 4 5 6 7
```
