# Определитель по модулю

Найдите определитель квадратной матрицы `n × n` по модулю `10^9 + 7` (результат от 0 до `10^9+6`).

**Ввод.** `n` (`1 ≤ n ≤ 100`) и матрица (`|a| ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
2
1 2
3 4
```

Вывод:
```
1000000005
```

## Пример 2

Ввод:
```
3
2 0 0
0 3 0
0 0 4
```

Вывод:
```
24
```
