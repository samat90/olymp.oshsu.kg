# Три вида скобок

Айгерим проверяет записи в тетради. Строка состоит из скобок `(`, `)`, `[`, `]`, `{`, `}`. Скобочная последовательность правильная, если каждая открывающая скобка закрывается скобкой того же вида и вложенность не нарушена.

## Входные данные
Одна строка длиной от 1 до 100000 из символов `()[]{}`.

## Выходные данные
`YES`, если последовательность правильная, иначе `NO`.

## Примеры

### Пример 1

Ввод:
```
([]{})
```

Вывод:
```
YES
```

### Пример 2

Ввод:
```
([)]
```

Вывод:
```
NO
```

### Пример 3

Ввод:
```
((
```

Вывод:
```
NO
```
