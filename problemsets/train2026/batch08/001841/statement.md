# Самый тяжёлый путь

В вершинах дерева записаны числа (возможно, отрицательные). Найдите наибольшую сумму чисел на простом пути, содержащем хотя бы одну вершину.

**Ввод.** В первой строке n. Во второй — n чисел (по модулю не больше 1000). Затем n−1 строк с рёбрами. 1 ≤ n ≤ 100000.

**Вывод.** Наибольшая сумма.

## Примеры

**Ввод 1**
```
5
-3 4 -1 5 -2
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
5
```

**Ввод 2**
```
3
-5 -2 -7
1 2
2 3
```
**Вывод 2**
```
-2
```
