# Минимум предметов на точную сумму

Из n чисел нужно выбрать как можно меньше (каждое не более одного раза) так, чтобы их сумма была равна S. Какое наименьшее количество чисел потребуется? Если набрать S нельзя, выведите −1.

**Ввод.** В первой строке n и S (1 ≤ n ≤ 100, 1 ≤ S ≤ 10^4), во второй n чисел a_i (1 ≤ a_i ≤ 10^4).

**Вывод.** Наименьшее количество чисел или −1.

**Пример**

Ввод:
```
5 9
2 3 4 5 6
```
Вывод:
```
2
```
