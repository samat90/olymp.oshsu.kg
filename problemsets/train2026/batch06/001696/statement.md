# Путь через все точки

Пастух Улан должен обойти n пастбищ, посетив каждое ровно один раз; начать и закончить можно на любых. Дано время d_ij перехода с пастбища i на пастбище j. Найдите наименьшее суммарное время пути.

**Ввод.** В первой строке n (1 ≤ n ≤ 13), далее n строк по n чисел d_ij (1 ≤ d_ij ≤ 100; диагональ игнорируется).

**Вывод.** Наименьшее суммарное время.

**Пример**

Ввод:
```
3
0 5 9
5 0 4
9 4 0
```
Вывод:
```
9
```
