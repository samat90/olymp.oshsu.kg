# Циклы случайной перестановки

Перестановка чисел $1, \dots, n$ выбирается случайно. Найдите математическое ожидание числа её циклов в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Одно число $n$ ($1 \le n \le 10^6$).

**Вывод.** Ответ по модулю $10^9+7$.

### Пример 1

Ввод:
```
3
```

Вывод:
```
833333341
```
