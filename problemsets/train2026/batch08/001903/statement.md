# Разные числа на отрезке

Дан массив из n чисел и q запросов «l r». Для каждого найдите, сколько различных значений среди aₗ, …, aᵣ.

**Ввод.** В первой строке n и q. Во второй — n чисел. Затем q строк l r. 1 ≤ n, q ≤ 100000, 1 ≤ aᵢ ≤ 10⁹.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
5 3
1 2 1 3 2
1 3
2 5
4 4
```
**Вывод 1**
```
2
3
1
```
