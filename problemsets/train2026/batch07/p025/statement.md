# Прыжки по камням

На камнях через реку написаны числа $a_1, \dots, a_n$. С камня $i$ можно прыгнуть на соседний камень ($i-1$ или $i+1$) или на любой другой камень с тем же числом. Какое наименьшее число прыжков нужно, чтобы добраться с камня $1$ на камень $n$?

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Во второй — $n$ чисел $a_i$ ($1 \le a_i \le 10^9$).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
8
7 3 5 7 5 1 3 9
```

**Вывод**
```
3
```
