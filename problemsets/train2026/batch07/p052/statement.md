# Способы разделить на команды

Среди $n$ школьников есть $m$ пар друзей. Нужно раздать каждому школьнику цвет «красный» или «синий» так, чтобы друзья получили разные цвета. Сколькими способами это можно сделать? Ответ выведите по модулю $10^9+7$.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
6 3
1 2
2 3
4 5
```

**Вывод**
```
8
```
