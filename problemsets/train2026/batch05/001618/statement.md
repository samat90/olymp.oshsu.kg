# Столкновение астероидов

Астероиды летят по одной прямой с одинаковой скоростью. Знак числа - направление (плюс вправо, минус влево), модуль - размер. Два астероида, летящие навстречу друг другу, сталкиваются: меньший исчезает, при равных размерах исчезают оба. Астероиды, летящие в одну сторону, не сталкиваются. Какие астероиды останутся?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` ненулевых целых чисел, по модулю не больше 10^9.

## Выходные данные
Оставшиеся астероиды слева направо через пробел или `ПУСТО`.

## Примеры

### Пример 1

Ввод:
```
5
5 10 -5 3 -8
```

Вывод:
```
5 10
```

### Пример 2

Ввод:
```
3
-2 -1 1
```

Вывод:
```
-2 -1 1
```
