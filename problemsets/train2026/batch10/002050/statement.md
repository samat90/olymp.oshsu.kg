# Камни и ограничение

Айбек и Бермет берут камни из одной кучи, Айбек первый. За ход можно взять от 1 до `k` камней. Выигрывает тот, кто возьмёт последний камень. Для каждой игры определите победителя.

**Ввод.** `t` (`1 ≤ t ≤ 10^5`) и `t` строк `n k` (`1 ≤ n ≤ 10^18`, `1 ≤ k ≤ 10^18`).

**Вывод.** Для каждой игры `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
3
10 3
8 3
5 10
```

Вывод:
```
Айбек
Бермет
Айбек
```
