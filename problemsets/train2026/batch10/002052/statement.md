# Дробление куч

Перед Айбеком и Берметом лежат кучи камней. За ход игрок выбирает кучу и делит её на две непустые кучи разного размера. Кто не может сделать ход, проиграл. Айбек ходит первым. Кто выиграет?

**Ввод.** `k` (`1 ≤ k ≤ 10^5`) и размеры куч `a_i` (`1 ≤ a_i ≤ 1000`).

**Вывод.** `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
1
5
```

Вывод:
```
Айбек
```

## Пример 2

Ввод:
```
2
3 4
```

Вывод:
```
Айбек
```
