# Эйлеров обход

В графе $n$ вершин и $m$ рёбер. Можно ли пройти по каждому ребру ровно один раз? Если можно вернуться в начальную вершину, ответ `CIRCUIT`; если можно, но нельзя вернуться — `PATH`; иначе `NO`. Если рёбер нет, ответ `CIRCUIT`.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$ (различные, $a \ne b$).

**Вывод.** `CIRCUIT`, `PATH` или `NO`.

### Пример 1

**Ввод**
```
4 5
1 2
2 3
3 1
3 4
4 2
```

**Вывод**
```
PATH
```
