Спортзал в Бишкеке заказали $n$ секций: $i$-я хочет занять зал с момента $l_i$ до момента $r_i$. Секции нельзя проводить одновременно; если одна заканчивается в момент, когда другая начинается, конфликта нет. Какое наибольшее число секций можно провести?

## Формат ввода

В первой строке дано $n$. Далее $n$ строк с парой $l_i$, $r_i$.

## Формат вывода

Выведите наибольшее число секций.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le l_i < r_i \le 2 \cdot 10^9$.

## Примеры

### Пример 1

Ввод:
```
4
1 3
2 5
3 6
6 8
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
2
1 4
2 3
```
Вывод:
```
1
```
