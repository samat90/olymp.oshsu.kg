Спортсмены стоят в шеренге, у каждого есть рост. Сначала шеренгу перестраивают по росту (по неубыванию). Сколько позиций после этого получат спортсмена другого роста, чем стоял на ней раньше?

## Формат ввода

В первой строке дано $n$. Во второй — $n$ значений роста.

## Формат вывода

Выведите количество позиций, на которых значение до и после сортировки различается.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5
1 3 2 4 5
```
Вывод:
```
2
```

### Пример 2

Ввод:
```
3
2 2 2
```
Вывод:
```
0
```
