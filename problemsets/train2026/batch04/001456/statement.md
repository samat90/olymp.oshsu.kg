В магазине в Оше цены товаров отсортированы по неубыванию. Покупатель задаёт запросы: сколько товаров стоит от $l$ до $r$ сомов включительно?

## Формат ввода

В первой строке даны $n$ и $q$. Во второй — цены. Далее $q$ строк по два числа $l$ и $r$.

## Формат вывода

Для каждого запроса выведите ответ через пробел.

## Ограничения

$1 \le n, q \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$, $0 \le l \le r \le 10^9+1$.

## Примеры

### Пример 1

Ввод:
```
5 2
1 3 3 8 10
3 8
4 7
```
Вывод:
```
3 0
```

### Пример 2

Ввод:
```
1 1
5
6 9
```
Вывод:
```
0
```
