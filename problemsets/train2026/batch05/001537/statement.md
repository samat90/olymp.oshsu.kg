# Схлопывание строки

Даны строка из строчных латинских букв. Пока в ней есть две одинаковые соседние буквы, обе удаляются. Какая строка получится в конце?

## Входные данные
Одна строка длиной от 1 до 200000.

## Выходные данные
Итоговая строка, а если она пустая - слово `ПУСТО`.

## Примеры

### Пример 1

Ввод:
```
abba
```

Вывод:
```
ПУСТО
```

### Пример 2

Ввод:
```
aabbcd
```

Вывод:
```
cd
```

### Пример 3

Ввод:
```
abab
```

Вывод:
```
abab
```
