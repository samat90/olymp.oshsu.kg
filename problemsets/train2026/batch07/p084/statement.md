# Одинаковые метки в ветвях

Дерево из $n$ узлов с корнем $1$. У каждого узла есть метка — строчная латинская буква. Для каждого узла найдите, сколько узлов в его ветви (включая сам узел) имеют ту же метку, что и он.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Во второй — строка из $n$ букв, $i$-я — метка узла $i$. Далее $n-1$ строка с парами $a\ b$.

**Вывод.** $n$ чисел через пробел.

### Пример 1

**Ввод**
```
5
abaab
1 2
1 3
2 4
2 5
```

**Вывод**
```
3 2 1 1 1
```
