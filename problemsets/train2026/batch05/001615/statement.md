# Частотный стек

Реализуйте стек с командами `push x` и `pop`. Команда `pop` убирает и выводит самый частый элемент стека (по числу вхождений в стеке сейчас). Если таких несколько, убирается тот, который положили позже других таких (ближе к вершине). Команда `pop` даётся только при непустом стеке.

## Входные данные
В первой строке число команд `q` (`1 ≤ q ≤ 200000`), далее `q` строк. Числа `x` от 0 до 10^9.

## Выходные данные
Результаты команд `pop`, каждый в своей строке.

## Примеры

### Пример 1

Ввод:
```
7
push 5
push 7
push 5
push 7
push 4
push 5
pop
```

Вывод:
```
5
```
