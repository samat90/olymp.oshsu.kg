# Самый большой квадрат

Дано поле n×m из нулей и единиц. Найдите наибольший по площади квадрат, целиком состоящий из единиц.

**Ввод.** В первой строке n и m (1 ≤ n, m ≤ 500), далее n строк по m символов 0 или 1.

**Вывод.** Площадь квадрата (0, если единиц нет).

**Пример**

Ввод:
```
3 4
0110
1111
0111
```
Вывод:
```
4
```
