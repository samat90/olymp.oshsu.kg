Дан массив различных чисел. Посчитайте, сколько есть упорядоченных пар $(i, j)$, для которых $a_j - a_i = d$.

## Формат ввода

В первой строке даны $n$ и $d$. Во второй — $n$ различных чисел.

## Формат вывода

Выведите количество пар.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le d, a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5 2
1 5 3 4 6
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
2 5
1 2
```
Вывод:
```
0
```
