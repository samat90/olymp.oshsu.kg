# Сумма расстояний до всех

Для каждой вершины дерева найдите сумму расстояний от неё до всех остальных вершин.

**Ввод.** В первой строке n. Затем n−1 строк с рёбрами. 1 ≤ n ≤ 100000.

**Вывод.** n чисел — ответы для вершин 1, 2, …, n.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
7 10 6 7 10
```
