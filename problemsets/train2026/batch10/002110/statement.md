# Расстановка ферзей: количество

Сколькими способами можно расставить `n` ферзей на шахматной доске `n × n` так, чтобы никакие два не били друг друга?

**Ввод.** `n` (`1 ≤ n ≤ 11`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
4
```

Вывод:
```
2
```

## Пример 2

Ввод:
```
6
```

Вывод:
```
4
```
