# Оставить и пропустить

Идём по списку: оставляем первые `m` элементов, затем удаляем следующие `n` элементов, снова оставляем `m`, удаляем `n` и так до конца списка.

## Входные данные
В первой строке числа `len`, `m`, `n` (`1 ≤ len ≤ 200000`, `1 ≤ m, n ≤ 200000`). Во второй строке `len` целых чисел.

## Выходные данные
Оставшиеся элементы через пробел.

## Примеры

### Пример 1

Ввод:
```
8 2 3
1 2 3 4 5 6 7 8
```

Вывод:
```
1 2 6 7
```

### Пример 2

Ввод:
```
5 1 1
1 2 3 4 5
```

Вывод:
```
1 3 5
```
