# Стек с прибавкой

Стек вмещает не больше `cap` чисел. Команды:

- `push x` - положить число; если стек полон, команда игнорируется;
- `pop` - убрать верхнее число и вывести его, а если стек пуст, вывести `-1`;
- `inc k v` - прибавить `v` к нижним `k` числам стека (если в стеке меньше `k` чисел, ко всем).

## Входные данные
В первой строке числа `cap` и `q` (`1 ≤ cap, q ≤ 200000`), далее `q` строк с командами. Числа по модулю не больше 10^9.

## Выходные данные
Результаты команд `pop`, каждый в своей строке.

## Примеры

### Пример 1

Ввод:
```
3 7
push 1
push 2
inc 2 10
pop
pop
pop
push 4
```

Вывод:
```
12
11
-1
```

### Пример 2

Ввод:
```
1 3
push 1
push 2
pop
```

Вывод:
```
1
```
