# Максимум в окне

Окно ширины `k` скользит по массиву слева направо. Для каждого положения окна найдите максимум в нём.

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ k ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
`n - k + 1` чисел через пробел.

## Примеры

### Пример 1

Ввод:
```
8 3
1 3 -1 -3 5 3 6 7
```

Вывод:
```
3 3 5 5 6 7
```

### Пример 2

Ввод:
```
3 1
4 2 9
```

Вывод:
```
4 2 9
```
