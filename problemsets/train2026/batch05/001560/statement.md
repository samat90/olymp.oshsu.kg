# Карточный фокус

Фокусник держит колоду из `n` карт. Он повторяет: открывает верхнюю карту и кладёт её на стол, затем следующую верхнюю карту переносит вниз колоды. Так продолжается, пока колода не кончится (последняя карта просто открывается). В каком порядке карты лягут на стол?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел - карты колоды сверху вниз.

## Выходные данные
Порядок карт на столе через пробел.

## Примеры

### Пример 1

Ввод:
```
7
1 2 3 4 5 6 7
```

Вывод:
```
1 3 5 7 4 2 6
```

### Пример 2

Ввод:
```
1
9
```

Вывод:
```
9
```
