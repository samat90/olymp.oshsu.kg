# Наибольший AND пары

Найдите максимальное значение $a_i \,\&\, a_j$ (побитовое И) среди всех пар $i < j$.

**Ввод.** В первой строке $n$ ($2 \le n \le 2\cdot 10^5$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{30}$).

**Вывод.** Максимальное И.

### Пример 1

Ввод:
```
3
12 10 5
```

Вывод:
```
8
```
