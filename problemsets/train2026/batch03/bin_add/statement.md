# Двоичное сложение

Сложите два числа, записанных в двоичной системе.

## Вход

Две строки из `0` и `1` без ведущих нулей (число 0 записывается как `0`), длина каждой от 1 до 200000.

## Выход

Сумма в двоичной системе без ведущих нулей.

## Пример 1

**Вход**
```
11
1
```

**Выход**
```
100
```

## Пример 2

**Вход**
```
1010
1011
```

**Выход**
```
10101
```
