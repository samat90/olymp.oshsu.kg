# Предок ли

Дано дерево с корнем в вершине 1 и q запросов «является ли a предком b». Вершина считается предком самой себя.

**Ввод.** В первой строке n и q. Затем n−1 строк с рёбрами, затем q строк с запросами a b. 1 ≤ n, q ≤ 100000.

**Вывод.** Для каждого запроса YES или NO.

## Примеры

**Ввод 1**
```
5 3
1 2
1 3
3 4
4 5
3 5
2 5
4 4
```
**Вывод 1**
```
YES
NO
YES
```
