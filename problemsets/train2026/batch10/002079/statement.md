# Раздача конфет

Айгуль раздаёт `m` конфет `n` детям, стоящим по кругу. Первому — 1 конфету, второму — 2, третьему — 3 и так далее; после последнего ребёнка снова идёт первый, получая на 1 больше предыдущего. Если конфет не хватает на очередную порцию, последний ребёнок получает все оставшиеся. Сколько получил каждый?

**Ввод.** `n` и `m` (`1 ≤ n ≤ 10^5`, `0 ≤ m ≤ 10^18`).

**Вывод.** `n` чисел через пробел.

## Пример 1

Ввод:
```
3 10
```

Вывод:
```
5 2 3
```

## Пример 2

Ввод:
```
4 7
```

Вывод:
```
1 2 3 1
```
