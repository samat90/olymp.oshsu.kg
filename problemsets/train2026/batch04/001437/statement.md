Айгерим составляет словарь: сначала короткие слова, а слова одинаковой длины — по алфавиту (сравнение по кодам символов). Отсортируйте её слова.

## Формат ввода

В первой строке дано $n$. В следующих $n$ строках — по одному слову из строчных латинских букв.

## Формат вывода

Выведите слова по одному в строке в нужном порядке.

## Ограничения

$1 \le n \le 5 \cdot 10^4$, длина слова от 1 до 10.

## Примеры

### Пример 1

Ввод:
```
4
kg
osh
a
bs
```
Вывод:
```
a
bs
kg
osh
```

### Пример 2

Ввод:
```
3
zz
ab
zz
```
Вывод:
```
ab
zz
zz
```
