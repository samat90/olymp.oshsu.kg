# Рюкзак туриста

Турист Темир может унести в рюкзаке груз не тяжелее W. Есть n предметов, у предмета i вес w_i и ценность v_i. Каждый предмет можно взять не более одного раза. Какова наибольшая суммарная ценность?

**Ввод.** В первой строке n и W (1 ≤ n ≤ 100, 1 ≤ W ≤ 10^4), далее n строк по два числа w_i и v_i (1 ≤ w_i ≤ 10^4, 1 ≤ v_i ≤ 1000).

**Вывод.** Наибольшая суммарная ценность.

**Пример**

Ввод:
```
4 8
3 30
4 50
5 60
2 20
```
Вывод:
```
90
```
