# Контейнер с водой

Вертикальные доски стоят в точках `1, 2, …, n`, высота `i`-й равна `h_i`. Выберите две доски так, чтобы между ними поместилось как можно больше воды: площадь равна расстоянию между досками, умноженному на меньшую высоту. Выведите максимальную площадь.

**Ввод.** `n` (`2 ≤ n ≤ 10^5`) и `n` высот (`0 ≤ h ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
9
1 8 6 2 5 4 8 3 7
```

Вывод:
```
49
```
