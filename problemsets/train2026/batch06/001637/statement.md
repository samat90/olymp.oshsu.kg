# Отрезок с одним удалением

Дан массив из n чисел. Выберите непустой отрезок и, если хотите, удалите из него не более одного элемента (оставшиеся элементы должны остаться непустыми). Какова наибольшая возможная сумма оставшихся элементов?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (−1000 ≤ a_i ≤ 1000).

**Вывод.** Наибольшая сумма.

**Пример**

Ввод:
```
5
1 -2 0 3 -4
```
Вывод:
```
4
```
