# Короткий отрезок с суммой

Найдите длину самого короткого непрерывного отрезка массива, сумма которого не меньше `K`. Числа могут быть отрицательными.

## Входные данные
В первой строке числа `n` и `K` (`1 ≤ n ≤ 200000`, `1 ≤ K ≤ 10^9`). Во второй строке `n` целых чисел, по модулю не больше 10^5.

## Выходные данные
Наименьшая длина или `-1`, если такого отрезка нет.

## Примеры

### Пример 1

Ввод:
```
3 4
2 -1 3
```

Вывод:
```
3
```

### Пример 2

Ввод:
```
1 5
2
```

Вывод:
```
-1
```

### Пример 3

Ввод:
```
4 3
84 -37 32 40
```

Вывод:
```
1
```
