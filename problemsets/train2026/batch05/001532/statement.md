# Самый длинный правильный кусок

Дана строка из `(` и `)`. Найдите длину самой длинной подстроки (подряд идущих символов), которая является правильной скобочной последовательностью.

## Входные данные
Одна строка длиной от 1 до 200000.

## Выходные данные
Длина искомой подстроки (0, если правильных подстрок нет).

## Примеры

### Пример 1

Ввод:
```
(()
```

Вывод:
```
2
```

### Пример 2

Ввод:
```
)()())
```

Вывод:
```
4
```

### Пример 3

Ввод:
```
(((
```

Вывод:
```
0
```
