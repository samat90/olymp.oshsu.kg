# Дискретный логарифм

Найдите наименьшее целое $x \ge 0$, для которого $a^x \equiv b \pmod p$, или сообщите, что такого $x$ нет.

**Ввод.** Три числа $a$, $b$, $p$ ($1 \le a, b < p \le 10^9$, $p$ — простое).

**Вывод.** Число $x$ или `-1`.

### Пример 1

Ввод:
```
2 3 5
```

Вывод:
```
3
```

### Пример 2

Ввод:
```
4 1 7
```

Вывод:
```
0
```
