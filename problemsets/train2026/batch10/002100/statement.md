# Наибольший квадрат

В таблице из нулей и единиц найдите квадрат наибольшей стороны, целиком состоящий из единиц. Выведите длину его стороны (0, если единиц нет).

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 1000`) и `n` строк по `m` символов `0`/`1`.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3 4
0110
1111
1111
```

Вывод:
```
2
```

## Пример 2

Ввод:
```
2 2
00
00
```

Вывод:
```
0
```
