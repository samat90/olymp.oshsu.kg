# Полоска из клеток

Полоска состоит из `n` свободных клеток. За ход игрок закрашивает одну клетку или две соседние свободные клетки. Кто не может сделать ход, проиграл. Айбек ходит первым. Определите победителя для нескольких полосок.

**Ввод.** `t` (`1 ≤ t ≤ 10^5`) и `t` значений `n` (`1 ≤ n ≤ 2000`).

**Вывод.** Для каждого `n` слово `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
3
1
3
5
```

Вывод:
```
Айбек
Айбек
Айбек
```
