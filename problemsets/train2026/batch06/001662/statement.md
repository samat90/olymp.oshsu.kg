# Различные подпоследовательности

Сколько существует различных непустых слов, которые можно получить из слова s вычёркиванием нескольких букв (в том числе нуля)?

**Ввод.** Слово из строчных латинских букв длиной от 1 до 10^5.

**Вывод.** Количество по модулю 10^9 + 7.

**Пример**

Ввод:
```
aba
```
Вывод:
```
6
```
