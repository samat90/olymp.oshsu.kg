Подпоследовательность называется зигзагом, если разности соседних её элементов строго чередуют знак (плюс, минус, плюс… или минус, плюс, минус…). Последовательность из одного элемента — тоже зигзаг. Найдите длину наибольшего зигзага, который можно получить, вычеркнув часть элементов.

## Формат ввода

В первой строке дано $n$. Во второй — массив.

## Формат вывода

Выведите наибольшую длину.

## Ограничения

$1 \le n \le 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
6
1 7 4 9 2 5
```
Вывод:
```
6
```

### Пример 2

Ввод:
```
4
3 3 3 3
```
Вывод:
```
1
```
