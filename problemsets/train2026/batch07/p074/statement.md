# Запасной остов

Дан связный граф с весами рёбер. Остов — набор из $n-1$ рёбер, связывающий все вершины, его вес — сумма весов рёбер. Выпишем веса всех различных остовов (разные наборы рёбер) по неубыванию. Выведите второе число в этом списке.

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 200$, $n-1 \le m \le 1000$). Далее $m$ строк $a\ b\ w$ ($1 \le w \le 1000$). Граф связный, без кратных рёбер.

**Вывод.** Второе число списка или $-1$, если остов единственный (граф — дерево).

### Пример 1

**Ввод**
```
4 5
1 2 1
2 3 2
3 4 3
1 4 4
1 3 5
```

**Вывод**
```
7
```
