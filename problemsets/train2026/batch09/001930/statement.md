# Делители произведения

Дан массив из $n$ натуральных чисел. Сколько натуральных делителей у их произведения? Ответ выведите по модулю $10^9+7$.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$), во второй — $n$ чисел $a_i$ ($1 \le a_i \le 10^6$).

**Вывод.** Количество делителей произведения по модулю $10^9+7$.

### Пример 1

Ввод:
```
3
4 6 10
```

Вывод:
```
20
```
