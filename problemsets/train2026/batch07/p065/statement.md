# Город с малым числом соседей

В стране $n$ городов и $m$ двусторонних дорог с длинами. Для порога $T$ сосед города — любой другой город, до которого кратчайший путь не длиннее $T$. Найдите город с наименьшим числом соседей; при равенстве — город с наибольшим номером.

**Ввод.** В первой строке $n, m, T$ ($2 \le n \le 100$, $0 \le m \le 2000$, $1 \le T \le 10^6$). Далее $m$ строк $a\ b\ w$ ($1 \le w \le 10^5$).

**Вывод.** Номер города.

### Пример 1

**Ввод**
```
4 4 4
1 2 3
2 3 1
2 4 1
3 4 4
```

**Вывод**
```
4
```
