# Сумма на пути

В каждой вершине дерева записано число. Для q запросов найдите сумму чисел на пути между вершинами u и v (включая обе).

**Ввод.** В первой строке n и q. Во второй — n чисел a₁…aₙ (|aᵢ| ≤ 1000). Затем n−1 строк с рёбрами, затем q строк с запросами u v. 1 ≤ n, q ≤ 100000.

**Вывод.** Для каждого запроса — сумма в отдельной строке.

## Примеры

**Ввод 1**
```
5 2
1 2 3 4 5
1 2
1 3
3 4
4 5
2 5
4 4
```
**Вывод 1**
```
15
4
```
