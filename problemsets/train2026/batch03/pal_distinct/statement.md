# Разные палиндромы

Тилек выписал все подстроки-палиндромы слова. Сколько среди них различных слов?

## Вход

Одна строка из строчных латинских букв, длина от 1 до 100000.

## Выход

Количество различных подстрок-палиндромов.

## Пример 1

**Вход**
```
aaa
```

**Выход**
```
3
```

## Пример 2

**Вход**
```
abacaba
```

**Выход**
```
7
```
