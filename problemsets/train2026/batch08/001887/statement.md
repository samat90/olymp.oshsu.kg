# Острова на карте

Карта — прямоугольная таблица: «#» — суша, «.» — вода. Острова — группы клеток суши, соседних по стороне. Сколько островов на карте?

**Ввод.** В первой строке n и m. Затем n строк по m символов. 1 ≤ n, m ≤ 300.

**Вывод.** Число островов.

## Примеры

**Ввод 1**
```
3 4
##..
#..#
...#
```
**Вывод 1**
```
2
```
