Из записи натурального числа нужно вычеркнуть ровно $k$ цифр так, чтобы получилось как можно меньшее число. Ведущие нули в результате отбрасываются (число 0 пишется как 0).

## Формат ввода

Одна строка: запись числа $s$ без ведущих нулей и число $k$.

## Формат вывода

Выведите наименьшее возможное число.

## Ограничения

Длина $s$ от 2 до $10^5$, $0 \le k <$ длины $s$.

## Примеры

### Пример 1

Ввод:
```
1432219 3
```
Вывод:
```
1219
```

### Пример 2

Ввод:
```
10200 1
```
Вывод:
```
200
```
