# Гнилые яблоки

В ящике яблоки лежат в таблице $h \times w$: `0` — пусто, `1` — свежее яблоко, `2` — гнилое. Каждую минуту каждое свежее яблоко, соседнее по стороне с гнилым, становится гнилым. Через сколько минут гнилыми станут все яблоки? Если это невозможно, выведите $-1$. Если свежих яблок нет, ответ $0$.

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 3\cdot 10^5$). Далее $h$ строк по $w$ символов.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
3 3
211
110
011
```

**Вывод**
```
4
```
