# Прямой обход дерева поиска

Двоичное дерево поиска строится так: первое число — корень; каждое следующее спускается от корня, влево если оно меньше значения в вершине, иначе вправо, и становится новым листом. Выведите значения в порядке прямого обхода: вершина, левое поддерево, правое поддерево.

**Ввод.** В первой строке n, во второй — n различных чисел в порядке добавления. 1 ≤ n ≤ 2000.

**Вывод.** n чисел через пробел.

## Примеры

**Ввод 1**
```
5
4 2 6 1 3
```
**Вывод 1**
```
4 2 1 3 6
```
