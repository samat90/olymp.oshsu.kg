# Стоимость превращения слов

Слово s нужно превратить в слово t. Вставка буквы стоит p, удаление — q, замена одной буквы на другую — r сомов. Какова наименьшая стоимость?

**Ввод.** В первой строке p, q, r (1 ≤ p, q, r ≤ 100). Во второй и третьей строках слова s и t длиной от 1 до 1000 из строчных латинских букв.

**Вывод.** Наименьшая стоимость.

**Пример**

Ввод:
```
2 3 4
abc
bcd
```
Вывод:
```
5
```
