# Треугольники с периметром n

Сколько существует невырожденных треугольников с целыми сторонами и периметром $n$? Треугольники, отличающиеся только порядком сторон, считаются одинаковыми.

**Ввод.** Одно число $n$ ($1 \le n \le 10^9$).

**Вывод.** Количество треугольников.

### Пример 1

Ввод:
```
12
```

Вывод:
```
3
```
