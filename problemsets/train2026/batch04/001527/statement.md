Даны $n$ отрезков. Отрезок называется вложенным, если существует другой отрезок (с другим номером), который целиком его содержит, то есть $l_j \le l_i$ и $r_i \le r_j$. Совпадающие отрезки считаются вложенными друг в друга. Сколько отрезков вложенные?

## Формат ввода

В первой строке дано $n$. Далее $n$ строк с парой $l_i$, $r_i$.

## Формат вывода

Выведите число вложенных отрезков.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $0 \le l_i \le r_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
4
1 6
2 4
3 9
2 4
```
Вывод:
```
2
```

### Пример 2

Ввод:
```
2
1 2
3 4
```
Вывод:
```
0
```
