Из строки нужно вычеркнуть часть букв так, чтобы каждая буква, которая была в строке, осталась ровно один раз, а оставшиеся буквы шли в прежнем порядке. Из всех способов выберите тот, при котором получится лексикографически наименьшая строка.

## Формат ввода

Одна строка из строчных латинских букв.

## Формат вывода

Выведите результат.

## Ограничения

Длина строки от 1 до $10^5$.

## Примеры

### Пример 1

Ввод:
```
bcabc
```
Вывод:
```
abc
```

### Пример 2

Ввод:
```
cbacdcbc
```
Вывод:
```
acdb
```
