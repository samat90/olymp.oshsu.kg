# Лягушка прыгает далеко

Лягушка Каныкей сидит на первом из n камней, высота камня i равна h_i. За один прыжок она может перепрыгнуть на любой из следующих k камней, потратив |h_i − h_j| энергии. Какова минимальная энергия, чтобы добраться до камня n?

**Ввод.** В первой строке n и k (2 ≤ n ≤ 20000, 1 ≤ k ≤ 100), во второй n высот (1 ≤ h_i ≤ 10^4).

**Вывод.** Минимальная затраченная энергия.

**Пример**

Ввод:
```
6 3
10 30 40 50 20 60
```
Вывод:
```
50
```
