# Заливка

Картинка — таблица $h \times w$ из цифр $0$–$9$ (цвета). Заливка из клетки $(r, c)$ перекрашивает эту клетку и все клетки, до которых можно дойти по соседним по стороне клеткам того же цвета. Сколько клеток будет перекрашено?

**Ввод.** В первой строке $h, w, r, c$ ($1 \le h\cdot w \le 3\cdot 10^5$, $1 \le r \le h$, $1 \le c \le w$). Далее $h$ строк по $w$ цифр.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
3 4 2 2
1121
1111
2112
```

**Вывод**
```
9
```
