# Самый длинный круг

В стране $n$ городов; из города $i$ ведёт не более одной односторонней дороги — в город $a_i$ ($a_i = 0$, если дороги нет; $a_i \ne i$). Круг — замкнутый маршрут, возвращающийся в исходный город, без повторов городов. Найдите длину самого длинного круга.

**Ввод.** В первой строке $n$ ($2 \le n \le 10^5$). Во второй — $n$ чисел $a_i$ ($0 \le a_i \le n$).

**Вывод.** Длина круга или $-1$, если кругов нет.

### Пример 1

**Ввод**
```
6
2 3 1 3 0 4
```

**Вывод**
```
3
```
