Дана перестановка чисел от 1 до $n$. За один ход можно поменять местами любые два числа. Сколько ходов нужно, чтобы расставить числа по возрастанию?

## Формат ввода

В первой строке дано $n$. Во второй — перестановка.

## Формат вывода

Выведите минимальное число обменов.

## Ограничения

$1 \le n \le 2 \cdot 10^5$.

## Примеры

### Пример 1

Ввод:
```
4
2 1 4 3
```
Вывод:
```
2
```

### Пример 2

Ввод:
```
3
2 3 1
```
Вывод:
```
2
```
