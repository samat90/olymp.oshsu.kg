# Ровные ступени чисел

Дан массив из n чисел. Найдите длину самой длинной подпоследовательности, у которой разность между соседними элементами постоянна (арифметическая прогрессия, возможно с нулевой или отрицательной разностью). Подпоследовательность из одного или двух элементов всегда подходит.

**Ввод.** В первой строке n (1 ≤ n ≤ 1000), во второй n чисел a_i (0 ≤ a_i ≤ 10^4).

**Вывод.** Наибольшая длина.

**Пример**

Ввод:
```
6
3 6 9 12 5 15
```
Вывод:
```
5
```
