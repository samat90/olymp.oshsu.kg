# Последний камень

Есть `n` камней. На каждом шаге берут два самых тяжёлых камня весом `x ≤ y` и сталкивают. Если `x = y`, оба исчезают, иначе остаётся один камень весом `y - x`. Какой вес у последнего камня? Если камней не осталось - 0.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел от 1 до 10^9.

## Выходные данные
Вес последнего камня.

## Примеры

### Пример 1

Ввод:
```
6
2 7 4 1 8 1
```

Вывод:
```
1
```

### Пример 2

Ввод:
```
1
5
```

Вывод:
```
5
```
