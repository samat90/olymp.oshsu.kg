# Общее начало

Найдите самую длинную строку, с которой начинаются все данные слова. Если такой непустой строки нет, выведите «-». Все слова состоят из строчных латинских букв.

**Ввод.** В первой строке n, затем n слов по одному в строке. 1 ≤ n ≤ 1000, длина слова от 1 до 100.

**Вывод.** Общий префикс или «-».

## Примеры

**Ввод 1**
```
3
kyrgyz
kyrk
kyr
```
**Вывод 1**
```
kyr
```

**Ввод 2**
```
2
osh
bishkek
```
**Вывод 2**
```
-
```
