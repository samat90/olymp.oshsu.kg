# Список-палиндром

Проверьте, читается ли список одинаково слева направо и справа налево.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел.

## Выходные данные
`YES` или `NO`.

## Примеры

### Пример 1

Ввод:
```
5
1 2 3 2 1
```

Вывод:
```
YES
```

### Пример 2

Ввод:
```
4
1 2 2 3
```

Вывод:
```
NO
```
