# Порядок выбывания

Условие как в предыдущей игре: `n` человек по кругу, выбывает каждый `k`-й. Выведите номера в порядке выбывания (последний — оставшийся).

**Ввод.** `n` и `k` (`1 ≤ n ≤ 10^5`, `1 ≤ k ≤ 10^9`).

**Вывод.** `n` чисел через пробел.

## Пример 1

Ввод:
```
5 2
```

Вывод:
```
2 4 1 5 3
```
