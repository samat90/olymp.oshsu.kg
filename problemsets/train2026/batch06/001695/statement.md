# Обход городов

Курьер Эрмек должен выехать из города 1, побывать в каждом из n городов ровно один раз и вернуться в город 1. Дано время d_ij переезда из города i в город j (оно может отличаться от d_ji). Найдите наименьшее суммарное время маршрута.

**Ввод.** В первой строке n (2 ≤ n ≤ 13), далее n строк по n чисел d_ij (1 ≤ d_ij ≤ 100; диагональные значения игнорируются).

**Вывод.** Наименьшее суммарное время.

**Пример**

Ввод:
```
3
0 10 15
5 0 20
8 12 0
```
Вывод:
```
32
```
