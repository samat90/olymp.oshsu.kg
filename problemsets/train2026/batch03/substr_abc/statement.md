# Три буквы

Сколько подстрок слова содержат каждую из букв `a`, `b` и `c` хотя бы по разу? Подстроки с разными позициями считаются разными.

## Вход

Одна строка из букв `a`, `b`, `c`, длина от 1 до 200000.

## Выход

Количество подстрок.

## Пример 1

**Вход**
```
abcabc
```

**Выход**
```
10
```

## Пример 2

**Вход**
```
aaabb
```

**Выход**
```
0
```
