# Две кучи с малой разницей

Мешки с зерном нужно разделить на две группы так, чтобы разность их общих весов была как можно меньше. Выведите эту наименьшую разность.

**Ввод.** `n` (`1 ≤ n ≤ 100`) и веса `a_i` (`1 ≤ a_i ≤ 100`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
4
1 6 11 5
```

Вывод:
```
1
```

## Пример 2

Ввод:
```
1
7
```

Вывод:
```
7
```
