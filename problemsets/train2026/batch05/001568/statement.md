# Команды для дека

Реализуйте дек (двустороннюю очередь) целых чисел. Команды:

- `push_front x` и `push_back x` - добавить число в начало или в конец, выводить ничего не нужно;
- `pop_front` и `pop_back` - удалить число с начала или с конца и вывести его;
- `front` и `back` - вывести первое или последнее число, не удаляя;
- `size` - вывести количество чисел в деке.

Если дек пуст, на команды `pop_front`, `pop_back`, `front`, `back` выведите `ERROR`.

## Входные данные
В первой строке число команд `q` (`1 ≤ q ≤ 200000`). Далее `q` строк с командами. Числа `x` по модулю не больше 10^9.

## Выходные данные
Результаты команд, каждый в своей строке.

## Примеры

### Пример 1

Ввод:
```
7
push_back 5
push_front 3
front
back
pop_back
size
pop_front
```

Вывод:
```
3
5
5
1
3
```
