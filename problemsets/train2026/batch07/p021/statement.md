# Пробить скалу

Карта $h \times w$: `.` — свободная клетка, `#` — скала. Вы идёте из левой верхней клетки в правую нижнюю по соседним по стороне клеткам. Можно пройти сквозь скалу, но не более чем через $K$ скальных клеток за весь путь. Найдите наименьшее число ходов.

**Ввод.** В первой строке $h, w, K$ ($1 \le h\cdot w \le 40000$, $0 \le K \le 10$). Далее $h$ строк по $w$ символов. Начальная и конечная клетки свободны.

**Вывод.** Число ходов или $-1$.

### Пример 1

**Ввод**
```
3 4 1
..#.
###.
.#..
```

**Вывод**
```
5
```
