Грузы на склате в Оше лежат в ряд, масса $i$-го равна $a_i$. Их нужно разделить на $k$ непустых групп подряд идущих грузов и развезти $k$ машинами по одной группе. Какой наименьшей может быть наибольшая масса группы?

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — массы.

## Формат вывода

Выведите минимальную возможную наибольшую массу группы.

## Ограничения

$1 \le k \le n \le 10^5$, $1 \le a_i \le 10^4$.

## Примеры

### Пример 1

Ввод:
```
5 2
7 2 5 10 8
```
Вывод:
```
18
```

### Пример 2

Ввод:
```
3 3
4 1 9
```
Вывод:
```
9
```
