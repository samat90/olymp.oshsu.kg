# Лишние линии связи

Айдар и Бермет пользуются сетью из $n$ узлов и $m$ линий трёх типов: тип $1$ — только Айдар, тип $2$ — только Бермет, тип $3$ — оба. Каждый должен иметь возможность добраться из любого узла в любой по доступным ему линиям. Какое наибольшее число линий можно отключить, чтобы это осталось верным? Если уже сейчас кто-то из них не может добраться из любого узла в любой, выведите $-1$.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ строк $t\ a\ b$ ($t \in \{1,2,3\}$).

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
4 5
3 1 2
3 2 3
1 3 4
2 3 4
3 1 4
```

**Вывод**
```
2
```
