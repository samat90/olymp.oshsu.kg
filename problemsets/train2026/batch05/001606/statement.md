# Двусвязный список с командами

Есть двусвязный список из различных целых чисел. Выполните команды:

- `after x y` - вставить новое число `y` сразу после `x`;
- `before x y` - вставить новое число `y` сразу перед `x`;
- `remove x` - удалить число `x`.

Число `x` всегда есть в списке, число `y` ещё не встречалось.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 100000`), во второй строке `n` различных чисел. В третьей строке число команд `q` (`1 ≤ q ≤ 100000`), далее `q` строк с командами. Все числа по модулю не больше 10^9.

## Выходные данные
Итоговый список через пробел или `ПУСТО`.

## Примеры

### Пример 1

Ввод:
```
3
10 20 30
4
after 20 25
before 10 5
remove 30
remove 5
```

Вывод:
```
10 20 25
```
