# Подсказка при вводе

Словарь содержит n различных слов. Пользователь вводит приставку p, и ему показывают слова словаря, начинающиеся с p, в алфавитном порядке. Для каждого из q запросов «p k» выведите k-е слово в этом списке или −1, если в нём меньше k слов. Все слова состоят из строчных латинских букв.

**Ввод.** В первой строке n и q. Затем n слов, затем q строк вида «p k». 1 ≤ n, q ≤ 5000, длины слов и приставок от 1 до 6, 1 ≤ k ≤ 4.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
4 3
osh
okuu
olo
bak
o 2
b 2
os 1
```
**Вывод 1**
```
olo
-1
osh
```
