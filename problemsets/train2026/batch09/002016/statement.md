# Юрта: точки с целыми координатами

Юрта на плане — круг радиуса $r$ с центром в начале координат. Сколько точек с целыми координатами лежит внутри круга или на его границе?

**Ввод.** Одно число $r$ ($1 \le r \le 10^6$).

**Вывод.** Количество точек.

### Пример 1

Ввод:
```
2
```

Вывод:
```
13
```
