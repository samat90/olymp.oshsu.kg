Для каждого числа $n$ найдите наибольшее целое $x$ такое, что $x^2 \le n$.

## Формат ввода

В первой строке дано $q$. Во второй — $q$ чисел $n$.

## Формат вывода

Выведите ответы через пробел.

## Ограничения

$1 \le q \le 10^5$, $0 \le n \le 10^{18}$.

## Примеры

### Пример 1

Ввод:
```
4
0 15 16 1000000000000000000
```
Вывод:
```
0 3 4 1000000000
```

### Пример 2

Ввод:
```
1
2
```
Вывод:
```
1
```
