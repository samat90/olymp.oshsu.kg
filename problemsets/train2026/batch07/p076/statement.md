# Компоненты взаимной достижимости

В стране $n$ городов и $m$ односторонних дорог. Два города принадлежат одной группе, если из каждого можно доехать до другого. Найдите количество групп и размер самой большой группы.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$ (различные, $a \ne b$).

**Вывод.** Два числа через пробел.

### Пример 1

**Ввод**
```
6 7
1 2
2 3
3 1
3 4
4 5
5 4
5 6
```

**Вывод**
```
3 3
```
