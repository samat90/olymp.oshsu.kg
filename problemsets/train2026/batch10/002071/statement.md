# Редактор с курсором

В текстовом редакторе пустой текст и курсор в начале. Команды: латинская буква или цифра — вставить символ перед курсором; `<` — курсор влево на один символ (если можно); `>` — вправо (если можно); `-` — удалить символ слева от курсора (если он есть). Выведите итоговый текст.

**Ввод.** Строка команд длины `n` (`1 ≤ n ≤ 10^6`) без пробелов.

**Вывод.** Итоговый текст (может быть пустой строкой).

## Пример 1

Ввод:
```
ab<c>d-
```

Вывод:
```
acb
```

## Пример 2

Ввод:
```
<<-x
```

Вывод:
```
x
```
