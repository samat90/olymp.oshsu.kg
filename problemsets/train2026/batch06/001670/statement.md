# Рюкзак с запасом предметов

В лавке Жылдыз n видов товаров, каждого вида сколько угодно. Товар i весит w_i и стоит v_i. В сумку помещается груз не тяжелее W. Какова наибольшая суммарная стоимость?

**Ввод.** В первой строке n и W (1 ≤ n ≤ 100, 1 ≤ W ≤ 10^4), далее n строк по два числа w_i и v_i (1 ≤ w_i ≤ 10^4, 1 ≤ v_i ≤ 1000).

**Вывод.** Наибольшая суммарная стоимость.

**Пример**

Ввод:
```
3 10
3 40
4 70
5 85
```
Вывод:
```
170
```
