# Кольцевой следующий больший

Числа записаны по кругу: после последнего элемента снова идёт первый. Для каждого элемента найдите первое строго большее число, двигаясь по кругу вперёд (не более одного полного круга).

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
`n` чисел через пробел: найденное число или `-1`.

## Примеры

### Пример 1

Ввод:
```
4
3 1 2 1
```

Вывод:
```
-1 2 3 3
```

### Пример 2

Ввод:
```
3
5 5 5
```

Вывод:
```
-1 -1 -1
```
