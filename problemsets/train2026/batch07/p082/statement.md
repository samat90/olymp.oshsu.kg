# Сколько городов посетим

В стране $n$ городов, из города $i$ ведёт ровно одна односторонняя дорога — в город $a_i$ (возможно, $a_i = i$). Турист выезжает из города $i$ и едет по дорогам, пока не окажется в городе, где уже был. Сколько различных городов он посетит (считая начальный)? Выведите ответ для каждого $i$.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Во второй — $n$ чисел $a_i$ ($1 \le a_i \le n$).

**Вывод.** $n$ чисел через пробел.

### Пример 1

**Ввод**
```
5
2 3 1 3 4
```

**Вывод**
```
3 3 3 4 5
```
