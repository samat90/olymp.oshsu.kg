# Наименьший сдвиг

Из всех циклических сдвигов слова выберите лексикографически наименьший.

## Вход

Одна строка из строчных латинских букв, длина от 1 до 200000.

## Выход

Наименьший циклический сдвиг.

## Пример 1

**Вход**
```
bca
```

**Выход**
```
abc
```

## Пример 2

**Вход**
```
abab
```

**Выход**
```
abab
```
