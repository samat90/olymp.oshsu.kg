# Пути с кратной суммой

На поле n×m в клетках записаны числа. Айгерим идёт из левой верхней клетки в правую нижнюю, шагая вправо или вниз. Сколько путей имеют сумму чисел (с первой и последней клетками), кратную k?

**Ввод.** В первой строке n, m и k (1 ≤ n, m ≤ 100, 1 ≤ k ≤ 20), далее n строк по m чисел (0 ≤ a_ij ≤ 100).

**Вывод.** Число путей по модулю 10^9 + 7.

**Пример**

Ввод:
```
2 2 3
1 2
3 3
```
Вывод:
```
1
```
