# Недавние обращения

Сервер получает обращения в моменты `t_1 ≤ t_2 ≤ ... ≤ t_n` (секунды). Для каждого обращения определите, сколько обращений (включая его) было за последние `w` секунд, то есть в моменты от `t - w` до `t` включительно.

## Входные данные
В первой строке числа `n` и `w` (`1 ≤ n ≤ 200000`, `0 ≤ w ≤ 10^9`). Во второй строке `n` неубывающих целых чисел от 0 до 10^9.

## Выходные данные
`n` чисел через пробел.

## Примеры

### Пример 1

Ввод:
```
5 3
1 2 4 6 9
```

Вывод:
```
1 2 3 2 2
```

### Пример 2

Ввод:
```
3 0
5 5 7
```

Вывод:
```
1 2 1
```
