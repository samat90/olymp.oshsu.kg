# Партия 7: «Графы» (коды 001729–001828)

100 задач на графы: BFS/DFS, сетки, компоненты связности, топологическая сортировка, кратчайшие пути
(Дейкстра, Флойд, 0-1 BFS), остовные деревья, мосты и точки сочленения, сильная связность, деревья, потоки.
Условия авторские, на русском, с кыргызскими названиями и местами; ввод/вывод через stdin/stdout.

Папка `pNNN` — задача с кодом `001728+NNN` (p001 = 001729, p100 = 001828):

- `statement.md` — условие (markdown, примеры уже подставлены);
- `gen.py` — генератор: `python3 gen.py K` (K = 1..10) печатает тест K; зерно фиксировано (`NNN*1000+K`), тесты на диске не хранятся;
- `sol.py` — эталонное решение (читает stdin), `brute.py` — перебор;
- `meta.json` — код, название, тема «Графы», TL (1 или 2 с, одинаково для всех языков), 100 баллов, 10 тестов, partial.

Ответ единственный (чекер не нужен): сравнение вывода токен-в-токен.

Проверка (`tools/`): `python3 tools/build.py check [N ...]` — примеры, 300 случайных мелких тестов (`sol == brute`),
детерминизм генератора и время `sol` на 10 тестах. `python3 tools/build.py emit` пересобирает папки `pNNN` из `tools/src/*.txt`.
Все 100 задач прошли проверку (300 мелких тестов на каждую, расхождений нет).

Сборка тестов на сервере: для K = 1..10 `python3 gen.py K > K.in; python3 sol.py < K.in > K.out`.
