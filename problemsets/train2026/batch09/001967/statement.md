# К-я перестановка

Все перестановки чисел $1, \dots, n$ выписаны в лексикографическом порядке и пронумерованы с единицы. Выведите перестановку с номером $k$.

**Ввод.** Два числа $n$ и $k$ ($1 \le n \le 20$, $1 \le k \le n!$).

**Вывод.** Перестановка через пробел.

### Пример 1

Ввод:
```
3 4
```

Вывод:
```
2 3 1
```
