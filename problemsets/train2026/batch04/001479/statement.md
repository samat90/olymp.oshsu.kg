У скаутов в Караколе есть $n$ верёвок. Нужно получить ровно $k$ кусков одинаковой целой длины (от верёвки можно отрезать несколько кусков, остатки выбрасываются). Какой наибольшей длины могут быть куски? Если получить $k$ кусков нельзя, выведите 0.

## Формат ввода

В первой строке даны $n$ и $k$. Во второй — длины верёвок.

## Формат вывода

Выведите наибольшую длину куска или 0.

## Ограничения

$1 \le n \le 10^5$, $1 \le k \le 10^{14}$ , $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
3 5
10 7 4
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
2 100
3 3
```
Вывод:
```
0
```
