# Наибольшее число из кусков

Есть `n` неотрицательных целых чисел. Запишите их подряд в некотором порядке так, чтобы получилось как можно большее число. Выведите его (если все числа нули — выведите `0`).

**Ввод.** `n` (`1 ≤ n ≤ 10^5`) и числа `a_i` (`0 ≤ a_i ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3
3 30 34
```

Вывод:
```
34330
```

## Пример 2

Ввод:
```
2
0 0
```

Вывод:
```
0
```
