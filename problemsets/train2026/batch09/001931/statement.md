# Наименьшее число с k делителями

Найдите наименьшее натуральное число, у которого ровно $k$ натуральных делителей.

**Ввод.** Одно число $k$ ($1 \le k \le 1000$). Гарантируется, что ответ не превосходит $10^{18}$.

**Вывод.** Искомое число.

### Пример 1

Ввод:
```
6
```

Вывод:
```
12
```

### Пример 2

Ввод:
```
12
```

Вывод:
```
60
```
