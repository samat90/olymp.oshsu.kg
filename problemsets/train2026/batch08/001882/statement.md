# Компоненты после каждого моста

Острова соединяют мостами по одному. После каждого нового моста выведите число групп островов, между которыми можно пройти по мостам.

**Ввод.** В первой строке n и m. В следующих m строках по два числа a, b — ребро между вершинами a и b (a ≠ b, кратные рёбра возможны). 2 ≤ n ≤ 100000, 1 ≤ m ≤ 150000.

**Вывод.** m чисел через пробел.

## Примеры

**Ввод 1**
```
5 3
1 2
2 3
4 5
```
**Вывод 1**
```
4 3 2
```
