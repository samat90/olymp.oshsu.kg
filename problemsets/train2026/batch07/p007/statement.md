# Ключи от комнат

В общежитии $n$ комнат, нумерация с $1$. Вы стоите в открытой комнате $1$, остальные заперты. В каждой комнате лежит несколько ключей, каждый открывает одну комнату. Попав в комнату, вы забираете все ключи оттуда. Можно ли побывать во всех комнатах?

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Далее $n$ строк: в $i$-й сначала число $c_i$ — количество ключей в комнате $i$, затем $c_i$ номеров комнат. Сумма $c_i$ не больше $3\cdot 10^5$.

**Вывод.** `YES` или `NO`.

### Пример 1

**Ввод**
```
4
1 2
1 3
1 1
0
```

**Вывод**
```
NO
```
