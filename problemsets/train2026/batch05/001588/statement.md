# Планировщик с паузами

Серверу нужно выполнить задачи, виды которых обозначены латинскими буквами. Каждая задача занимает одну секунду. Между двумя задачами одного вида должно пройти не менее `c` секунд, занятых другими задачами или простоем (простой сервера допускается). Порядок задач можно выбирать любой. За какое наименьшее время сервер выполнит все задачи?

## Входные данные
В первой строке строка из заглавных латинских букв длиной от 1 до 200000. Во второй строке число `c` (`0 ≤ c ≤ 100`).

## Выходные данные
Минимальное время в секундах.

## Примеры

### Пример 1

Ввод:
```
AAABBB
2
```

Вывод:
```
8
```

### Пример 2

Ввод:
```
AAABBB
0
```

Вывод:
```
6
```

### Пример 3

Ввод:
```
ABCDEF
3
```

Вывод:
```
6
```
