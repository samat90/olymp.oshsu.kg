Нурлан записал на доске несколько чисел и решил расставить их так: сначала по последней цифре (по возрастанию), а числа с одинаковой последней цифрой — по возрастанию самого числа.

## Формат ввода

В первой строке дано число $n$. Во второй — $n$ целых неотрицательных чисел.

## Формат вывода

Выведите числа в нужном порядке через пробел.

## Ограничения

$1 \le n \le 10^5$, $0 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5
21 11 30 5 15
```
Вывод:
```
30 11 21 5 15
```

### Пример 2

Ввод:
```
3
7 7 0
```
Вывод:
```
0 7 7
```
