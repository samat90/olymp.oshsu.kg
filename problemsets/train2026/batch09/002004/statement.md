# Ним

Азамат и Айгуль играют в ним: есть $n$ куч камней, игроки ходят по очереди, Азамат первый. За ход нужно взять любое положительное число камней из одной кучи. Кто не может сделать ход — проигрывает.

Выведите имя победителя при оптимальной игре (`Азамат` или `Айгуль`). Если побеждает Азамат, во второй строке выведите его выигрышный ход: номер кучи и сколько камней взять; из всех выигрышных ходов выберите с наименьшим номером кучи.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$), во второй — размеры куч $a_i$ ($1 \le a_i \le 10^9$).

**Вывод.** Победитель и, если это Азамат, ход.

### Пример 1

Ввод:
```
3
1 2 3
```

Вывод:
```
Айгуль
```

### Пример 2

Ввод:
```
3
1 2 4
```

Вывод:
```
Азамат
3 1
```
