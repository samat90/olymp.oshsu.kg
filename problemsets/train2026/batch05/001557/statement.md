# Самая широкая рампа

Пара позиций `i < j` называется рампой, если `a[i] ≤ a[j]`. Шириной рампы считается `j - i`. Найдите наибольшую ширину.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел от 0 до 10^9.

## Выходные данные
Наибольшая ширина рампы или `0`, если рамп нет.

## Примеры

### Пример 1

Ввод:
```
6
6 0 8 2 1 5
```

Вывод:
```
4
```

### Пример 2

Ввод:
```
3
3 2 1
```

Вывод:
```
0
```
