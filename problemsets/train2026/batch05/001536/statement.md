# Упростить путь

Путь к файлу на сервере записан по правилам Linux: `.` означает текущую папку, `..` - родительскую (из корня остаёмся в корне), несколько подряд идущих `/` считаются одним. Запишите путь в каноническом виде: он начинается с `/`, папки разделены одним `/`, в конце нет `/` (кроме корня), нет `.` и `..`.

## Входные данные
Одна строка, начинающаяся с `/`, длиной от 1 до 100000. Названия папок состоят из строчных латинских букв, а также могут быть `.` или `..`.

## Выходные данные
Канонический путь.

## Примеры

### Пример 1

Ввод:
```
/ala/too/../sary/./
```

Вывод:
```
/ala/sary
```

### Пример 2

Ввод:
```
/../
```

Вывод:
```
/
```

### Пример 3

Ввод:
```
//a//b///c/..
```

Вывод:
```
/a/b
```
