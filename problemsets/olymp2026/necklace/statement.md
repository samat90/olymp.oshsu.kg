В Ысык-Ате мастерицы нанизывают бусы из `n` бусин по кругу. Бусины бывают `k` цветов, и по обычаю две соседние бусины никогда не бывают одного цвета (первая и последняя бусины тоже соседние).

Две раскраски считаются одинаковыми бусами, если одна получается из другой поворотом круга. Если же бусы можно ещё и перевернуть другой стороной (зеркально отразить), то одинаковых раскрасок становится больше — такие бусы назовём браслетами.

{{img necklace.svg 460}}

Для каждого из `T` вопросов `n k` найдите количество различных бус и количество различных браслетов. Ответы выведите по модулю 10⁹ + 7.

## Входные данные

В первой строке — число `T` (1 ≤ T ≤ 1000). В каждой из следующих `T` строк — два целых числа `n` и `k` (3 ≤ n ≤ 10⁹, 1 ≤ k ≤ 10⁹ + 6).

## Выходные данные

Для каждого вопроса выведите два числа: количество бус и количество браслетов по модулю 10⁹ + 7.

{{sample 1}}

## Пояснение

При `n = 4`, `k = 3` раскраски без одинаковых соседей: «abab» (6 раскрасок, это 3 различных буса) и «abac» (12 раскрасок, это 3 различных буса), всего 6. Переворот ничего не склеивает. При `n = 6`, `k = 3` переворот склеивает бусы «abcabc» и «acbacb», поэтому браслетов меньше.

## Система оценивания

Решение проверяется на 20 тестах, каждый стоит 5 баллов. В 20 % тестов n ≤ 8 и k ≤ 6.

## Подсказка

Лемма Бёрнсайда: число классов равно среднему по всем преобразованиям числу раскрасок, которые преобразование не меняет.
