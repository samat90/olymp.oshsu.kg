# Перераспределение

В ряду `n` ящиков с конфетами (по кругу). Каждый шаг: берут ящик с наибольшим числом конфет (при равенстве — с наименьшим номером), вынимают все его конфеты и раскладывают по одной в следующие ящики по кругу, начиная со следующего за ним (может получиться и в тот же ящик). Через сколько шагов набор ящиков впервые повторит одно из уже встречавшихся состояний (включая начальное) и какова длина получившегося цикла?

**Ввод.** `n` (`1 ≤ n ≤ 16`) и числа `a_i` (`0 ≤ a_i ≤ 15`), хотя бы одно положительно.

**Вывод.** Два числа: число шагов до первого повтора и длина цикла.

## Пример 1

Ввод:
```
4
0 2 7 0
```

Вывод:
```
5 4
```
