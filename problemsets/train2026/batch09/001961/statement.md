# Разбиения числа

Сколькими способами число $n$ можно представить в виде суммы натуральных слагаемых? Порядок слагаемых не важен: $3 + 1$ и $1 + 3$ — один способ. Ответ по модулю $10^9+7$.

**Ввод.** Одно число $n$ ($1 \le n \le 5000$).

**Вывод.** Количество способов по модулю $10^9+7$.

### Пример 1

Ввод:
```
4
```

Вывод:
```
5
```
