# Подмножества с суммой

Сколько существует подмножеств (по позициям, пустое тоже считается) набора из `n` чисел с суммой ровно `S`?

**Ввод.** `n` (`1 ≤ n ≤ 40`), `S` (`0 ≤ S ≤ 4·10^10`) и `n` чисел `a_i` (`1 ≤ a_i ≤ 10^9`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
4 5
1 2 3 5
```

Вывод:
```
2
```

## Пример 2

Ввод:
```
3 0
4 4 4
```

Вывод:
```
1
```
