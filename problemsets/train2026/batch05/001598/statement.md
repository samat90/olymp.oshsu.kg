# Развернуть группами

Разбейте список на группы подряд идущих элементов по `k` штук и переверните каждую полную группу. Последняя неполная группа остаётся как есть.

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ k ≤ n ≤ 200000`). Во второй строке `n` целых чисел.

## Выходные данные
Новый список через пробел.

## Примеры

### Пример 1

Ввод:
```
5 2
1 2 3 4 5
```

Вывод:
```
2 1 4 3 5
```

### Пример 2

Ввод:
```
6 3
1 2 3 4 5 6
```

Вывод:
```
3 2 1 6 5 4
```
