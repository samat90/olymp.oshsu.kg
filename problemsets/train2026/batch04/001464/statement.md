В отсортированном по возрастанию массиве нечётной длины каждое число встречается ровно два раза, кроме одного, которое встречается один раз. Найдите его.

## Формат ввода

В первой строке дано $n$ (нечётное). Во второй — массив.

## Формат вывода

Выведите число без пары.

## Ограничения

$1 \le n \le 2 \cdot 10^5 - 1$ (нечётное), $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
7
1 1 3 3 4 5 5
```
Вывод:
```
4
```

### Пример 2

Ввод:
```
1
8
```
Вывод:
```
8
```
