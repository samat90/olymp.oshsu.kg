# Все предшественники

Дан ориентированный граф без циклов на $n$ вершинах. Для каждой вершины найдите, сколько других вершин могут по стрелкам дойти до неё.

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 2000$, $0 \le m \le 10^4$). Далее $m$ пар $a\ b$. Циклов нет.

**Вывод.** $n$ чисел через пробел.

### Пример 1

**Ввод**
```
5 5
1 2
2 3
1 3
4 3
3 5
```

**Вывод**
```
0 1 3 0 4
```
