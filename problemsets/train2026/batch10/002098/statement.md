# Суммы по прямоугольникам

Дана таблица `n × m`. Ответьте на `q` запросов: найти сумму чисел в прямоугольнике с углами `(r1, c1)` и `(r2, c2)` (строки и столбцы нумеруются с 1, границы включены).

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 1000`), таблица (`0 ≤ a ≤ 10^9`), `q` (`1 ≤ q ≤ 10^5`) и `q` строк `r1 c1 r2 c2`.

**Вывод.** `q` чисел, по одному в строке.

## Пример 1

Ввод:
```
2 3
1 2 3
4 5 6
2
1 1 2 2
2 2 2 3
```

Вывод:
```
12
11
```
