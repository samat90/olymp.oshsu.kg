# Номер в коде Грея

Код Грея из `n` бит строится так: для `n=1` это `0, 1`; для `n` берётся список для `n-1`, к каждому слову приписывается спереди `0`, затем тот же список в обратном порядке, к каждому слову спереди приписывается `1`. Слова нумеруются с нуля в порядке списка. Задано слово — выведите его номер в двоичной записи ровно из `n` символов.

**Ввод.** Двоичная строка длины `n` (`1 ≤ n ≤ 10^5`).

**Вывод.** Двоичная строка длины `n`.

## Пример 1

Ввод:
```
110
```

Вывод:
```
100
```

## Пример 2

Ввод:
```
0101
```

Вывод:
```
0110
```
