# Викторина: план реализации

Делаем всё сразу, без этапов. Только локально на ноутбуке, на сервер не выкладываем, пока Самат не посмотрит.

## Решения Самата (не менять)
- Раздел называется «Викторина», это отдельный раздел. В рейтинг сайта ничего не идёт.
- Создать викторину может любой пользователь. Войти в игру по PIN или QR может и пользователь с аккаунтом, и гость по нику.
- Лимит 1000 игроков в одной игре для всех.
- Режимы: с ведущим и экраном, с ведущим без экрана (пульт на телефоне), автоматический групповой, в одиночку (таблица рекордов викторины).
- Вопрос и варианты видны на телефоне каждого игрока, так что проектор не обязателен.
- Картинки по желанию: в вопросе и в каждом варианте ответа.
- Музыка, звуки, анимации обязательны. Всё оформление своё, ничего не копируем у Kahoot (ни названия, ни цвета, ни фигуры, ни звуки).

## Где код
Делаем как typing/workspace, внутри приложения judge:
- `judge/models/quiz.py` и аддитивные миграции (существующие таблицы не трогаем)
- `judge/views/quiz.py`, при необходимости `judge/views/quiz_api.py`
- `templates/quiz/*.html`, `resources/quiz/*.js|*.css|*.scss`
- URL-префикс `/quiz/`, пункт меню «Викторина»
- `judge/admin/` для Quiz и жалоб, тесты `judge/test_quiz.py`
- Новые pip-зависимости не добавляем: qrcode[pil], openpyxl, redis, Pillow уже есть.

## Модели
- **Quiz**: автор (Profile), название, описание, обложка, тема оформления, тема/предмет, доступ (открытая или по ссылке), скрыта админом, число игр, даты.
- **Question**: quiz, порядок, тип (12 типов ниже), текст (markdown + формулы), код и язык подсветки, картинка (по желанию), время 5–240 с, вес (обычный / x2 / без очков), пояснение, `data` JSON для параметров типа.
- **Option**: question, порядок, текст, картинка (по желанию), верный ли.
- **GameSession**: quiz, ведущий (null для одиночной), PIN из 6 цифр (уникален среди активных), режим, статус (lobby / question / reveal / leaderboard / finished), текущий вопрос, время начала фазы, настройки (перемешивание, музыка, гости разрешены, лимит игроков = 1000), даты.
- **Player**: игра, профиль или null, ник, токен гостя (cookie), очки, серия, удалён ли.
- **Answer**: игрок, вопрос, ответ JSON, верно, доля верности, очки, время в мс; уникально (игрок, вопрос).
- **QuizReport**: жалоба на открытую викторину.

## 12 типов вопросов
| Тип | data / проверка |
| --- | --- |
| Один вариант (2–4, текст или картинка) | одна верная Option |
| Верно / Неверно | две Option |
| Несколько верных | очки x доля (верно отмеченные минус лишние, не меньше 0) |
| Собери слово | слово, буквы перемешиваются на сервере; сравнение без регистра |
| Расставь по порядку (3–6) | верный порядок; полные очки только за точный порядок |
| Что выведет код | код + язык; варианты или ввод |
| Введи ответ | список допустимых ответов; числа с допуском |
| Ползунок | min, max, step, ответ, допуск; очки по близости |
| Точка на картинке | картинка + верная область (x, y, радиус в %) |
| Опрос | без очков, показываем распределение |
| Облако слов | без очков, частотное облако |
| Открытый ответ | без очков, ведущий показывает выбранные |

Очки: `1000 * (1 - t / (2T))` за верный ответ, x2 или 0 по весу, бонус серии +100 за каждый верный подряд, максимум +500. Неверный = 0.

## Механика игры и сеть
- WebSocket не используем (прокси университета его режет). Только HTTP-опрос.
- Состояние игры хранится в кэше Django (на сервере Redis; если `CACHES` локально locmem, для теста тоже работает в одном процессе). Ключ состояния небольшой: фаза, номер вопроса, версия, дедлайн, число ответивших.
- `GET /quiz/g/<pin>/state?v=N`: отвечает за 1–2 мс, без запросов к БД. Если версия не изменилась, ответ пустой (304 или `{}`). Сервер сам задаёт интервал опроса: 1 с до 200 игроков, 1,5 с до 500, 2 с больше 500.
- Вопрос отдаётся отдельным запросом при смене версии, БЕЗ верного ответа. Момент выдачи вопроса игроку пишется в кэш, время ответа считается от него (сервер, не телефон). Верный ответ уходит на телефон только на фазе разбора.
- `POST answer`: один ответ на вопрос, после дедлайна (+0,5 с запас на сеть) не принимается, CSRF, проверка что игрок в этой игре.
- Таблица лидеров в кэше, в БД сохраняем ответы и итоги (по каждому ответу или пачкой на разборе, главное без потерь).
- Переподключение по тому же PIN (cookie/аккаунт) сохраняет очки.
- Лимит входов с одного IP, фильтр неприличных ников, ведущий может удалить игрока. Гость = один браузер (cookie-токен).
- Админ может временно ограничить игры на время олимпиады (настройка в админке).

## Экраны
1. Каталог «Викторина»: открытые викторины, поиск, темы, «Мои викторины», большая кнопка «Войти по PIN».
2. Редактор: список вопросов с перетаскиванием, выбор типа, картинки (загрузка, сжатие Pillow до 1280 px и ~100 КБ, лимит 5 МБ, проверка что это картинка), предпросмотр глазами игрока, автосохранение, импорт из Excel (шаблон для скачивания), копирование чужой открытой викторины.
3. Запуск: выбор режима и настроек.
4. Вход `/quiz/join`: поле PIN крупно (QR ведёт сюда с PIN), затем ник для гостя.
5. Лобби: PIN + QR, имена «всплывают», счётчик игроков, музыка, кнопка «Начать».
6. Экран ведущего (проектор): крупный шрифт, PIN и QR в углу всю игру, таймер, ответившие, разбор со столбиками, топ-5, кнопки Далее / Пауза / Пропустить / Звук, полноэкранный режим.
7. Пульт ведущего (телефон): те же кнопки + верный ответ + счётчик.
8. Экран игрока (телефон, mobile-first): номер вопроса, таймер, очки, текст вопроса, картинка, ответы по типу. После ответа: «Ответ принят», потом «Верно! +870» / «Неверно», серия, место.
9. Финал: пьедестал, место и очки игрока, разбор ошибок. Отчёт ведущему по игрокам и вопросам + выгрузка Excel (openpyxl).
10. Одиночная игра и рекорды викторины. История игр в профиле.

## Дизайн
- Стиль сайта: переменные из `vars-default.scss` / `vars-dark.scss`, светлая и тёмная тема.
- Свои 4 цвета ответов из палитры сайта (бирюзовый, оранжевый, фиолетовый, малиновый или похожие, с достаточным контрастом) и свои фигуры (например звезда, шестиугольник, капля, ромб с вырезом), фигура видна на каждой кнопке (для дальтоников). Не красный/синий/жёлтый/зелёный с треугольником/ромбом/кругом/квадратом.
- Тонкий кыргызский орнамент (мотив тюндюка/ою) на фоне лобби и финала как фирменная деталь.
- 3–4 готовые темы фона викторины на выбор автору.
- Вся игровая страница с JS, CSS и звуками до 1 МБ, кэшируется.

## Музыка и звуки
- Всё генерируется в браузере через Web Audio API (свой небольшой секвенсор), файлов нет: ноль проблем с лицензиями и нулевой трафик.
- Лобби: спокойная мелодия по кругу (щипковый тембр в духе комуза). Вопрос: ритмичная музыка, ускоряется в последние 5 с. Отсчёт: тиканье. Верно / неверно: короткие сигналы. Таблица: барабанная дробь. Финал: фанфары.
- Музыка играет на экране ведущего. На телефонах только короткие сигналы (+ вибрация), можно выключить. В режиме без экрана музыка тихо играет на телефонах.
- Кнопки громкости/выключения, звук включается после первого нажатия (правила браузеров).

## Анимации
CSS + небольшой JS, без тяжёлых библиотек: всплывающие имена, отсчёт 3–2–1, таймер-кольцо (краснеет в конце), растущие столбики, перестановка строк таблицы (FLIP), набегающие очки, пьедестал, конфетти (свой canvas-код), вибрация телефона. Учитываем `prefers-reduced-motion`.
