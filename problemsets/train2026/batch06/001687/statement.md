# Разрезать слово на палиндромы

Слово нужно разрезать на несколько частей так, чтобы каждая часть была палиндромом. Какое наименьшее число разрезов потребуется?

**Ввод.** Слово из строчных латинских букв длиной от 1 до 2000.

**Вывод.** Наименьшее число разрезов.

**Пример**

Ввод:
```
aabaca
```
Вывод:
```
2
```
