# Отрезки с нулевым XOR

Сколько непустых подотрезков массива имеют побитовое исключающее ИЛИ, равное нулю?

**Ввод.** В первой строке $n$ ($1 \le n \le 2\cdot 10^5$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{30}$).

**Вывод.** Количество подотрезков.

### Пример 1

Ввод:
```
5
1 2 3 1 1
```

Вывод:
```
4
```
