# Медиана в окне

Дан массив из n чисел и число k. Для каждого окна из k подряд идущих элементов найдите медиану: если отсортировать окно по возрастанию, это элемент с номером ⌈k/2⌉ (при чётном k — левый из двух средних).

**Ввод.** В первой строке n и k. Во второй — n чисел. 1 ≤ k ≤ n ≤ 100000, 1 ≤ aᵢ ≤ 10⁹.

**Вывод.** n − k + 1 чисел через пробел.

## Примеры

**Ввод 1**
```
6 3
5 1 3 8 2 4
```
**Вывод 1**
```
3 3 3 4
```

**Ввод 2**
```
4 2
4 1 3 2
```
**Вывод 2**
```
1 1 2
```
