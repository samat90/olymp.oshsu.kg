# Тройки с нулевым XOR

Сколько существует троек индексов $i < j < k$ таких, что $a_i \oplus a_j \oplus a_k = 0$?

**Ввод.** В первой строке $n$ ($3 \le n \le 2000$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{30}$).

**Вывод.** Количество троек.

### Пример 1

Ввод:
```
4
1 2 3 3
```

Вывод:
```
2
```
