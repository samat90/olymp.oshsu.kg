# Падающие плиты

Одна за другой на ось падают `n` плит. Плита занимает отрезок `[l, l+w)` (длина `w`, высота 1). Падая вертикально, плита останавливается, когда упирается в ось или в уже лежащие плиты (касание только краями не считается упором). После каждой плиты выведите наибольшую высоту башни.

**Ввод.** `n` (`1 ≤ n ≤ 2000`), затем `n` строк `l w` (`0 ≤ l ≤ 10^8`, `1 ≤ w ≤ 10^8`).

**Вывод.** `n` чисел через пробел.

## Пример 1

Ввод:
```
3
2 3
5 2
3 4
```

Вывод:
```
1 1 2
```
