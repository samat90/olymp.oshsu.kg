# Обратная польская запись

Выражение записано в обратной польской записи: числа и знаки `+`, `-`, `*`. Знак применяется к двум последним числам (сначала идёт левый операнд, потом правый). Вычислите значение.

## Входные данные
В первой строке число `n` токенов (`1 ≤ n ≤ 200001`, нечётное). Во второй строке `n` токенов через пробел: целые числа от 0 до 9 или знаки `+`, `-`, `*`. Выражение корректно.

## Выходные данные
Значение выражения по модулю 1000000007 (результат от 0 до 1000000006).

## Примеры

### Пример 1

Ввод:
```
5
2 3 + 4 *
```

Вывод:
```
20
```

### Пример 2

Ввод:
```
7
9 1 - 3 * 2 +
```

Вывод:
```
26
```
