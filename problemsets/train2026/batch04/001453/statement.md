Расположите числа по возрастанию и найдите наибольшую разность между двумя соседними числами в этом порядке.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ целых чисел.

## Формат вывода

Выведите наибольшую разность соседних чисел в отсортированном порядке.

## Ограничения

$2 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5
3 6 9 1 14
```
Вывод:
```
5
```

### Пример 2

Ввод:
```
3
4 4 4
```
Вывод:
```
0
```
