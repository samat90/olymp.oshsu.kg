# Числа из диапазона

Дан массив из n чисел и q запросов «l r lo hi». Для каждого найдите, сколько среди aₗ, …, aᵣ чисел x, для которых lo ≤ x ≤ hi.

**Ввод.** В первой строке n и q. Во второй — n чисел. Затем q строк l r lo hi. 1 ≤ n, q ≤ 50000, 1 ≤ aᵢ, lo, hi ≤ 10⁹.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
5 2
3 1 4 1 5
1 5 1 3
2 4 4 9
```
**Вывод 1**
```
3
1
```
