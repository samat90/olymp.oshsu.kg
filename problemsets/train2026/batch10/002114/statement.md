# Анаграммы по порядку

Выведите все различные перестановки букв заданной строки в лексикографическом порядке, по одной в строке.

**Ввод.** Строка из строчных латинских букв длиной от 1 до 8.

**Вывод.** Все различные перестановки, по одной в строке.

## Пример 1

Ввод:
```
aab
```

Вывод:
```
aab
aba
baa
```

## Пример 2

Ввод:
```
ab
```

Вывод:
```
ab
ba
```
