# Сумма чисел Фибоначчи на отрезке

Числа Фибоначчи: $F_0 = 0$, $F_1 = 1$, $F_i = F_{i-1} + F_{i-2}$. Найдите $F_l + F_{l+1} + \dots + F_r$ по модулю $m$.

**Ввод.** Три числа $l$, $r$, $m$ ($0 \le l \le r \le 10^{18}$, $1 \le m \le 10^9$).

**Вывод.** Остаток от деления суммы на $m$.

### Пример 1

Ввод:
```
1 5 100
```

Вывод:
```
12
```
