# Расшифровка послания

Каныкей зашифровала слово цифрами: A = 1, B = 2, …, Z = 26. Получилась строка из цифр без разделителей. Сколькими способами её можно расшифровать? Нуля среди кодов нет, поэтому «0» может быть только второй цифрой кодов 10 и 20.

**Ввод.** Строка из цифр длиной от 1 до 10^5.

**Вывод.** Число способов по модулю 10^9 + 7 (может быть 0).

**Пример**

Ввод:
```
2262
```
Вывод:
```
3
```
