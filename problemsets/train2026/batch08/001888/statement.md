# Остров растёт

Карта размера n × m сначала вся покрыта водой. Каждый день вода отступает в одной клетке (r, c), и там появляется суша; если суша там уже была, ничего не меняется. После каждого дня выведите число островов (группы клеток суши, соседних по стороне).

**Ввод.** В первой строке n, m, k. Затем k строк с парами r c. 1 ≤ n, m ≤ 300, 1 ≤ k ≤ 50000.

**Вывод.** k чисел через пробел.

## Примеры

**Ввод 1**
```
3 3 4
1 1
3 3
2 2
2 1
```
**Вывод 1**
```
1 2 3 2
```
