# Линейное уравнение в целых неотрицательных

Нурлан хочет заплатить ровно $c$ сомов купюрами по $a$ и по $b$ сомов. Найдите количество купюр каждого вида, если у него есть неотрицательные целые $x$ и $y$, для которых $ax + by = c$. Если решений несколько, выберите с наименьшим $x$.

**Ввод.** Три числа $a$, $b$, $c$ ($1 \le a, b, c \le 10^9$).

**Вывод.** Два числа $x$ и $y$, либо `-1`, если решения нет.

### Пример 1

Ввод:
```
6 4 20
```

Вывод:
```
0 5
```

### Пример 2

Ввод:
```
6 4 7
```

Вывод:
```
-1
```
