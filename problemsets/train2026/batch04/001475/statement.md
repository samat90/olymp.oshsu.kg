Для каждого $k$ найдите наименьшее $n$, при котором число $n!$ оканчивается не менее чем на $k$ нулей.

## Формат ввода

В первой строке дано $q$. Во второй — $q$ значений $k$.

## Формат вывода

Выведите ответы через пробел.

## Ограничения

$1 \le q \le 2 \cdot 10^4$, $1 \le k \le 10^{12}$.

## Примеры

### Пример 1

Ввод:
```
3
1 6 25
```
Вывод:
```
5 25 105
```

### Пример 2

Ввод:
```
1
8
```
Вывод:
```
35
```
