# Хоровод

`n` детей (чётное число) стоят по кругу на местах `1…n`; в начале на месте `i` стоит ребёнок `i`. Команды: `1 x` — все сдвигаются по часовой стрелке на `x` мест (`-n ≤ x ≤ n`, отрицательное — против), `2` — дети на местах `1,2` меняются, `3,4` меняются и т. д. Выведите, кто стоит на каждом месте после всех команд.

**Ввод.** `n` и `q` (`2 ≤ n ≤ 2·10^5` чётное, `1 ≤ q ≤ 2·10^5`), затем `q` команд.

**Вывод.** `n` чисел через пробел.

## Пример 1

Ввод:
```
6 3
1 2
2
1 -1
```

Вывод:
```
5 2 1 4 3 6
```
