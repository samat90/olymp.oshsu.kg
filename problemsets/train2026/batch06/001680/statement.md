# Рюкзак с огромной вместимостью

Грузовик может увезти груз не тяжелее W. Есть n предметов, у предмета i вес w_i и ценность v_i. Каждый предмет можно взять не более одного раза. Какова наибольшая суммарная ценность? Вместимость очень велика, но ценности малы.

**Ввод.** В первой строке n и W (1 ≤ n ≤ 60, 1 ≤ W ≤ 10^9), далее n строк по два числа w_i и v_i (1 ≤ w_i ≤ 10^9, 1 ≤ v_i ≤ 300).

**Вывод.** Наибольшая суммарная ценность.

**Пример**

Ввод:
```
3 10
6 30
5 20
5 25
```
Вывод:
```
45
```
