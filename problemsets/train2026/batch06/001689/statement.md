# Слияние куч по кругу

Кучи камней лежат по кругу, в куче i — a_i камней; первая куча соседствует с последней. За ход можно слить две соседние кучи, заплатив столько, сколько в них камней вместе. Какова наименьшая суммарная плата, чтобы слить всё в одну кучу?

**Ввод.** В первой строке n (1 ≤ n ≤ 100), во второй n чисел a_i (1 ≤ a_i ≤ 100).

**Вывод.** Наименьшая суммарная плата.

**Пример**

Ввод:
```
4
4 1 1 4
```
Вывод:
```
18
```
