# Кодовый замок

Замок имеет четыре колеса с цифрами $0$–$9$; колесо можно повернуть на одну цифру вверх или вниз ($9 \to 0$ и $0 \to 9$ допустимо). Изначально стоит `0000`. Есть $d$ запрещённых комбинаций: если колёса показали такую, замок блокируется. За какое наименьшее число поворотов можно набрать комбинацию $T$, не попав ни на одну запрещённую?

**Ввод.** В первой строке $T$ — четыре цифры. Во второй — $d$ ($0 \le d \le 2000$). Далее $d$ строк по четыре цифры.

**Вывод.** Число поворотов или $-1$.

### Пример 1

**Ввод**
```
0202
3
0201
0101
0102
```

**Вывод**
```
6
```
