# Назначение на работы

В мастерской Айбека n мастеров и n заказов. Если мастер i берёт заказ j, он тратит c_ij часов. Каждому мастеру нужно дать ровно один заказ, и каждый заказ достаётся ровно одному мастеру. Каково наименьшее суммарное число часов?

**Ввод.** В первой строке n (1 ≤ n ≤ 14), далее n строк по n чисел c_ij (1 ≤ c_ij ≤ 1000).

**Вывод.** Наименьшая сумма.

**Пример**

Ввод:
```
3
9 2 7
6 4 3
5 8 1
```
Вывод:
```
9
```
