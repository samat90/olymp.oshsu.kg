# Сумма XOR всех подотрезков

Для каждого непустого подотрезка массива возьмите побитовое исключающее ИЛИ его элементов. Найдите сумму этих значений по всем подотрезкам.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$), во второй — $n$ чисел $a_i$ ($0 \le a_i < 2^{30}$).

**Вывод.** Сумма.

### Пример 1

Ввод:
```
3
1 2 3
```

Вывод:
```
10
```
