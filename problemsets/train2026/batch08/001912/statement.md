# Подотрезки с суммой в диапазоне

Сколько в массиве непустых подотрезков (подряд идущих элементов), сумма которых лежит в пределах от L до R включительно?

**Ввод.** В первой строке n, L, R. Во второй — n чисел. 1 ≤ n ≤ 100000, |aᵢ| ≤ 10⁹, |L|, |R| ≤ 10¹⁴, L ≤ R.

**Вывод.** Количество подотрезков.

## Примеры

**Ввод 1**
```
4 2 5
1 2 3 -1
```
**Вывод 1**
```
7
```
