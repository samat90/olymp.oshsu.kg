# Удалить с конца

Из списка из `n` чисел удалите `k`-й элемент с конца (последний элемент - первый с конца).

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ k ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
Список после удаления через пробел или `ПУСТО`, если он пуст.

## Примеры

### Пример 1

Ввод:
```
5 2
1 2 3 4 5
```

Вывод:
```
1 2 3 5
```

### Пример 2

Ввод:
```
1 1
9
```

Вывод:
```
ПУСТО
```
