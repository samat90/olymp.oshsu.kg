# Без одинаковых соседей

Переставьте буквы строки так, чтобы никакие две соседние буквы не совпадали. Если возможно несколько вариантов, выведите лексикографически наименьший.

## Входные данные
Одна строка из строчных латинских букв длиной от 1 до 20000.

## Выходные данные
Искомая строка или слово `НЕТ`, если так переставить нельзя.

## Примеры

### Пример 1

Ввод:
```
aab
```

Вывод:
```
aba
```

### Пример 2

Ввод:
```
aaab
```

Вывод:
```
НЕТ
```

### Пример 3

Ввод:
```
abc
```

Вывод:
```
abc
```
