# Лягушка Чолпон

Лягушка Чолпон сидит на первом из n камней. Высота камня i равна h_i. Она может прыгнуть на камень i+1 или i+2, потратив |h_i − h_j| энергии, где j — камень приземления. Какова минимальная энергия, чтобы добраться до камня n?

**Ввод.** В первой строке n (2 ≤ n ≤ 10^5), во второй n высот (1 ≤ h_i ≤ 10^4).

**Вывод.** Минимальная затраченная энергия.

**Пример**

Ввод:
```
5
10 30 40 20 50
```
Вывод:
```
40
```
