# Ним с ограничением хода

Азамат и Айгуль играют в ним с $n$ кучами, Азамат ходит первым. За ход нужно взять от 1 до $k$ камней из одной кучи. Кто не может сделать ход — проигрывает. Выведите имя победителя при оптимальной игре (`Азамат` или `Айгуль`).

**Ввод.** В первой строке $n$ и $k$ ($1 \le n \le 10^5$, $1 \le k \le 10^9$), во второй — размеры куч $a_i$ ($1 \le a_i \le 10^9$).

**Вывод.** Имя победителя.

### Пример 1

Ввод:
```
2 2
3 4
```

Вывод:
```
Азамат
```
