# Тропа через ущелье

Карта ущелья — таблица $h \times w$: `.` — проходимая клетка, `#` — скала. Вы стоите в левой верхней клетке и хотите попасть в правую нижнюю. За ход можно перейти в соседнюю по стороне свободную клетку. Какое наименьшее число ходов нужно?

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 3\cdot 10^5$). Далее $h$ строк по $w$ символов. Левая верхняя и правая нижняя клетки свободны.

**Вывод.** Число ходов или $-1$.

### Пример 1

**Ввод**
```
3 4
..#.
#...
..#.
```

**Вывод**
```
5
```
