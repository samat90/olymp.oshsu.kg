# Общая подпоследовательность по алфавиту

Даны две строки. Среди всех их наибольших общих подпоследовательностей выберите лексикографически наименьшую.

**Ввод.** Две строки по одной в строке, длиной от 1 до 1000, из строчных латинских букв.

**Вывод.** В первой строке длина ответа, во второй сама подпоследовательность (если длина 0 — пустая строка).

**Пример**

Ввод:
```
abcab
cabbac
```
Вывод:
```
3
aba
```
