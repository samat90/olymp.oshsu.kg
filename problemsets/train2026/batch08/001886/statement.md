# Переставить кабели

В офисе n компьютеров, соединённых m кабелями. Кабель можно вытащить и воткнуть между любыми двумя компьютерами. Какое наименьшее число кабелей нужно переставить, чтобы все компьютеры оказались в одной сети? Если это невозможно, выведите −1.

**Ввод.** В первой строке n и m. В следующих m строках по два числа a, b — ребро между вершинами a и b (a ≠ b, кратные рёбра возможны). 1 ≤ n ≤ 100000, 0 ≤ m ≤ 150000.

**Вывод.** Число перестановок или −1.

## Примеры

**Ввод 1**
```
4 3
1 2
1 3
2 3
```
**Вывод 1**
```
1
```

**Ввод 2**
```
6 5
1 2
1 3
2 3
2 3
4 5
```
**Вывод 2**
```
2
```
