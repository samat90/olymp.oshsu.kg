# Лестница с платой

На лестнице Эрмека n ступеней, за наступание на ступень i платят c_i сомов. Эрмек стоит на земле (позиция 0) и должен попасть на крышу (позиция n+1). За шаг можно перейти на 1 или 2 позиции вперёд; земля и крыша бесплатны. Какова минимальная суммарная плата?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел c_i (0 ≤ c_i ≤ 1000).

**Вывод.** Минимальная плата.

**Пример**

Ввод:
```
4
5 1 9 2
```
Вывод:
```
3
```
