# Разменные монеты 1..k

У Элмиры есть неограниченное количество монет номиналом $1, 2, \dots, k$ сомов. Сколькими способами можно набрать ровно $n$ сомов? Наборы с одинаковым числом монет каждого номинала считаются одинаковыми. Ответ по модулю $10^9+7$.

**Ввод.** Два числа $n$ и $k$ ($1 \le n, k \le 2000$).

**Вывод.** Количество способов по модулю $10^9+7$.

### Пример 1

Ввод:
```
5 3
```

Вывод:
```
5
```
