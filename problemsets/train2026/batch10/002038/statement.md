# Пересечение отрезков

Пройдут ли два отрезка через общую точку? Касание концом или совпадение части отрезков тоже считается пересечением.

**Ввод.** `t` (`1 ≤ t ≤ 10^5`) и `t` строк по 8 чисел `ax ay bx by cx cy dx dy`: отрезки `AB` и `CD` (концы каждого отрезка различны, `|·| ≤ 10^9`).

**Вывод.** Для каждого теста `YES` или `NO`.

## Пример 1

Ввод:
```
3
0 0 4 4 0 4 4 0
0 0 1 1 2 2 3 3
0 0 2 0 2 0 2 5
```

Вывод:
```
YES
NO
YES
```
