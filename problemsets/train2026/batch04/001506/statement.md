Ученики стоят в ряд, у каждого есть оценка $r_i$. Учитель раздаёт конфеты: каждому хотя бы одну, а ученик с оценкой выше, чем у соседа (слева или справа), получает больше конфет, чем этот сосед. Какое наименьшее число конфет понадобится?

## Формат ввода

В первой строке дано $n$. Во второй — оценки.

## Формат вывода

Выведите минимальное общее число конфет.

## Ограничения

$1 \le n \le 10^5$, $1 \le r_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
3
1 0 2
```
Вывод:
```
5
```

### Пример 2

Ввод:
```
4
2 2 2 2
```
Вывод:
```
4
```
