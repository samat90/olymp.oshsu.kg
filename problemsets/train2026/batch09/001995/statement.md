# Номер в коде Грея

Код Грея с номером $i$ — это число $i \oplus (i \gg 1)$ (сдвиг вправо на один бит, затем исключающее ИЛИ с $i$). Для заданного числа $g$ найдите номер $i$, которому оно соответствует.

**Ввод.** Одно число $g$ ($0 \le g \le 10^{18}$).

**Вывод.** Номер $i$.

### Пример 1

Ввод:
```
6
```

Вывод:
```
4
```
