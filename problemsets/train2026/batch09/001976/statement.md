# Собрать все значки

Существует $n$ разных значков. Каждый раз Мээрим получает один случайный значок (все значки равновероятны). Каково математическое ожидание числа получений, после которых у неё будут все $n$ значков? Выведите ответ в виде $P \cdot Q^{-1} \bmod (10^9+7)$, где $P/Q$ — несократимая дробь.

**Ввод.** Одно число $n$ ($1 \le n \le 10^6$).

**Вывод.** Ответ по модулю $10^9+7$.

### Пример 1

Ввод:
```
2
```

Вывод:
```
3
```
