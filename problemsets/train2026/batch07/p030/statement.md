# Шаги к числу

Вы начинаете с числа $s$ и хотите получить число $t$. Даны $n$ различных чисел $a_1,\dots,a_n$. За один шаг к текущему числу $x$ применяют одну из операций с любым $a_i$: $x+a_i$, $x-a_i$ или $x \oplus a_i$ (побитовое «исключающее или»). Если результат равен $t$, цель достигнута. Иначе результат должен лежать в отрезке $[0, 1000]$, иначе дальше продолжать нельзя. Найдите наименьшее число шагов.

**Ввод.** В первой строке $n, s, t$ ($1 \le n \le 100$, $0 \le s \le 1000$, $0 \le t \le 2000$). Во второй — $n$ чисел $a_i$ ($1 \le a_i \le 1000$).

**Вывод.** Число шагов или $-1$. Если $s = t$, ответ $0$.

### Пример 1

**Ввод**
```
3 5 12
3 7 10
```

**Вывод**
```
1
```
