# Диаметр дерева

Диаметр дерева — наибольшее расстояние (в рёбрах) между двумя вершинами. Найдите его.

**Ввод.** В первой строке n. В следующих n−1 строках по два числа u, v — ребро дерева. 1 ≤ n ≤ 100000.

**Вывод.** Диаметр дерева.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
4
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
4
```
