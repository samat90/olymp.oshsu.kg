# Повороты и отражения

Над матрицей `n × m` выполняется последовательность операций: `R` — повернуть на 90° по часовой стрелке, `H` — отразить по горизонтали (первый столбец меняется с последним и т. д.), `V` — отразить по вертикали (первая строка с последней), `T` — транспонировать. Выведите итоговую матрицу.

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 200`), матрица (`0 ≤ a ≤ 10^9`) и строка операций длины `q` (`1 ≤ q ≤ 10^5`).

**Вывод.** Итоговая матрица.

## Пример 1

Ввод:
```
2 3
1 2 3
4 5 6
R
```

Вывод:
```
4 1
5 2
6 3
```

## Пример 2

Ввод:
```
2 2
1 2
3 4
HT
```

Вывод:
```
2 4
1 3
```
