# Деревья поиска ограниченной высоты

Сколько существует различных двоичных деревьев поиска из `n` узлов с ключами `1…n`, высота которых не больше `h`? Высота — число узлов на самом длинном пути от корня вниз (пустое дерево имеет высоту 0). Ответ по модулю `10^9 + 7`.

**Ввод.** `n` и `h` (`1 ≤ n, h ≤ 100`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3 2
```

Вывод:
```
1
```

## Пример 2

Ввод:
```
3 3
```

Вывод:
```
5
```
