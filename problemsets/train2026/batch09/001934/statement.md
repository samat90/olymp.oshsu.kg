# Каноническое разложение

Разложите число $n$ на простые множители. Выведите разложение в порядке возрастания простых в виде `p1^e1 * p2^e2 * ...`. Если показатель равен 1, степень не пишется. Для $n = 1$ выведите `1`.

**Ввод.** Одно число $n$ ($1 \le n \le 10^{12}$).

**Вывод.** Разложение.

### Пример 1

Ввод:
```
360
```

Вывод:
```
2^3 * 3^2 * 5
```

### Пример 2

Ввод:
```
97
```

Вывод:
```
97
```

### Пример 3

Ввод:
```
1
```

Вывод:
```
1
```
