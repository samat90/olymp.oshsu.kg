# Редактор с отменой

В пустом текстовом редакторе выполняются команды:

- `type s` - дописать в конец текста строку `s`;
- `del k` - удалить последние `k` символов (`k` не больше длины текста);
- `undo` - отменить последнюю ещё не отменённую команду `type` или `del` (если таких нет, ничего не делает);
- `print` - вывести текст (пустой текст - пустая строка).

## Входные данные
В первой строке число команд `q` (`1 ≤ q ≤ 100000`), далее `q` строк. Строки `s` состоят из строчных латинских букв, суммарная длина всех `s` не больше 100000, общая длина выводимых текстов не больше 2·10^6.

## Выходные данные
Результаты команд `print`, каждый в своей строке.

## Примеры

### Пример 1

Ввод:
```
6
type ala
type too
del 2
print
undo
print
```

Вывод:
```
alat
alatoo
```
