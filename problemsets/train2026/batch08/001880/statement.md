# Сколько островов

В архипелаге n островов, между некоторыми проложены мосты. Сколько в нём групп островов, между которыми можно пройти по мостам?

**Ввод.** В первой строке n и m. В следующих m строках по два числа a, b — ребро между вершинами a и b (a ≠ b, кратные рёбра возможны). 1 ≤ n ≤ 100000, 0 ≤ m ≤ 150000.

**Вывод.** Число групп.

## Примеры

**Ввод 1**
```
5 3
1 2
2 3
4 5
```
**Вывод 1**
```
2
```
