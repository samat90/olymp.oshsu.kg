# Количество маршрутов

Между $n$ площадками проложены $m$ односторонних канатных дорог, циклов нет. Сколько существует различных маршрутов из площадки $1$ в площадку $n$? Ответ выведите по модулю $10^9+7$.

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$. Циклов нет.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5 7
1 2
1 3
2 3
2 4
3 4
3 5
4 5
```

**Вывод**
```
5
```
