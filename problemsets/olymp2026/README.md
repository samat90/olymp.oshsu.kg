## Как устроена папка задачи

- `problem.json` — название, ограничения, сложность, темы, 20 тестов по 5 баллов (параметры генератора), параметры стресс-проверки;
- `statement.md` — условие; `{{sample N}}` и `{{img файл ширина}}` подставляет сборщик;
- `sol.cpp` — эталонное решение (по нему считаются ответы);
- `brute.py` — медленное решение: сверяется с эталоном на примерах, маленьких тестах и сотнях случайных тестов (`stress`);
- `gen.py` — генератор (детерминированный, зерно — последний параметр);
- `samples/`, `img/` — примеры и иллюстрации (картинки рисует `python3 pics.py`).

## Сборка и проверка (в WSL или Linux, нужны g++ и python3)

```bash
bash b.sh            # все задачи: картинки, стресс-проверка, тесты в /root/olymp2026/build
bash b.sh dragon     # одна задача
bash tm.sh имя...    # время эталона на каждом тесте
```

Сборщик останавливается при любом расхождении эталона с перебором.

## Загрузка на сайт

```bash
python manage.py import_problemset /root/olymp2026/build --dry-run
python manage.py import_problemset /root/olymp2026/build --public --author samat1
```

Команда только добавляет задачи (существующие задачи с тем же названием пропускаются). Картинки копируются в
`MEDIA_ROOT/problems/kg2026/`.
