# Лампочки в гирлянде

Лампочки пронумерованы от 1 до `n`, сначала все выключены. В раунде `i` (для `i = 1, 2, …, n`) переключаются все лампочки, номера которых делятся на `i`. Сколько лампочек с номерами от `l` до `r` включено после всех раундов?

**Ввод.** `n`, `l`, `r` (`1 ≤ l ≤ r ≤ n ≤ 10^18`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
10 1 10
```

Вывод:
```
3
```

## Пример 2

Ввод:
```
100 5 50
```

Вывод:
```
5
```
