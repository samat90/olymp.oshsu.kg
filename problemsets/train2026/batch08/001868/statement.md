# Высота дерева поиска

Двоичное дерево поиска строится так: первое число — корень; каждое следующее спускается от корня, влево если оно меньше значения в вершине, иначе вправо, и становится новым листом. Найдите высоту получившегося дерева — число вершин на самом длинном пути от корня вниз.

**Ввод.** В первой строке n, во второй — n различных чисел в порядке добавления. 1 ≤ n ≤ 2000.

**Вывод.** Высота дерева.

## Примеры

**Ввод 1**
```
5
4 2 6 1 3
```
**Вывод 1**
```
3
```

**Ввод 2**
```
4
1 2 3 4
```
**Вывод 2**
```
4
```
