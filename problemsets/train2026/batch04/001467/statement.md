Даны два отсортированных по возрастанию списка результатов. Если объединить их и снова отсортировать, какое число окажется на $k$-м месте?

## Формат ввода

В первой строке даны $n$, $m$ и $k$. Во второй — первый список. В третьей — второй.

## Формат вывода

Выведите $k$-й по возрастанию элемент объединения.

## Ограничения

$1 \le n, m \le 2 \cdot 10^5$, $1 \le k \le n + m$, $1 \le a_i, b_j \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
3 2 4
1 5 9
2 7
```
Вывод:
```
7
```

### Пример 2

Ввод:
```
1 1 1
3
3
```
Вывод:
```
3
```
