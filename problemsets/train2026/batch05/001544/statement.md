# Сумма минимумов

Для каждого непрерывного подмассива (всего `n(n+1)/2` подмассивов) возьмите его минимальный элемент. Найдите сумму всех этих минимумов.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел от 1 до 10^9.

## Выходные данные
Сумма по модулю 1000000007.

## Примеры

### Пример 1

Ввод:
```
4
3 1 2 4
```

Вывод:
```
17
```

### Пример 2

Ввод:
```
1
7
```

Вывод:
```
7
```
