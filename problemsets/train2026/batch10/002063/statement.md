# Фишка на поле

Фишка стоит в клетке `(r, c)` поля. За ход её можно передвинуть в `(r-1, c-2)`, `(r-2, c-1)` или `(r-1, c-1)`, если клетка не выходит за границу `r ≥ 0`, `c ≥ 0`. Кто не может сделать ход, проиграл. Айбек ходит первым. Определите победителя для нескольких стартовых клеток.

**Ввод.** `q` (`1 ≤ q ≤ 10^5`) и `q` строк `r c` (`0 ≤ r, c ≤ 1000`).

**Вывод.** Для каждой клетки `Айбек` или `Бермет`.

## Пример 1

Ввод:
```
3
0 0
2 1
3 3
```

Вывод:
```
Бермет
Айбек
Бермет
```
