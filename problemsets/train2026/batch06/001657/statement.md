# Палиндром из слова

Из слова s можно вычеркнуть несколько букв так, чтобы оставшиеся (в прежнем порядке) образовали палиндром. Какова наибольшая возможная длина палиндрома?

**Ввод.** Слово из строчных латинских букв длиной от 1 до 1500.

**Вывод.** Наибольшая длина.

**Пример**

Ввод:
```
bbbab
```
Вывод:
```
4
```
