# Первый - наименьший

Посчитайте количество непрерывных подмассивов, у которых первый элемент не больше всех остальных элементов подмассива. Подмассив из одного элемента подходит.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел, по модулю не больше 10^9.

## Выходные данные
Количество подмассивов.

## Примеры

### Пример 1

Ввод:
```
4
2 3 1 4
```

Вывод:
```
6
```

### Пример 2

Ввод:
```
3
5 5 5
```

Вывод:
```
6
```
