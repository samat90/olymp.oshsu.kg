# Очередь печати

В очереди печати `n` заданий с приоритетами от 1 до 9. Принтер берёт первое задание: если в очереди есть задание с большим приоритетом, он переносит первое в конец, иначе печатает его. Ровно одно задание — на позиции `p` (нумерация с 1) — интересует Нурлана. Каким по счёту оно будет напечатано?

**Ввод.** `n`, `p` (`1 ≤ p ≤ n ≤ 10^5`) и приоритеты.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
4 3
1 1 9 1
```

Вывод:
```
1
```

## Пример 2

Ввод:
```
5 1
2 3 3 2 1
```

Вывод:
```
4
```
