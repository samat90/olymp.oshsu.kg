# Спиральный обход

Выведите элементы матрицы `n × m` в порядке обхода по спирали по часовой стрелке, начиная с левого верхнего угла.

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 500`) и матрица (`0 ≤ a ≤ 10^9`).

**Вывод.** `n·m` чисел через пробел.

## Пример 1

Ввод:
```
3 3
1 2 3
4 5 6
7 8 9
```

Вывод:
```
1 2 3 6 9 8 7 4 5
```

## Пример 2

Ввод:
```
2 3
1 2 3
4 5 6
```

Вывод:
```
1 2 3 6 5 4
```
