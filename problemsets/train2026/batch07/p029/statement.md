# Ход конём

Шахматный конь стоит в клетке $(0, 0)$ бесконечной доски. За какое наименьшее число ходов он дойдёт до клетки $(x, y)$? Ответьте на $q$ вопросов.

**Ввод.** В первой строке $q$ ($1 \le q \le 10^5$). Далее $q$ строк с парами $x\ y$ ($|x|, |y| \le 100$).

**Вывод.** $q$ строк — ответы.

### Пример 1

**Ввод**
```
3
2 1
5 5
-1 0
```

**Вывод**
```
1
4
3
```
