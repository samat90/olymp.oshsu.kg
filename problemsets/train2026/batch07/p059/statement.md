# Самая ровная тропа

Карта горного района — таблица высот $h \times w$. Тропа идёт из левой верхней клетки в правую нижнюю по соседним по стороне клеткам. Усилие тропы — наибольшая разность высот между двумя соседними клетками на ней. Найдите наименьшее возможное усилие.

**Ввод.** В первой строке $h$ и $w$ ($1 \le h\cdot w \le 10^5$). Далее $h$ строк по $w$ высот ($1 \le a_{ij} \le 10^9$).

**Вывод.** Одно число (для одной клетки — $0$).

### Пример 1

**Ввод**
```
3 3
1 2 2
3 8 2
5 3 5
```

**Вывод**
```
2
```
