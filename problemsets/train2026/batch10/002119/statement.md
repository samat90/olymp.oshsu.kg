# Раскраска карты

Есть `n` областей и `m` пар соседних областей. Какое наименьшее число цветов нужно, чтобы покрасить области так, чтобы соседние имели разные цвета?

**Ввод.** `n`, `m` (`1 ≤ n ≤ 12`, `0 ≤ m ≤ n(n-1)/2`) и `m` пар `u v`.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3 3
1 2
2 3
1 3
```

Вывод:
```
3
```

## Пример 2

Ввод:
```
4 3
1 2
2 3
3 4
```

Вывод:
```
2
```
