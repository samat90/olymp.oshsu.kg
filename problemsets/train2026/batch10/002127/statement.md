# Обход всех клеток

Поле `n × m`: `S` — старт, `E` — финиш, `.` — свободная клетка, `#` — преграда. Сколько существует путей из `S` в `E` по соседним (по стороне) клеткам, проходящих по каждой непреграждённой клетке ровно один раз?

**Ввод.** `n`, `m` (`1 ≤ n, m ≤ 5`) и поле.

**Вывод.** Одно число.

## Пример 1

Ввод:
```
2 2
S.
.E
```

Вывод:
```
0
```

## Пример 2

Ввод:
```
3 3
S..
...
..E
```

Вывод:
```
2
```
