# Горная тропа

Тропа в горах задана высотами a_1…a_n. Турист выбирает подпоследовательность, которая строго растёт до вершины, а затем строго убывает (любая часть может состоять из одной вершины). Найдите наибольшую длину такой подпоследовательности.

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (1 ≤ a_i ≤ 10^9).

**Вывод.** Наибольшая длина.

**Пример**

Ввод:
```
8
1 5 2 6 7 3 4 1
```
Вывод:
```
6
```
