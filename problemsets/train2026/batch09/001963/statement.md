# Раздел на непустые группы

Азамат делит $n$ различных студентов на $k$ непустых групп. Группы не различаются между собой, порядок студентов в группе не важен. Сколько способов? Ответ по модулю $10^9+7$.

**Ввод.** Два числа $n$ и $k$ ($1 \le k \le n \le 2000$).

**Вывод.** Количество способов по модулю $10^9+7$.

### Пример 1

Ввод:
```
4 2
```

Вывод:
```
7
```
