Ученики выстроились в очередь на экскурсию в Ош, и у каждого есть номер. Назовём беспорядком пару учеников, где стоящий раньше имеет строго больший номер, чем стоящий позже. Посчитайте число беспорядков.

## Формат ввода

В первой строке дано $n$. Во второй — $n$ номеров $a_i$.

## Формат вывода

Выведите количество пар $i < j$ таких, что $a_i > a_j$.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
5
3 1 2 5 4
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
4
7 7 7 7
```
Вывод:
```
0
```
