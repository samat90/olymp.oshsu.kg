# XOR с запросом

Дан массив из n чисел и q запросов. Для каждого числа x найдите наибольшее значение a XOR x по всем элементам a массива.

**Ввод.** В первой строке n и q. Во второй — n чисел. В третьей — q чисел x. 1 ≤ n, q ≤ 50000, числа от 0 до 2³⁰ − 1.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
3 3
1 2 4
7 0 3
```
**Вывод 1**
```
6
4
7
```
