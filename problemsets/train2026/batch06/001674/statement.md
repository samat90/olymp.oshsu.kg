# Плюсы и минусы

Перед каждым из n чисел a_i нужно поставить знак «+» или «−». Сколькими способами можно расставить знаки, чтобы значение выражения равнялось T? Способы различаются расстановкой знаков.

**Ввод.** В первой строке n и T (1 ≤ n ≤ 100, −10^4 ≤ T ≤ 10^4), во второй n чисел a_i (0 ≤ a_i ≤ 100).

**Вывод.** Число способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
5 3
1 1 1 1 1
```
Вывод:
```
5
```
