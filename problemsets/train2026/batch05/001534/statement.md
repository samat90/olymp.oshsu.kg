# Калькулятор со скобками

Вычислите значение выражения из неотрицательных целых чисел, знаков `+`, `-`, `*` и скобок. Умножение выполняется раньше сложения и вычитания.

## Входные данные
Одна строка без пробелов длиной от 1 до 100000. Числа записаны без ведущих нулей и не превосходят 10^9. Выражение корректно.

## Выходные данные
Значение выражения по модулю 1000000007 (результат от 0 до 1000000006).

## Примеры

### Пример 1

Ввод:
```
2+3*4
```

Вывод:
```
14
```

### Пример 2

Ввод:
```
(2+3)*4-5
```

Вывод:
```
15
```

### Пример 3

Ввод:
```
7
```

Вывод:
```
7
```
