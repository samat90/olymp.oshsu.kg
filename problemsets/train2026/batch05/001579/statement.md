# Аудитории для лекций

В университете проходит `n` лекций; лекция `i` занимает полуинтервал времени `[s_i, e_i)`. В одной аудитории лекции не должны пересекаться (конец одной в момент начала другой допустим). Сколько аудиторий нужно минимум?

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). В следующих `n` строках пары `s_i e_i` (`0 ≤ s_i < e_i ≤ 10^9`).

## Выходные данные
Минимальное число аудиторий.

## Примеры

### Пример 1

Ввод:
```
3
0 30
5 10
15 20
```

Вывод:
```
2
```

### Пример 2

Ввод:
```
2
1 5
5 8
```

Вывод:
```
1
```
