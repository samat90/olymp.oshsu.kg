# Проверка судоку

Доска судоку `9 × 9` заполнена частично: цифры `1–9` и `0` для пустой клетки. Правильна ли она, то есть нет ли одинаковых цифр в одной строке, в одном столбце или в одном блоке `3 × 3`?

**Ввод.** `t` (`1 ≤ t ≤ 1000`) и `t` досок по 9 строк из 9 символов.

**Вывод.** Для каждой доски `YES` или `NO`.

## Пример 1

Ввод:
```
1
530070000
600195000
098000060
800060003
400803001
700020006
060000280
000419005
000080079
```

Вывод:
```
YES
```
