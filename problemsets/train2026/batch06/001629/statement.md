# Лестница в Нарыне

Айбек поднимается по лестнице из n ступеней. За один шаг он поднимается на 1 или 2 ступени. Сколько существует способов подняться на верхнюю ступень?

**Ввод.** Одно число n (1 ≤ n ≤ 10^5).

**Вывод.** Количество способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
4
```
Вывод:
```
5
```
