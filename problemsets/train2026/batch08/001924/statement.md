# Слово по буквам

Слово можно «построить по буквам», если оно есть в словаре и каждое его непустое начало (префикс) тоже есть в словаре. Найдите самое длинное такое слово; если их несколько, выведите наименьшее по алфавиту. Если таких слов нет, выведите «-». Все слова состоят из строчных латинских букв.

**Ввод.** В первой строке n, затем n слов по одному в строке. 1 ≤ n ≤ 5000, длины от 1 до 100.

**Вывод.** Искомое слово или «-».

## Примеры

**Ввод 1**
```
6
k
ky
kyr
kyrg
kz
kyrgyz
```
**Вывод 1**
```
kyrg
```

**Ввод 2**
```
2
ab
b
```
**Вывод 2**
```
b
```
