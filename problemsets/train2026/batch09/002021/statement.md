# Уравнение Пелля

Найдите наименьшее решение уравнения $x^2 - D y^2 = 1$ в натуральных числах $x, y$.

**Ввод.** Одно число $D$ ($2 \le D \le 1000$, $D$ не является полным квадратом). Гарантируется, что $x \le 10^{18}$.

**Вывод.** Два числа $x$ и $y$.

### Пример 1

Ввод:
```
2
```

Вывод:
```
3 2
```

### Пример 2

Ввод:
```
7
```

Вывод:
```
8 3
```
