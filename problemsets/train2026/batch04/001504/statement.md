Лягушка сидит на первом из $n$ камней, камень $i$ позволяет прыгнуть вперёд на любое число камней от 1 до $a_i$ (если $a_i = 0$, прыгнуть нельзя). За какое наименьшее число прыжков она доберётся до последнего камня? Если это невозможно, выведите -1.

## Формат ввода

В первой строке дано $n$. Во второй — $a_i$.

## Формат вывода

Выведите минимальное число прыжков или -1.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $0 \le a_i \le 10^5$.

## Примеры

### Пример 1

Ввод:
```
5
2 3 1 1 4
```
Вывод:
```
2
```

### Пример 2

Ввод:
```
4
3 2 0 0
```
Вывод:
```
1
```
