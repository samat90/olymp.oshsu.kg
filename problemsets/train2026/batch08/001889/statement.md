# Мосты рушатся

Между n островами было m мостов. Мосты разрушаются по одному в порядке, в котором они перечислены. После разрушения каждого моста выведите число групп островов, между которыми ещё можно пройти по уцелевшим мостам.

**Ввод.** В первой строке n и m. В следующих m строках по два числа a, b — ребро между вершинами a и b (a ≠ b, кратные рёбра возможны). 2 ≤ n ≤ 100000, 1 ≤ m ≤ 150000.

**Вывод.** m чисел через пробел.

## Примеры

**Ввод 1**
```
4 3
1 2
2 3
3 4
```
**Вывод 1**
```
2 3 4
```
