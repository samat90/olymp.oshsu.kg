# Нечётный маршрут

Между $n$ городами $m$ двусторонних дорог. Туристу нужно проехать из города $1$ в город $n$ так, чтобы число пройденных дорог было нечётным (дороги и города можно посещать повторно). Какое наименьшее число дорог в таком маршруте?

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$.

**Вывод.** Число дорог или $-1$.

### Пример 1

**Ввод**
```
4 4
1 2
2 3
3 1
3 4
```

**Вывод**
```
3
```
