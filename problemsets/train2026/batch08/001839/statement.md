# Лежит ли на пути

Дано дерево и q запросов. В запросе заданы вершины u, v, c. Лежит ли вершина c на пути между u и v (концы пути тоже считаются)?

**Ввод.** В первой строке n и q. Затем n−1 строк с рёбрами, затем q строк с запросами u v c. 1 ≤ n, q ≤ 100000.

**Вывод.** Для каждого запроса YES или NO.

## Примеры

**Ввод 1**
```
5 3
1 2
1 3
3 4
4 5
2 5 3
2 5 4
4 4 4
```
**Вывод 1**
```
YES
YES
YES
```
