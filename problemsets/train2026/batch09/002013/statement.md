# К-й палиндром

Палиндром — число, которое одинаково читается слева направо и справа налево (в десятичной записи, без ведущих нулей). Найдите $k$-й по возрастанию палиндром среди натуральных чисел.

**Ввод.** Одно число $k$ ($1 \le k \le 10^9$).

**Вывод.** Число.

### Пример 1

Ввод:
```
10
```

Вывод:
```
11
```

### Пример 2

Ввод:
```
11
```

Вывод:
```
22
```
