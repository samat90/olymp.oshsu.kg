# Рюкзак с ограниченным числом

В лавке n видов товаров. Товара вида i есть c_i штук, каждый весит w_i и стоит v_i. В сумку помещается груз не тяжелее W. Какова наибольшая суммарная стоимость?

**Ввод.** В первой строке n и W (1 ≤ n ≤ 50, 1 ≤ W ≤ 5000), далее n строк по три числа w_i, v_i, c_i (1 ≤ w_i ≤ 500, 1 ≤ v_i ≤ 100, 1 ≤ c_i ≤ 20).

**Вывод.** Наибольшая суммарная стоимость.

**Пример**

Ввод:
```
2 10
3 10 2
4 25 3
```
Вывод:
```
50
```
