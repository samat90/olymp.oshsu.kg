# Квадратный корень по простому модулю

Найдите наименьшее целое $x \ge 0$, для которого $x^2 \equiv a \pmod p$, или сообщите, что такого $x$ нет.

**Ввод.** Два числа $a$ и $p$ ($0 \le a < p \le 10^9$, $p$ — нечётное простое).

**Вывод.** Число $x$ или `-1`.

### Пример 1

Ввод:
```
2 7
```

Вывод:
```
3
```

### Пример 2

Ввод:
```
3 7
```

Вывод:
```
-1
```
