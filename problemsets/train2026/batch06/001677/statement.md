# Рюкзак с двумя ограничениями

Мастерская Эрмека может изготовить любое число из n изделий (по одному каждого вида). Изделие i требует a_i часов работы и b_i кг материала, а приносит c_i сомов дохода. В распоряжении A часов и B кг материала. Какой наибольший доход можно получить?

**Ввод.** В первой строке n, A и B (1 ≤ n ≤ 100, 1 ≤ A, B ≤ 100), далее n строк по три числа a_i, b_i, c_i (1 ≤ a_i, b_i ≤ 100, 1 ≤ c_i ≤ 1000).

**Вывод.** Наибольший доход.

**Пример**

Ввод:
```
3 5 5
2 3 10
3 2 12
4 4 20
```
Вывод:
```
22
```
