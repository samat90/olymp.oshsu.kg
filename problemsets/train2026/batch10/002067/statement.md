# Очередь в кассу

В кассу вокзала в Караколе подходят `n` человек, `i`-й в момент `a_i` (в порядке неубывания времени), обслуживание длится `d_i`. Работают `k` касс. Подошедший встаёт к кассе, которая освободится раньше всех (если обслуживание уже началось раньше — к любой свободной). Время ожидания человека — это разница между началом и приходом. Выведите суммарное время ожидания и момент, когда обслужен последний человек.

**Ввод.** `n`, `k` (`1 ≤ n ≤ 10^5`, `1 ≤ k ≤ 10^5`), затем `n` строк `a_i d_i` (`0 ≤ a_i ≤ 10^9`, `1 ≤ d_i ≤ 10^4`, `a_i` не убывают).

**Вывод.** Два числа через пробел.

## Пример 1

Ввод:
```
4 2
0 5
1 3
2 4
3 1
```

Вывод:
```
4 8
```
