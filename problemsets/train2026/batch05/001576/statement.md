# Стартап и проекты

У Айбека `w` сомов капитала и `n` проектов. Проект `i` требует иметь не меньше `c_i` капитала и после завершения увеличивает капитал на `p_i`. Можно выполнить не более `k` проектов, по одному за раз. Какой наибольший капитал можно получить?

## Входные данные
В первой строке числа `k`, `w`, `n` (`1 ≤ k, n ≤ 200000`, `0 ≤ w ≤ 10^9`). Во второй строке `n` чисел `p_i`, в третьей `n` чисел `c_i` (`0 ≤ p_i, c_i ≤ 10^9`).

## Выходные данные
Максимальный итоговый капитал.

## Примеры

### Пример 1

Ввод:
```
3 0 3
1 2 3
0 1 1
```

Вывод:
```
6
```

### Пример 2

Ввод:
```
2 1 2
5 7
0 2
```

Вывод:
```
13
```
