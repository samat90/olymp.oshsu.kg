# Разделить по значению

Дан список и число `x`. Переставьте элементы так, чтобы сначала шли все элементы, меньшие `x`, затем все остальные. Относительный порядок внутри каждой группы сохраняется.

## Входные данные
В первой строке числа `n` и `x` (`1 ≤ n ≤ 200000`, `|x| ≤ 10^9`). Во второй строке `n` чисел, по модулю не больше 10^9.

## Выходные данные
Новый список через пробел.

## Примеры

### Пример 1

Ввод:
```
6 3
1 4 3 2 5 2
```

Вывод:
```
1 2 2 4 3 5
```

### Пример 2

Ввод:
```
3 1
5 6 7
```

Вывод:
```
5 6 7
```
