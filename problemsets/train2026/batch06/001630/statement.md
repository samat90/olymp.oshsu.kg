# Сломанные ступени

На лестнице из n ступеней Нурлана m ступеней сломаны, наступать на них нельзя. За шаг можно подняться на 1 или 2 ступени. Сколько способов дойти до ступени n, начав с земли (ступень 0)?

**Ввод.** В первой строке n и m (1 ≤ n ≤ 10^5, 0 ≤ m < n). Во второй строке m различных номеров сломанных ступеней (от 1 до n−1).

**Вывод.** Количество способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
6 2
2 4
```
Вывод:
```
1
```
