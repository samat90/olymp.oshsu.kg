# Дороги к столице

В стране $n$ городов, между ними $n-1$ односторонняя дорога, и если не учитывать направления, из любого города можно попасть в любой. Нужно развернуть некоторые дороги так, чтобы из каждого города можно было доехать до столицы — города $1$. Какое наименьшее число дорог придётся развернуть?

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Далее $n-1$ строка $a\ b$ — дорога из $a$ в $b$.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
6
1 3
2 3
4 1
4 5
6 5
```

**Вывод**
```
2
```
