Найдите наибольшую длину строго возрастающей подпоследовательности (не обязательно подряд идущих элементов).

## Формат ввода

В первой строке дано $n$. Во второй — $n$ чисел.

## Формат вывода

Выведите длину.

## Ограничения

$1 \le n \le 10^5$, $1 \le a_i \le 10^9$.

## Примеры

### Пример 1

Ввод:
```
6
5 2 8 6 3 6
```
Вывод:
```
3
```

### Пример 2

Ввод:
```
3
4 4 4
```
Вывод:
```
1
```
