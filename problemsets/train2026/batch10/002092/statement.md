# Наименьшая последовательность де Брёйна

Нужна двоичная строка длины `2^n`, в которой при циклическом чтении все `2^n` подстрок длины `n` различны (то есть встречаются все двоичные слова длины `n`). Таких строк много; выведите лексикографически наименьшую.

**Ввод.** `n` (`1 ≤ n ≤ 16`).

**Вывод.** Строка из `2^n` символов.

## Пример 1

Ввод:
```
2
```

Вывод:
```
0011
```

## Пример 2

Ввод:
```
3
```

Вывод:
```
00010111
```
