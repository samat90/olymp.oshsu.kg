# Срезка листьев

Садовник срезает дерево по раундам: в каждом раунде одновременно удаляются все листья (вершины, у которых осталось не более одного соседа). Сколько раундов понадобится, чтобы удалить всё дерево?

**Ввод.** В первой строке n. Затем n−1 строк с рёбрами. 1 ≤ n ≤ 100000.

**Вывод.** Число раундов.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
3
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
3
```

**Ввод 3**
```
1
```
**Вывод 3**
```
1
```
