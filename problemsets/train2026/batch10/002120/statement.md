# Ханойские башни: k-й ход

В игре «Ханойские башни» `n` дисков переносятся со стержня 1 на стержень 3 (стержень 2 вспомогательный) по стандартному оптимальному алгоритму: сначала `n-1` дисков переносятся на стержень 2, затем нижний диск на стержень 3, затем `n-1` дисков со стержня 2 на стержень 3. Каков `k`-й ход? Выведите номера стержней: откуда и куда.

**Ввод.** `n` (`1 ≤ n ≤ 60`) и `k` (`1 ≤ k ≤ 2^n - 1`).

**Вывод.** Два числа.

## Пример 1

Ввод:
```
3 1
```

Вывод:
```
1 3
```

## Пример 2

Ввод:
```
3 4
```

Вывод:
```
1 3
```
