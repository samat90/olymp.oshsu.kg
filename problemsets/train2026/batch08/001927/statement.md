# Лучший XOR подотрезка

Найдите наибольшее значение побитового XOR всех элементов на непрерывном подотрезке массива (подотрезок должен быть непустым).

**Ввод.** В первой строке n, во второй — n чисел. 1 ≤ n ≤ 50000, 0 ≤ aᵢ < 2³⁰.

**Вывод.** Максимальный XOR.

## Примеры

**Ввод 1**
```
4
8 1 2 12
```
**Вывод 1**
```
15
```

**Ввод 2**
```
1
0
```
**Вывод 2**
```
0
```
