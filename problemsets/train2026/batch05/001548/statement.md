# Наименьшая подпоследовательность

Из массива из `n` чисел нужно выбрать `k` элементов, сохраняя их порядок, так чтобы полученная последовательность была лексикографически наименьшей.

## Входные данные
В первой строке числа `n` и `k` (`1 ≤ k ≤ n ≤ 200000`). Во второй строке `n` целых чисел от 1 до 10^9.

## Выходные данные
`k` чисел через пробел.

## Примеры

### Пример 1

Ввод:
```
5 3
9 1 8 2 7
```

Вывод:
```
1 2 7
```

### Пример 2

Ввод:
```
3 3
5 4 3
```

Вывод:
```
5 4 3
```
