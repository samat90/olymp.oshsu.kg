Для каждого числа $c$ найдите наибольшее целое неотрицательное $x$, для которого $x^3 + x \le c$.

## Формат ввода

В первой строке дано $q$. Во второй — $q$ чисел $c$.

## Формат вывода

Выведите ответы через пробел.

## Ограничения

$1 \le q \le 10^5$, $0 \le c \le 10^{18}$.

## Примеры

### Пример 1

Ввод:
```
3
0 2 100
```
Вывод:
```
0 1 4
```

### Пример 2

Ввод:
```
1
1000000000000000000
```
Вывод:
```
999999
```
