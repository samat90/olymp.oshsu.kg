# Наборы монет

В кассе Темира m видов монет, каждого вида сколько угодно. Сколькими способами можно выдать ровно X сомов, если порядок монет не важен (наборы с разным числом монет какого-либо номинала считаются разными)?

**Ввод.** В первой строке m и X (1 ≤ m ≤ 20, 1 ≤ X ≤ 5000), во второй m различных номиналов (1 ≤ c_i ≤ 5000).

**Вывод.** Число способов по модулю 10^9 + 7.

**Пример**

Ввод:
```
3 5
1 2 5
```
Вывод:
```
4
```
