# Карусель процессов

Процессор по очереди выполняет задачи. Каждая задача получает не более `q` секунд, после чего, если не закончилась, уходит в конец очереди. Задача `i` требует `b_i` секунд работы. Когда закончится каждая задача? Переключение мгновенное.

## Входные данные
В первой строке числа `n` и `q` (`1 ≤ n ≤ 1000`, `1 ≤ q ≤ 1000`). Во второй строке `n` чисел `b_i` (`1 ≤ b_i ≤ 1000`).

## Выходные данные
`n` чисел через пробел - момент завершения каждой задачи по порядку ввода.

## Примеры

### Пример 1

Ввод:
```
3 4
10 4 6
```

Вывод:
```
20 8 18
```

### Пример 2

Ввод:
```
2 100
5 7
```

Вывод:
```
5 12
```
