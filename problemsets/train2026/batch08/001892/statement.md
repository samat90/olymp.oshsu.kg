# Самый тяжёлый мост на пути

Острова соединены мостами, каждый мост имеет вес w. Стоимость маршрута — наибольший вес моста на нём. Для каждого из q запросов u, v найдите наименьшую возможную стоимость маршрута или −1, если пройти нельзя. Для u = v ответ 0.

**Ввод.** В первой строке n, m, q. Затем m строк a b w, затем q строк u v. 1 ≤ n ≤ 50000, 1 ≤ m, q ≤ 100000, 1 ≤ w ≤ 100.

**Вывод.** Ответ на каждый запрос в отдельной строке.

## Примеры

**Ввод 1**
```
4 4 3
1 2 5
2 3 3
1 3 7
3 1 4
1 3
1 4
2 2
```
**Вывод 1**
```
4
-1
0
```
