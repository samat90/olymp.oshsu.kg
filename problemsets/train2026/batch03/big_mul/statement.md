# Умножение больших чисел

Перемножьте два больших неотрицательных числа.

## Вход

Две строки: десятичные записи чисел без ведущих нулей (число 0 записывается одной цифрой), длина каждой от 1 до 1000.

## Выход

Произведение чисел.

## Пример 1

**Вход**
```
12
34
```

**Выход**
```
408
```

## Пример 2

**Вход**
```
999
0
```

**Выход**
```
0
```
