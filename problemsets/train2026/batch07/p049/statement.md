# Единственный порядок

Даны $n$ задач и $m$ условий «задача $a$ раньше задачи $b$». Верно ли, что существует ровно один порядок решения всех задач, удовлетворяющий условиям?

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ пар $a\ b$.

**Вывод.** `YES`, если порядок ровно один, иначе `NO` (в том числе если порядка нет).

### Пример 1

**Ввод**
```
4 3
1 2
2 3
3 4
```

**Вывод**
```
YES
```
