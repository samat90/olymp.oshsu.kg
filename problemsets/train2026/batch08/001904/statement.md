# Самая длинная возрастающая

Найдите длину наибольшей строго возрастающей подпоследовательности массива (элементы берутся в исходном порядке, не обязательно подряд).

**Ввод.** В первой строке n, во второй — n чисел. 1 ≤ n ≤ 100000, 1 ≤ aᵢ ≤ 10⁹.

**Вывод.** Длина подпоследовательности.

## Примеры

**Ввод 1**
```
6
3 1 4 1 5 9
```
**Вывод 1**
```
4
```
