# Расстояние между словами

За одну операцию над словом можно вставить букву, удалить букву или заменить букву. Какое наименьшее число операций превращает слово s в слово t?

**Ввод.** Два слова по одному в строке, длиной от 1 до 1000, из строчных латинских букв.

**Вывод.** Наименьшее число операций.

**Пример**

Ввод:
```
kitten
sitting
```
Вывод:
```
3
```
