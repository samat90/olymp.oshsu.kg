# Маршрутка Бишкек — Ош

Между $n$ городами курсируют $m$ маршруток, каждая ходит в обе стороны. Бишкек — город $1$, Ош — город $n$. За какое наименьшее количество поездок на маршрутках можно добраться из Бишкека в Ош?

**Ввод.** В первой строке $n$ и $m$ ($2 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$). Далее $m$ строк с парами $a\ b$.

**Вывод.** Наименьшее количество поездок или $-1$, если добраться нельзя.

### Пример 1

**Ввод**
```
5 5
1 2
2 3
3 5
1 4
4 3
```

**Вывод**
```
3
```
