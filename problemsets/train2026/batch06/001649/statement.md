# Самый длинный подъём

Дан массив из n чисел. Найдите длину самой длинной строго возрастающей подпоследовательности (элементы берутся в исходном порядке, не обязательно подряд).

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (1 ≤ a_i ≤ 10^9).

**Вывод.** Длина.

**Пример**

Ввод:
```
8
5 2 8 6 3 6 9 7
```
Вывод:
```
4
```
