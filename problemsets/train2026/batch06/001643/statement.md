# Красивые числа

Число называется красивым, если оно делится только на простые числа 2, 3 и 5 (то есть имеет вид 2^a·3^b·5^c). Единица — красивое. Найдите n-е красивое число по возрастанию.

**Ввод.** Число n (1 ≤ n ≤ 10^5).

**Вывод.** n-е красивое число.

**Пример**

Ввод:
```
10
```
Вывод:
```
12
```
