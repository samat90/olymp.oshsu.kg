# Треугольники дружбы

В группе $n$ человек и $m$ пар друзей. Тройка людей, в которой каждый дружит с каждым, называется треугольником. Сколько в группе треугольников?

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 3000$, $0 \le m \le 30000$). Далее $m$ пар $a\ b$.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5 7
1 2
2 3
3 1
3 4
4 1
4 5
5 3
```

**Вывод**
```
3
```
