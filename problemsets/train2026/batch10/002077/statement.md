# Сортировка через тупик

Вагоны с номерами образуют перестановку чисел `1…n` и по одному заезжают в тупик (стек). Из тупика вагон можно в любой момент выпустить на выходной путь. Можно ли выпустить вагоны на выходной путь в порядке `1, 2, …, n`?

**Ввод.** `n` (`1 ≤ n ≤ 10^6`) и перестановка.

**Вывод.** `YES` или `NO`.

## Пример 1

Ввод:
```
3
2 1 3
```

Вывод:
```
YES
```

## Пример 2

Ввод:
```
3
3 1 2
```

Вывод:
```
YES
```
