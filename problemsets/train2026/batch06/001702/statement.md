# Компания без ссор

В кружке Бермет n учеников, у ученика i рейтинг r_i. Некоторые пары учеников в ссоре, их нельзя брать вместе. Какую наибольшую суммарную сумму рейтингов можно получить у набора учеников, в котором никто не в ссоре?

**Ввод.** В первой строке n и m (1 ≤ n ≤ 16, 0 ≤ m ≤ n(n−1)/2), во второй n рейтингов r_i (1 ≤ r_i ≤ 100), далее m строк с парами a, b (1 ≤ a < b ≤ n), пары различны.

**Вывод.** Наибольшая сумма.

**Пример**

Ввод:
```
4 3
5 3 4 6
1 2
2 3
3 4
```
Вывод:
```
11
```
