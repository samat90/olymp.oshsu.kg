# Шаблон со звёздочкой

Шаблон может содержать строчные латинские буквы и два особых знака: «?» заменяет ровно одну любую букву, «*» заменяет любую последовательность букв (в том числе пустую). Подходит ли строка шаблону целиком?

**Ввод.** В первой строке шаблон (1 ≤ длина ≤ 1500), во второй строка из строчных букв (1 ≤ длина ≤ 1500).

**Вывод.** YES или NO.

**Пример**

Ввод:
```
a*b?c
axxbyc
```
Вывод:
```
YES
```
