# Скобки ограниченной глубины

Сколько существует правильных скобочных последовательностей из `n` пар скобок, у которых глубина вложенности не превышает `d`? Ответ по модулю `10^9 + 7`.

**Ввод.** `n` и `d` (`1 ≤ d ≤ n ≤ 2000`).

**Вывод.** Одно число.

## Пример 1

Ввод:
```
3 2
```

Вывод:
```
4
```

## Пример 2

Ввод:
```
4 4
```

Вывод:
```
14
```
