# Лишняя дорога

Сёла $1..n$ были соединены сетью из $n-1$ дорог так, что из любого села можно добраться в любое. Затем построили ещё одну дорогу, и дорог стало $n$. Одну из дорог теперь можно закрыть, чтобы снова осталась сеть без циклов, связывающая все села. Выведите ту из подходящих дорог, которая стоит в списке последней.

**Ввод.** В первой строке $n$ ($3 \le n \le 10^5$). Далее $n$ строк с парами $a\ b$ — дорогами (все дороги различны).

**Вывод.** Пара $a\ b$ в том виде, как она записана во входных данных.

### Пример 1

**Ввод**
```
4
1 2
2 3
3 1
3 4
```

**Вывод**
```
3 1
```
