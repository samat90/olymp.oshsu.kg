# Стек с максимумом

Реализуйте стек с командами:

- `push x` - положить число;
- `pop` - убрать верхнее число и вывести его;
- `top` - вывести верхнее число;
- `peekMax` - вывести наибольшее число в стеке;
- `popMax` - вывести наибольшее число и удалить его из стека; если таких несколько, удаляется то, что ближе к вершине.

Команды `pop`, `top`, `peekMax`, `popMax` даются только при непустом стеке.

## Входные данные
В первой строке число команд `q` (`1 ≤ q ≤ 200000`), далее `q` строк. Числа `x` по модулю не больше 10^9.

## Выходные данные
Ответы на команды, кроме `push`, каждый в своей строке.

## Примеры

### Пример 1

Ввод:
```
7
push 5
push 1
push 5
top
popMax
top
peekMax
```

Вывод:
```
5
5
1
5
```
