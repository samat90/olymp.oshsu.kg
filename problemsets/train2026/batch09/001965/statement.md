# Ровно k неподвижных точек

Сколько существует перестановок чисел $1, 2, \dots, n$, в которых ровно $k$ чисел стоят на своих местах (на позиции $i$ стоит число $i$)? Ответ по модулю $10^9+7$.

**Ввод.** Два числа $n$ и $k$ ($0 \le k \le n \le 10^6$, $n \ge 1$).

**Вывод.** Количество перестановок по модулю $10^9+7$.

### Пример 1

Ввод:
```
3 1
```

Вывод:
```
3
```
