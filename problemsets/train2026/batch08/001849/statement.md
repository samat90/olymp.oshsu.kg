# Освещение дороги

Вершины дерева — перекрёстки. Нужно поставить фонари на некоторых перекрёстках так, чтобы каждый перекрёсток либо имел свой фонарь, либо был соединён дорогой с перекрёстком, где фонарь есть. Какое наименьшее число фонарей нужно?

**Ввод.** В первой строке n. Затем n−1 строк с рёбрами. 1 ≤ n ≤ 100000.

**Вывод.** Наименьшее число фонарей.

## Примеры

**Ввод 1**
```
5
1 2
1 3
3 4
4 5
```
**Вывод 1**
```
2
```

**Ввод 2**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
```
**Вывод 2**
```
2
```
