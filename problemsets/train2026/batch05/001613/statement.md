# История браузера

Браузер открывается на начальной странице. Команды:

- `visit s` - перейти на страницу `s` (все страницы «вперёд» забываются);
- `back k` - вернуться назад на `k` страниц, но не дальше первой страницы в истории;
- `forward k` - перейти вперёд на `k` страниц, но не дальше последней доступной.

После каждой команды `back` и `forward` выведите текущую страницу.

## Входные данные
В первой строке название начальной страницы, во второй число команд `q` (`1 ≤ q ≤ 200000`), далее `q` строк с командами. Названия состоят из строчных латинских букв, `1 ≤ k ≤ 10^9`.

## Выходные данные
Текущая страница после каждой команды `back` и `forward`, по одной в строке.

## Примеры

### Пример 1

Ввод:
```
osh
7
visit jalalabad
visit naryn
back 1
back 5
forward 1
visit talas
forward 2
```

Вывод:
```
jalalabad
osh
jalalabad
talas
```
