На шоссе вдоль озера Иссык-Куль стоят остановки на отметках $a_i$ (по неубыванию). Для каждой точки $x$ найдите отметку ближайшей остановки. Если две остановки одинаково близки, выберите ту, что левее.

## Формат ввода

В первой строке даны $n$ и $q$. Во второй — отметки остановок. В третьей — $q$ точек.

## Формат вывода

Для каждой точки выведите отметку ближайшей остановки, ответы через пробел.

## Ограничения

$1 \le n, q \le 2 \cdot 10^5$, $1 \le a_i \le 10^9$, $0 \le x \le 10^9+2$.

## Примеры

### Пример 1

Ввод:
```
3 3
2 5 9
4 7 20
```
Вывод:
```
5 5 9
```

### Пример 2

Ввод:
```
2 1
4 8
6
```
Вывод:
```
4
```
