# Свободные от квадратов наборы

Дано n чисел от 1 до 30. Сколько существует непустых наборов этих чисел (по позициям), у которых произведение не делится ни на один квадрат простого числа (то есть 4, 9, 25, … не делят произведение)?

**Ввод.** В первой строке n (1 ≤ n ≤ 10^5), во второй n чисел a_i (1 ≤ a_i ≤ 30).

**Вывод.** Количество наборов по модулю 10^9 + 7.

**Пример**

Ввод:
```
4
1 2 3 4
```
Вывод:
```
7
```
