# Прямоугольник в гистограмме

Гистограмма состоит из `n` столбцов шириной 1 и заданной высоты. Найдите наибольшую площадь прямоугольника, который целиком помещается внутри гистограммы.

## Входные данные
В первой строке число `n` (`1 ≤ n ≤ 200000`). Во второй строке `n` целых чисел - высоты от 0 до 10^9.

## Выходные данные
Максимальная площадь.

## Примеры

### Пример 1

Ввод:
```
6
2 1 5 6 2 3
```

Вывод:
```
10
```

### Пример 2

Ввод:
```
2
4 4
```

Вывод:
```
8
```
