# Не более k обменов

Дана перестановка `p` чисел `1…n`. За одну операцию можно поменять местами два соседних элемента. Разрешено не более `k` операций. Выведите лексикографически наименьшую перестановку, которую можно получить.

**Ввод.** `n`, `k` (`1 ≤ n ≤ 2000`, `0 ≤ k ≤ 10^9`) и перестановка.

**Вывод.** `n` чисел через пробел.

## Пример 1

Ввод:
```
5 3
5 4 3 2 1
```

Вывод:
```
2 5 4 3 1
```

## Пример 2

Ввод:
```
4 10
3 1 2 4
```

Вывод:
```
1 2 3 4
```
