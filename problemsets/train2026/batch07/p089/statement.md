# Самый ценный участок пути

Сеть из $n$ узлов — дерево, в каждом узле записано число $c_i$ (может быть отрицательным). Выберите простой путь (хотя бы из одного узла) с наибольшей суммой чисел в его узлах.

**Ввод.** В первой строке $n$ ($1 \le n \le 10^5$). Во второй — $n$ чисел $c_i$ ($|c_i| \le 10^4$). Далее $n-1$ строка с парами $a\ b$.

**Вывод.** Одно число.

### Пример 1

**Ввод**
```
5
-3 4 -1 5 2
1 2
2 3
2 4
4 5
```

**Вывод**
```
11
```
