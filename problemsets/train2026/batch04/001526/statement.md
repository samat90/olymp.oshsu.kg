Рабочий день длится от 0 до $T$. У преподавателя $n$ занятых промежутков $[l_i, r_i]$, они могут пересекаться. Найдите длину самого длинного непрерывного свободного промежутка в течение рабочего дня (промежуток с $l_i = r_i$ ничего не занимает).

## Формат ввода

В первой строке даны $n$ и $T$. Далее $n$ строк с парой $l_i$, $r_i$.

## Формат вывода

Выведите длину самого длинного свободного промежутка.

## Ограничения

$1 \le n \le 2 \cdot 10^5$, $1 \le T \le 10^9$, $0 \le l_i \le r_i \le T$.

## Примеры

### Пример 1

Ввод:
```
2 20
2 5
4 12
```
Вывод:
```
8
```

### Пример 2

Ввод:
```
1 6
0 6
```
Вывод:
```
0
```
