# Наименьшие суммы пар

Даны два массива `a` и `b`, каждый отсортирован по неубыванию. Из каждой пары `(a_i, b_j)` получается сумма `a_i + b_j`. Выведите `k` наименьших из этих сумм.

## Входные данные
В первой строке числа `n`, `m`, `k` (`1 ≤ n, m ≤ 100000`, `1 ≤ k ≤ min(n·m, 100000)`). Во второй строке `n` чисел, в третьей `m` чисел - элементы массивов, по модулю не больше 10^9.

## Выходные данные
`k` сумм по неубыванию через пробел.

## Примеры

### Пример 1

Ввод:
```
3 3 4
1 7 11
2 4 6
```

Вывод:
```
3 5 7 9
```

### Пример 2

Ввод:
```
2 1 2
1 1
3
```

Вывод:
```
4 4
```
