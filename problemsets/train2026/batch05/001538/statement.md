# Удаление повторов по k

Даны число `k` и строка из строчных латинских букв. Пока в строке есть `k` одинаковых букв подряд, такой блок из `k` букв удаляется (остальные части склеиваются). Какая строка получится?

## Входные данные
В первой строке число `k` (`2 ≤ k ≤ 10`). Во второй строке строка длиной от 1 до 200000.

## Выходные данные
Итоговая строка, а если она пустая - слово `ПУСТО`.

## Примеры

### Пример 1

Ввод:
```
2
aabbc
```

Вывод:
```
c
```

### Пример 2

Ввод:
```
3
ddeeeccdd
```

Вывод:
```
ddccdd
```

### Пример 3

Ввод:
```
2
abc
```

Вывод:
```
abc
```
